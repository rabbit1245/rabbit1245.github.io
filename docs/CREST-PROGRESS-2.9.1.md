# K볼 2.9.1 구단 배지 보완 완료

2026-10-26 · 누락 57개를 모두 연결해 **913개 구단 표시 / 표시 누락 0개**가 됐다. 마지막 11개는 사용자가 허용한 구버전·전신 배지 4개와 비공식 창작 SVG 7개로 보완했다. 창작 배지를 공식 엠블럼으로 분류하지 않는다.

구버전·전신 자료는 리라-리르서 베를라르(Lyra TSV), 벨리시아 빌전(Spouwen-Mopertingen), 몽스(RAEC Mons), 튀비즈-브렌(AFC Tubize)이다. 창작 배지는 울산시민, 여주, 센트럴 밸리 푸에고, 노던 콜로라도 헤일스톰, 니노버, 스토케, 뱅슈에 적용했다.

전체 913개 오프라인 디코딩·웹 캐시·재접속, 새 57개 구단의 PC·모바일 선택 화면 및 13개 리그 그룹의 전체 순위표, 기존 플레이 11항목 검수를 통과했다. 로고 경로 외 기존 카탈로그 데이터와 시뮬레이션·성장·이적·수상·세이브 로직을 보존했다. 외부 자료 사이트의 접속 설정 변경은 이번 배포의 선행 조건이 아니다.

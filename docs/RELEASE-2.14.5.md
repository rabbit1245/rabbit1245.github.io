# K볼 2.14.5 · 시즌 전환 오류와 불러오기 개선

2.14.4에서는 일반 경기 기록을 갖고 있는 커리어가 장기 진행 경로로 들어갈 때, 이미 읽기 전용인 경기의 `events`를 압축 배열로 교체하려다가 멈출 수 있었습니다. 22세·2031/32 시즌 결산 재현용 커리어에서 **다음 시즌 시작**으로 같은 예외를 확인했습니다. 수정본은 이전 경기 객체를 그대로 사용하고, 저장에 필요한 압축본을 별도로 생성합니다.

큰 원본을 읽을 때 압축 해제 청크를 묶어 같은 문자열을 반복 복사하는 비용을 줄였습니다. 처음 불러오는 동안 별도 스레드에서 원본 체크섬과 원장을 검사하며, 화면에 변환과 최근 진행 적용 단계를 표시합니다.

검증된 빠른 저장은 경기별 파일을 하나로 묶어 읽습니다. 이어하기는 저장해 둔 상태에 이후 변경분을 확인해 적용합니다. 자동 저장은 새 진행분을 이전과 같은 원장 형식으로 기록합니다. 캐시가 없거나 손상됐다면 원본 검사로 돌아갑니다. 기존 슬롯·백업·복구 원본을 같은 버전에서 계속 사용할 수 있습니다.

## 검수와 사용

22세 시즌 결산은 재현용 세이브로 확인했고, 장기 저장은 첨부된 실제 록 카발란 원본으로 확인했습니다. Linux의 Playwright Chromium에서 배포 HTML을 `file://`로 열고, 브라우저를 종료한 뒤 동일 경로와 동일 프로필로 다시 실행했습니다. Windows Edge의 실행 시간은 이 환경에서 측정하지 못했습니다.

다운로드한 ZIP을 풀어 기존과 같은 경로·이름의 `Kball.html`로 교체한 뒤 같은 브라우저 프로필에서 **이어서 플레이**를 선택하세요. 이전과 다른 경로에서 열거나 새 슬롯이 필요하면 **저장 가져오기**에서 보관한 `.kball-recovery`를 선택할 수 있습니다.

네 번의 진행은 리비전 950에서 1002까지 이어졌으며, 저장한 기준 스냅샷은 리비전 840을 유지했습니다. 진행 후 내보낸 복구 파일에서 원래 변경 기록 25개와 원본 압축 파트 8개를 바이트 단위로 대조했습니다. 과거 18시즌의 클럽 602경기와 대표팀 과거 기록 47개의 전체 필드 해시도 일치했습니다.

# 배포 대기 · 잠금 중 부상과 팀 기여 개선

> 후속 배포 요청에 따라 2.7.3으로 통합했습니다. 현재 최종 검수·배포 상태는 [2.7.3 릴리스 기록](RELEASE-2.7.3.md)을 확인하세요. 아래는 당시 개발 검증 기록입니다.

상태: **로컬 수정·검증, 배포 보류**. 최초 검증 버전은 `2.7.3-dev.1`, 현재는 성능 개선과 함께 `2.7.3-dev.2`에 포함합니다. 추가 패치를 받은 뒤 함께 검토하도록 보관하며, GitHub 소스·플레이용 브랜치에 푸시하거나 ZIP을 새로 올리지 않았습니다. 기존 2.7.2 다운로드 파일은 유지합니다.

## 잠금 상태의 부상 처리

- 능력치 전체·개별 잠금을 유지한 채 반 시즌/한 시즌 부상을 적용할 수 있습니다. 잠긴 능력치는 부상 진행 중에도 고정됩니다. 팀·국대 일정은 실제로 진행하고 선수에게 출전·득점·도움을 만들지 않습니다.
- 오프시즌에도 부상을 예약할 수 있습니다. 계약·훈련 결정 후 실제 다음 시즌의 소속 리그와 달력에 맞춰 182일/365일을 적용합니다. 예약만으로 과거 경기나 능력치를 바꾸지 않습니다. 이미 활성화된 부상과 중복 예약은 막습니다.
- 부상 예약은 저장·불러오기 후에도 유지하며 훈련 화면에서 ‘예약됨’으로 구별합니다. 후속 은퇴 기록 정리 요청에 따라 은퇴 TXT에는 연도별 실제 부상 유무·확인된 결장만 표시합니다. 기존 부상 이력은 보존합니다. 실제 선수 소속팀·국대 경기만 새 결장 원장에 추가하고 다른 구단의 컵 경기를 결장으로 세지 않습니다.
- 긴 부상 진행이 기존의 전체 60초 제한으로 중단되던 경로를 수정했습니다. 라운드별 진행 상황을 전달하고 응답이 계속되는 동안 계산을 유지합니다. 60초 동안 새 진행이나 결과 응답이 없으면 중단하고 기존 저장을 유지합니다. 진행 상황은 저장 데이터나 경기 난수에 포함하지 않습니다.

## 주장·부주장의 경기 기여

완장·임명 기록에 더해 실제 출전 중인 리더의 리더십·판단력·팀워크와 출전 시간을 조직력에 반영합니다. 정식 주장과 함께 뛰는 부주장도 작은 추가 기여를 합니다. 이 효과는 공격 전개와 상대 기회 억제에 적용하며 전체 조직력 효과는 최대 4.5%로 제한합니다. 결장 선수에게 효과를 주지 않고, NPC 주장도 같은 조직력 계산에 참여합니다. 기존의 주장 제의·수락 자격과 경력 기록은 유지합니다.

## 윙백의 경기력과 장기 구단 성장

- 크로스·시야·패스·판단 등이 동료의 실제 슈팅 기회 생성에 반영됩니다. 기존의 도움 배분과 실제 골·어시스트 원장은 유지합니다.
- 위치 선정·예측·수비·집중에 따른 수비 커버가 상대 슈팅 기회에 반영됩니다. 포지션마다 공격·수비 영향이 다르며 사용자·NPC에 같은 계산을 적용합니다.
- LWB/RWB 출전 시 같은 측면의 자리를 우선 교체합니다. 윙백을 넣으면서 센터백을 빼던 배치를 개선했습니다.
- 시즌에 실제로 충분히 뛴 핵심 선수는 중하위권 성적에서도 구단 수입과 보강 예산의 근거가 됩니다. 최소 8경기 출전과, 720분·리그 전체 시간 35% 중 더 큰 출전 시간 기준, 실제 평점, 구단 기본 전력 대비 실력을 함께 봅니다. 수비 포지션은 포지션별 평점 규모를 적용합니다. OVR만 높고 출전하지 않으면 이 효과가 없습니다.
- 핵심 선수 수입은 기여도에 따라 연 수입의 최대 3.5%, 잔류 핵심 선수에 맞춘 추가 예산 배정은 최대 7%입니다. 실제 구단 예산을 사용하며 기존 예산 사용 상한, 연간 투자 전력 증가 최대 0.7, 누적 투자 전력 최대 6, 연 3% 투자 효과 감소를 유지합니다. 구단 기본 전력·선수 능력치·기존 성적을 다시 쓰지 않습니다.
- 구단 성장 화면에 기여 선수·출전 시간·평점·배정 예산을 남깁니다. 후속 은퇴 기록 정리 요청에 따라 은퇴 TXT에는 내부 재투자 이력을 출력하지 않습니다. 저장 검사도 보존한 수입 근거와 추가 예산 한도를 확인합니다.

## 검증 결과와 범위

변경 관련 로직 8개(부상 결장 필터 별도 실행 포함), 기존 경기·구단 성장·명령 회귀 검사 43개가 통과했습니다. 브라우저에서는 잠금 중 오프시즌 예약·재실행·중복 방지, 실제 시즌 부상 명령의 Worker 진행과 능력치 보존을 확인했습니다. 시간 제한 갱신은 가상 시계로 177초 동안 진행 응답을 보내 검증하고, 응답이 멈추면 제한이 작동하는 것도 확인했습니다.

초기 첼시 선수단·일정을 고정하고 동일한 12개 난수 조건에서 전 경기 90분 출전시킨 비교입니다. 세부 능력치를 같은 수준으로 맞춘 실험이며, 사용자의 448경기 저장을 재현한 것은 아닙니다.

| 조건 | 평균 순위 | 평균 승점 | 3위 이내 |
|---|---:|---:|---:|
| 기존 계산 · 윙백 74 | 12.67 | 46.83 | 0/12 |
| 수정 계산 · 윙백 74 | 12.83 | 46.58 | 0/12 |
| 기존 계산 · 윙백 94 | 11.50 | 50.50 | 0/12 |
| 수정 계산 · 윙백 94 | 8.83 | 55.58 | 1/12 |

별도로 같은 시드에서 실제 전체 리그·컵·국대·부상·계약을 진행한 4시즌 비교도 했습니다. 투자 전력 누적은 기존 0.086에서 수정안 2.038로 늘었습니다. 수정 후 3년차에 4위가 나왔지만 4년차에는 14위도 나왔으며, 이 단일 장기 사례의 평균 순위·승점이 좋아졌다고 주장하지 않습니다. 확인한 것은 핵심 선수의 경기 기여와 실제 재투자가 생긴다는 점입니다. 우승·상위권을 보장하지 않으며, 장기 순위 분포는 추가 패치와 최종 배포 전 검토 대상입니다. 상세 시즌 결과를 검증 JSON에 그대로 보존합니다.

새 오프시즌 회귀 자료는 이전 2.7.2의 실제 시뮬레이션 내보내기를 gzip으로 보관했습니다. 과거 기록을 잘라내거나 새로 만들지 않고 가져오기·예약·달력 전환·기록 보존을 검증합니다. 자세한 근거는 [회귀 자료 설명](../tests/fixtures/v272-offseason.md)에 있습니다.

이번에는 요청한 변경에 관련된 검사와 로컬 웹 빌드만 마무리했습니다. 전체 회귀 일괄 실행은 중간에 중단했으며 전체 통과로 표시하지 않습니다. 플레이용 HTML·ZIP 생성과 다운로드판 검사는 추가 패치 반영 후 최종 배포 단계에서 진행합니다.

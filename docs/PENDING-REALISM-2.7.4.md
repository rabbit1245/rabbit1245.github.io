# 배포 보류 · 국대·개인상·장기 잔류 성장 개선

2026-10-25 · **로컬 개발본 2.7.4-dev.1, 배포하지 않음**. 사용자가 확인한 쵸비 선수의 인테르 트레블·리그 17골 10도움 사례와 포르투갈 소집 문제를 기준으로 개선했습니다. 쵸비 원본 저장은 제공되지 않아 동일 조건의 구성 시나리오와 별도 실제 커리어로 검증했으며, 원본 플레이를 재현했다고 표시하지 않습니다. 공개 다운로드판은 2.7.3을 유지합니다.

## 국대와 능력치 기준

- 사용자의 90은 기존 S 잠재력 89~92의 기준, 즉 손흥민 전성기·득점왕 수준의 세계적인 선수라는 기준을 유지합니다. 국대에서도 사용자와 NPC를 같은 경기 능력치 척도로 비교합니다.
- 클럽 경기의 NPC 보정 전 내부 OVR을 국대에서는 그대로 사용하던 불일치를 수정했습니다. 연령대 선택, 소집 경쟁, 대표팀 경기, 주장 평가에 클럽에서 실제 사용하는 NPC 실력을 적용합니다. 선수·클럽의 기존 기록이나 사용자 능력치를 낮추지 않습니다.
- 국대는 GK 3·DF 8·MF 8·FW 7의 26인 명단을 구성합니다. 중앙 공격수와 좌우 윙, 수비·중원 대체 자리를 확보한 뒤 남은 자리를 실제 출전·평점·실력·리그 수준·컨디션으로 비교합니다. 부상과 실제 경쟁은 계속 적용하며 능력치만으로 무조건 선발시키지 않습니다.
- 주장 화면의 국대 평가는 해당 국적 전체 선수의 OVR 상위 11명이 아닌, 포지션을 고려한 소집 명단의 예상 XI를 기준으로 합니다. 화면에도 ‘예상 주전 평균’으로 표시하며 실제 경기의 기용·교체와 구별합니다.
- 구단 매칭에 성공한 선수만 담겨 있던 국적 색인을 보관된 FC25 전체 **16,161명·153국적**으로 재생성했습니다. 예를 들어 벤피카 소속 파블리디스를 포르투갈 선수로 잘못 분류하던 부분을 그리스로 바로잡습니다. 국적을 읽을 때 보관 자료를 적용하므로 이전 경기·국대 이력은 다시 쓰지 않습니다. 재생성 명령은 `python3 scripts/refresh-nationalities.py`입니다.
- 앞으로 생성되는 보강·유망주 선수는 모두 소속 리그 국적으로 만들지 않고, 보관된 해당 구단의 국적 구성에서 별도 시드로 배정합니다. 기존 가상 선수의 국적은 유지합니다.

## 개인상과 베스트 11

- 세리에 A 시즌 MVP와 AIC 올해의 팀 평가 경로를 추가했습니다. 베스트 11이 없던 다른 리그에도 명확히 ‘K볼 선정’으로 구분한 평가를 제공합니다. 기존 공식 명칭·득점왕·도움·골키퍼 상은 유지합니다. 실제 투표 및 시상 일정과 게임의 시즌 모형은 구별합니다.
- 리그 시상은 계속 리그 기록만 사용합니다. 베스트 11은 골키퍼·수비·중원·공격 인원에 더해 좌우 측면과 중앙 역할도 고려합니다. 중앙 공격수 세 명으로 윙의 자리를 모두 채우던 선정을 개선했습니다.
- 포지션별 행동 수와 평점의 구조 차이가 특정 포지션을 일방적으로 유리하게 만들지 않도록, 같은 리그·역할에서 충분히 뛴 선수들의 실제 기록을 공통 기준으로 사용합니다. 구단 연간 개인상도 이 기준으로 비교합니다. 능력치나 재능 등급을 수상 점수로 넣지 않습니다.
- 발롱도르·월드 11에는 리그 성적과 주요 대회 우승, 해당 선수의 실제 대회 출전·기여를 반영합니다. 챔피언스리그·다른 대륙대회·국내 컵의 가중치를 구분하고 실제로 기여한 리그·대륙·국내 컵 트레블에 추가 평가를 부여합니다. 같은 우승팀의 미출전 선수에게 점수를 주지 않습니다.
- 평가 상세에 전체 순위와 대회 기여 점수, 리그 포지션군 경쟁 순위를 표시합니다. 후보에서 빠져도 어떤 범위와 기록으로 비교했는지 확인할 수 있습니다.
- 이미 확정된 과거 수상과 순위는 보존하며 새 평가부터 적용합니다. 과거에 상대 선수단의 세부 원장이 보존되지 않은 시즌을 임의 재평가해 상을 만들지 않습니다.

## 장기 잔류와 팀 성장

- 기존 원래 구단 전력은 고정합니다. 실제 성적과 재투자로 누적되는 전력의 상한을 기존 6점에서 구단 수준에 따라 최대 22점으로 넓히고, 평판의 장기 상향 여지도 3점에서 6점으로 확대합니다.
- 투자에는 여전히 실제 성과 수입·핵심 선수 기여·배정 예산·재투자 금액이 필요합니다. 한 시즌 투자 증가 상한은 1.4점이며 리그 단계와 이미 높은 팀 전력에 따라 효과가 줄어듭니다. 투자 효과는 연 2% 감가합니다. 기존 투자액은 업데이트 때문에 잘라내지 않습니다.
- 패스·찬스 공급과 수비 커버의 경기 영향은 소폭 높였으며 NPC와 사용자에게 같은 공식을 사용합니다. 순위나 우승을 강제하지 않습니다. 사용자 능력치와 훈련 선택·잠금 규칙은 바꾸지 않습니다.

고정 능력치 90·전 경기 90분 조건으로 이스트렐라 아마도라에 12시즌 잔류한 공격수 3시드와 윙백 3시드를 이전판과 짝지어 비교했습니다. 이 실험은 해당 리그의 모든 경기를 실제 계산하지만 컵·국대·승강은 제외한 리그 단위 대조이며, 제품의 계산 범위를 줄인 것이 아닙니다.

| 마지막 시즌 6시드 평균 | 이전판 | 수정본 |
| --- | ---: | ---: |
| 팀 전력 | 78.26 | 84.19 |
| 순위 | 4.33위 | 3.50위 |
| 승점 | 66.17 | 75.00 |
| 전체 72개 리그 시즌의 우승 횟수 | 2 | 7 |

모든 시드의 마지막 순위가 좋아진 것은 아닙니다. 한 공격수 시드는 2위에서 4위로 내려갔습니다. 확인한 것은 원래 전력과 개인 능력치를 유지하면서 장기 재투자가 누적되고 강팀으로 올라갈 경로가 생긴다는 점입니다. [전체 대조 자료](validation/pending-realism-274/club-balance.json).

## 통산 기본 정보

은퇴 화면과 TXT의 통산 기본 정보에서 능력점수를 제외했습니다. 실제 게임 계산용 현재 능력치, 연도별 시작·종료 점수와 능력 성장 기록은 그대로 유지합니다.

기존 30시즌 저장 81,104,879바이트를 가져와 재실행·내보내기한 TXT는 요청한 기본 정보의 능력점수 한 줄을 제외하면 이전 출력과 바이트 단위로 같습니다. 변경 후 86,425바이트이며 모든 연도별·통산 보존 스탯, 수상과 결승 기록을 대조했습니다.

## 검증

- 회귀 **239개 통과·실패 0**, 30시즌 신규 생성 1개는 이번 비배포 단계에서 생략했습니다. 아래 별도의 3시즌 전체 세계 진행과 12시즌 리그 대조, 기존 30시즌 호환 검사를 수행했습니다.
- 리그 17골·10도움에 유럽·국내 컵 실제 기여를 구성한 트레블 사례가 발롱도르 후보와 리그 올해의 팀 평가에 반영됩니다. 능력치 숫자만 바꿔도 수상 순위는 같고, 미출전 우승팀 선수는 해당 상을 받지 않으며 확정 평가를 반복해도 중복 수상하지 않습니다.
- 포르투갈 국적·인테르 RW·능력치 90으로 **전체 세계·컵·국대 일정을 실제 3시즌 진행**했습니다. 능력치는 게임의 치트 API로 설정한 뒤 잠갔으며 출전·승패·국대 발탁·수상은 강제하지 않았습니다. 리그 15골 12도움 / 23골 14도움 / 16골 10도움, 발롱도르 17위 / 4위 / 6위, 국대 누적 8 / 19 / 27경기를 기록했고 세 시즌 모두 리그 올해의 팀에 선정됐습니다. 기존 시즌의 경기·스탯·수상·능력·재정은 해시로 보존을 확인했습니다. 시즌 전환 뒤 실제 계산되어 추가되는 구단 성장 자료는 그 해시에서 제외합니다.
- 실제 브라우저에서 국대 예상 평균 85.1·사용자 90·대표팀 발탁·세리에 A 올해의 팀, 새로고침과 모바일 연도별 기록을 확인했습니다. 타입 검사와 로컬 웹 빌드도 통과했습니다.
- 공개 브랜치·ZIP은 수정하지 않았고 새 플레이용 HTML·ZIP을 생성하지 않았습니다. Windows Edge의 직접 `file://` 실행을 검증했다고 표시하지 않습니다.

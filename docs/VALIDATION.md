# K볼 2.2 구현·검증 기록

2026-10-22의 추가 색상 요청은 화면 색상과 배포 파일의 테마 색상만 변경한다. 경기 계산·저장 형식·기능·화면 배치·글꼴 크기는 그대로 유지한다. 아래 2.2 기능과 엔진·30시즌 결과는 앞선 기능 개편에서 완료한 검증이며, 이번 색상 개편에서 엔진 검사를 다시 실행했다는 뜻은 아니다. 실행 산출물은 `npm run build`와 `npm run build:playable`로 생성한다.

## 화이트 중심·연두 포인트 색상 개편

구글 시트처럼 흰색 바탕과 중립 회색 구분선, 짙은 회색 본문을 사용한다. 큰 배너·알림·훈련 요약·주장 제의·은퇴 요약의 녹색 면적을 흰색 또는 옅은 회색으로 바꾸고, 연두색은 주요 버튼과 선택 상태·작은 표시 영역에 사용한다. 본문은 `#202124`, 보조 글자는 `#5f6368`, 배경은 `#ffffff`, 보조 면은 `#f8f9fa`다.

주요 버튼은 연두 바탕에 짙은 글자를 사용하고 hover에서도 글자 대비를 유지한다. 비활성 상태는 투명도를 낮추지 않고 회색 바탕과 읽을 수 있는 글자로 구별한다. 입력·선택 상자·placeholder·차트 눈금과 값·브라우저의 어두운 색상 선호도 같은 기준으로 확인한다. 증감·승패·오류의 의미를 전달하는 상태색은 보존하고, 양수 글자는 선택 배경에서도 읽히도록 `#137333`을 사용한다.

색상 검수는 실제 전경·조상 배경·투명도를 합성해 대비를 측정한다. 일반 글자와 비활성 글자는 4.5:1 이상, 큰 글자는 3:1 이상을 기준으로 삼는다. 원본 구단 로고·국기 이미지는 텍스트 대비 측정 대상에서 제외한다.

이번 색상 개편의 최종 빌드에서 1366×768·1920×1080·390×844, 일반·선택·hover·비활성 상태와 어두운 색상 선호를 포함한 117개 화면을 검사했다. 텍스트 표본 11,312개에서 대비 기준 미달 0개, 최소 대비 4.752:1, 비활성 표본 356개다. 알림에 가려진 글자·잘린 글자·브라우저 오류는 모두 0개다. 모바일 성장표의 마지막 열은 기존 가로 스크롤로 실제 화면 안에서 확인할 수 있다.

## 시즌 진행·주장 제의

이적·재계약은 시즌 종료 후 한 번 결정한다. 반시즌에는 제안을 생성하거나 계약 때문에 진행을 멈추지 않는다. 이전 저장의 시즌 중 제안은 원래 해시를 확인한 뒤 첫 명령에서 해제하고 이미 체결한 계약은 보존한다.

팀 현황과 라커룸 중복 탭·설정 진입 버튼을 정리했다. 훈련은 선수 화면 한 곳에서 관리하고 미확정 오프시즌에만 바로가기를 보여 준다. 라커룸 시즌 현황 아래에는 현재 시즌 클럽·국대 합계의 9개 세부 지표를 표시한다. 상단 대회와 선수 요약은 같은 실제 소속·발탁·출전 기록을 사용하며, 새 시즌에 이전 국대 소집 상태를 그대로 표시하지 않는다.

주장·부주장은 실제 팀 전력·주전 평균과 실력·성과·연령·리더십·근속·신뢰를 평가해 제의한다. 사용자와 동료 후보 순위는 같은 시즌·항목·가중치로 비교한다. 제의는 수락 전까지 역할·정식 임기를 바꾸지 않으며, 거절·만료·이력과 기존 임기는 보존한다. 수락 후 과거 경기 수를 소급하지 않는다.

## 이전 2.2 화이트·연두 화면 검증

이전 2.2 배포는 화이트 카드·연두 배경에 진한 녹색 글자를 사용했다. 비활성 버튼의 투명도를 없애고 글자·배경을 함께 지정했으며, 활성/비활성 전환 중 대비가 낮아지는 배경 애니메이션도 제거했다. 입력 상자·선택 상자·placeholder·브라우저의 어두운 색상 선호에도 밝은 색상 모드를 명시했다. 구단 로고가 없을 때의 대체 글자는 구단 색과 무관하게 읽히는 색으로 표시한다. 이러한 가독성 처리와 화면 배치는 이번 색상 개편에서도 유지한다.

알림은 헤더의 흐름 안에 표시해 훈련 수치나 확정 버튼을 가리지 않는다. 생성 중 훈련을 모두 해제해도 20개 수치 목록을 유지하고 다시 선택할 수 있도록 수정했다.

1366×768·1920×1080·390×844의 일반·선택·hover·비활성 상태, 생성·능력치·훈련·계약·성장·커리어·설정·경기 상세 등 117개 화면 표본에서 11,372개 텍스트의 실제 전경/배경/투명도를 합성해 측정했다. 대비 기준 미달 0개, 최소 대비 4.752:1, 비활성 표본 353개, 고정 알림에 가려진 텍스트 0개, 잘린 텍스트 0개, 브라우저 오류 0개다. 이미지는 텍스트 대비 측정 대상에서 제외한다. 모바일 성장표는 가로 스크롤로 나머지 열을 확인하는 기존 방식을 유지하며, 선수 화면에서 맨 오른쪽 열을 실제 화면 안으로 이동해 접근할 수 있음을 확인했다.

프로덕션과 단일 HTML의 브라우저 플레이·데스크톱 배치·모바일 GK·저장·불러오기·은퇴 통계도 통과했다. 색상 검수는 브라우저 검사에서 생성한 저장 파일을 사용하므로 `npm run test:e2e` 뒤 `npm run test:colors`로 반복한다.

앞선 2.2 기능 개편에서 엔진·저장 자동 검사 150개를 통과했다(빠른 검사 149개 + 실제 30시즌 검사 1개). 당시 TypeScript·프로덕션 빌드와 데스크톱/모바일 브라우저 흐름도 통과했다. 이번 색상 개편은 계산·저장 코드를 바꾸지 않으므로 이 결과를 기존 기능 검증으로 구분해 보존한다. 정확한 실행 명령은 README의 검증 절에 있다.

관리형 브라우저는 `file://` 접근을 차단하므로 단일 HTML의 자동 검증은 동일 파일을 로컬 HTTP로 전달해 수행했다. 사용자가 자신의 PC에서 파일을 직접 여는 경로는 이 환경에서 직접 확인하지 못했다.

**2026/27 공식 규정·평가 기간 전체 확인은 미완료**다. 공식 사이트 접근에 네트워크 403이 발생했으며, 실제 수상 명칭과 게임 선정 모형을 구분했다. 상세 범위와 참고 기관은 [RULES.md](RULES.md)에 남겼다.

# K볼 2.1 구현·검증 기록

2026-10-21 개선안 기준으로 화면과 계산을 함께 변경했다. 실행 산출물은 `npm run build`와 `npm run build:playable`로 생성한다.

## 화이트·연두 화면 보완

화이트 카드·연두 배경에 진한 녹색 글자를 사용한다. 비활성 버튼의 투명도를 없애고 글자·배경을 함께 지정했으며, 활성/비활성 전환 중 대비가 낮아지는 배경 애니메이션도 제거했다. 입력 상자·선택 상자·placeholder·브라우저의 어두운 색상 선호에도 밝은 색상 모드를 명시했다. 구단 로고가 없을 때의 대체 글자는 구단 색과 무관하게 읽히는 색으로 표시한다.

알림은 헤더의 흐름 안에 표시해 훈련 수치나 확정 버튼을 가리지 않는다. 생성 중 훈련을 모두 해제해도 20개 수치 목록을 유지하고 다시 선택할 수 있도록 수정했다.

1366×768·1920×1080·390×844의 일반·선택·hover·비활성 상태, 생성·능력치·훈련·계약·성장·커리어·설정·경기 상세 등 119개 화면 표본에서 10,147개 텍스트의 실제 전경/배경/투명도를 합성해 측정했다. 대비 기준 미달 0개, 최소 대비 4.752:1, 비활성 표본 427개, 고정 알림에 가려진 텍스트 0개, 브라우저 오류 0개다. 이미지는 텍스트 대비 측정 대상에서 제외한다. 모바일 성장표는 가로 스크롤로 나머지 열을 확인하는 기존 방식을 유지하며, 라커룸·선수 화면 두 곳에서 맨 오른쪽 열을 실제 화면 안으로 이동해 접근할 수 있음을 확인했다.

프로덕션과 단일 HTML의 브라우저 플레이·데스크톱 배치·모바일 GK·저장·불러오기·은퇴 통계도 통과했다. 색상 검수는 브라우저 검사에서 생성한 저장 파일을 사용하므로 `npm run test:e2e` 뒤 `npm run test:colors`로 반복한다.

엔진·저장 자동 검사 137개를 통과했다(빠른 검사 136개 + 실제 30시즌 검사 1개). TypeScript·프로덕션 빌드와 데스크톱/모바일 브라우저 흐름도 통과했다. 정확한 실행 명령은 README의 검증 절에 있다.

관리형 브라우저는 `file://` 접근을 차단하므로 단일 HTML의 자동 검증은 동일 파일을 로컬 HTTP로 전달해 수행했다. 사용자가 자신의 PC에서 파일을 직접 여는 경로는 이 환경에서 직접 확인하지 못했다.

**2026/27 공식 규정·평가 기간 전체 확인은 미완료**다. 공식 사이트 접근에 네트워크 403이 발생했으며, 실제 수상 명칭과 게임 선정 모형을 구분했다. 상세 범위와 참고 기관은 [RULES.md](RULES.md)에 남겼다.

# K볼 2.1 구현·검증 기록

2026-10-21 개선안 기준으로 화면과 계산을 함께 변경했다. 실행 산출물은 `npm run build`와 `npm run build:playable`로 생성한다.

| 범위 | 구현 및 검증 |
|---|---|
| 화면 | 3개 주요 메뉴, 같은 자리의 하위 화면 전환, Pretendard 내장, 능력치 설명창 제거, 능력치·훈련 현재값과 변화량 상시 표시 |
| 데스크톱 | 1366×768·1920×1080에서 라커룸 핵심, 필드 20능력치, 훈련 20항목 표시. 오프시즌 훈련 확정 버튼과 전체 패널이 화면 안에 들어오는지 실제 DOM 치수 검사 |
| 작은 화면 | 모바일 GK 10능력치와 9지표·반시즌 플레이, 가로 넘침 검사. 125% 확대에 해당하는 작은 CSS 뷰포트에서 17px 본문 유지·재배치 확인 |
| 성장 | 실제 생성 미리보기=시작 수치. 선택 훈련 집중, 출전 경험·발달 상한, 환경·출전·부상 영향, 원인별 합계, 별도 노화 보고서, 연간 한 번 확정 |
| 경기·세계 | 기존 능력치별 공통 난수 비교·개인 행동/득점 원장·필드/GK 지표·지속 선수단·승강의 다음 리그/상대/일정/재정 반영 유지 |
| 국대 | 경기일별 진행, 미래 경기 선계산 방지, 이중 창 방지, 이전 저장의 중간 창 이관, 다음 클럽 선발에 국대 부상 반영 |
| 경제 | 이전/새 계약 조건·실제 날짜·재계약 이력, 시즌 시작 몸값, 주급 고정·구단 이적료/선수 수입 분리 |
| 저장 | 실제 구버전 v1·배포 v2 해시 보존, 과거 미집계 유지, 새 원장 검증, 독립 가져오기 슬롯·손상 거절·이전 정상본 복구 |
| 장기 | 14세→43세 30시즌 실제 세계 경기 계산. 클럽 1,020경기·국대 115경기와 은퇴 전후 통산 일치. 실제 69,547,417바이트 저장의 JSON 왕복·브라우저 가져오기·IndexedDB 저장·재접속 확인 |
| 연출·오프라인 | 연출 생략/움직임 줄이기 전후 세계 해시·경기·경제·국대 일치. 프로덕션 오프라인 재접속, 단일 HTML 외부 코드/데이터/이미지/글꼴 요청 없음 |
| 기존 게임 | CAREER24 코어 및 브라우저 회귀 통과. 원래 게임·저장은 별도 경로로 보존 |

엔진·저장 자동 검사 137개를 통과했다(빠른 검사 136개 + 실제 30시즌 검사 1개). TypeScript·프로덕션 빌드와 데스크톱/모바일 브라우저 흐름도 통과했다. 정확한 실행 명령은 README의 검증 절에 있다.

관리형 브라우저는 `file://` 접근을 차단하므로 단일 HTML의 자동 검증은 동일 파일을 로컬 HTTP로 전달해 수행했다. 사용자가 자신의 PC에서 파일을 직접 여는 경로는 이 환경에서 직접 확인하지 못했다.

**2026/27 공식 규정·평가 기간 전체 확인은 미완료**다. 공식 사이트 접근에 네트워크 403이 발생했으며, 실제 수상 명칭과 게임 선정 모형을 구분했다. 상세 범위와 참고 기관은 [RULES.md](RULES.md)에 남겼다.

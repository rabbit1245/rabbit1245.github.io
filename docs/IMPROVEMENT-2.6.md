# K볼 2.6 · 대회 진행과 커리어 기록의 연결

최종 통합 요청서의 우선순위에 따라 경기 편성·진행·진출권·기록·수상을 먼저 연결했다. 화이트·회색과 제한된 연두 포인트, 기존 성장·훈련·계약·스카우팅·치트·기록 기능을 유지했다.

## 확인한 원인

- 기존 세계에는 정규리그만 있었고 국내 컵·UEFA 클럽대회의 별도 일정과 원장이 없었다. 표시 문제만으로 해결할 수 없었다.
- 국대는 6·11월 두 차례 소집, 짧은 예선과 최대 4팀 본선이었다. 경기 기회가 적고 컵 성과도 세계 개인상 평가에 들어갈 수 없었다.
- 기존 개인상 판정 자체는 존재했다. 문제는 빠진 대회 성과와 평가 근거의 부재였다. 수상을 일괄 보장하는 방식으로 바꾸지 않았다.
- 구단의 초기 전력 보존은 2.3.1 이후 이미 적용돼 있었다. 재투자로 개선된 선수단이 구단 전력 기준에 남는 효과를 추가하고 반복 결과를 검증했다.
- 사용자 선수의 시즌 전 자동 능력치 감소와 강제 연령 은퇴, 주장 선임의 연령 문턱이 새 요구와 맞지 않았다.
- 확장 과정에서 저장 검증의 국대 소집 월 제한, NPC 득점과 연결된 슈팅 보관, 중복 유로파 참가권, 국대·컵 날짜 처리 순서 문제를 발견해 고쳤다.

## 지원 대회와 명시한 게임 규칙

국내 컵은 지원하는 구단만 참가한다. 지역 예선에서 존재하지 않는 구단이나 과거 경기·우승을 만들지 않는다.

| 국가 | 대회 | 게임에서 지원하는 방식 |
|---|---|---|
| 잉글랜드 | FA컵·카라바오컵 | FA 단판, 카라바오 4강 홈·원정 |
| 독일 | DFB 포칼 | 최대 64팀 단판 |
| 스페인 | 코파 델 레이 | 리저브 제외, 4강 홈·원정 |
| 이탈리아 | 코파 이탈리아 | 최대 44팀, 4강 홈·원정 |
| 프랑스 | 쿠프 드 프랑스 | 지원 구단 단판 |
| 네덜란드 | KNVB 베이커 | 리저브 제외, 단판 |
| 포르투갈 | 타사 드 포르투갈·타사 다 리가 | 타사 4강 홈·원정, 리가 1부 6팀·2부 2팀 |
| 벨기에 | 벨기에 컵 | 4강 홈·원정 |
| 튀르키예 | 튀르키예 컵 | 지원 구단 단판; 실제 시즌별 조별 형식 축약 |
| 대한민국 | 코리아컵 | 지원 K1·K2·K3 단판 |
| 일본 | 천황배·르방컵 | 천황배 단판, 르방 8강·4강 홈·원정 |
| 중국 | 중국 FA컵 | 지원 구단 단판 |
| 브라질 | 코파 두 브라질 | 32강부터 홈·원정, 결승은 게임 단판 |
| 미국 | US 오픈컵 | 지원 미국 구단 단판, 캐나다 구단 제외 |

현재 존재하지 않는 한국·프랑스·독일 등의 리그컵은 생성하지 않는다. 지원 구단이 없는 대회의 지역 예선이나 다른 나라의 구단은 가상으로 채우지 않는다. 부전승과 홈·원정 합계, 실제 경기 승자에 따른 진출·탈락·우승을 처리한다. 정규 90분, 홈·원정은 합계 동률일 때 **연장전을 생략하고 승부차기**를 진행하는 게임 규칙을 화면에도 명시했다. 승부차기는 정규 골·도움에 더하지 않는다.

UEFA는 UCL·UEL·UECL을 별도 편성한다. 각각 36팀, 리그 페이즈 8·8·6경기, 1~8위 직행·9~24위 플레이오프, 16강 이후 홈·원정과 단판 결승이다. 이전 대회 탈락팀을 다른 대회로 보내는 옛 방식은 사용하지 않는다. 최초 시즌은 전력 시드, 이후에는 실제 리그 순위·국내 컵 우승·UEFA 우승팀 자격으로 다음 시즌 참가권을 정한다. 중복 자격은 차순위로 넘긴다.

**UEFA의 9개 지원 국가 내 참가권 배분과 빈자리 충원, 예선과 추첨의 포트·동일 협회 제한은 게임 모형**이다. 전체 UEFA 회원국의 실제 연도별 계수·예선 토너먼트를 재현한 구현은 아니다. 국내 컵도 지원 범위 밖 지역 예선과 시즌별 상세 시드를 축약했다. 코드의 `cup-rules.ts`와 대회 상세에서 적용 규칙을 확인할 수 있다.

국대는 3·6·9·10·11월 소집 기간을 사용한다. 예선을 일찍 마친 해에도 친선을 편성한다. 월드컵 48팀·104경기, 유로·아시안컵·아프리카컵·U20 월드컵 24팀, 골드컵 16팀, 코파 10팀, OFC 8팀을 지원 국가 범위에서 진행한다. 조별리그와 녹아웃을 실제 경기로 치르고, 해당 대회의 3·4위전도 처리한다. 주기는 WC 4년, U20 2년, 골드컵·아프리카컵 2년, 그 외 지원 대륙대회 4년이다. 국적과 대륙 소속으로 참가 대회를 정한다. 지원 대표팀 목록 밖 국적은 사유를 표시하고 공식 대회 출전을 생성하지 않는다.

대표팀 예선은 국가별 실제 예선 구조 대신 **지원 국가의 시드 조·홈원정 리그와 성적 비교**를 사용한다. 본선 개최일과 중립 구장, 연장 생략도 게임 모형이다. 국제대회가 없는 해의 모든 소집에서 반드시 같은 경기 수를 강제하지 않는다. 출전 경쟁·로테이션·부상 때문에 선수 출전 수는 팀 경기 수와 다를 수 있다.

`season.matches`와 `season.playerStats`, 세계 리그 기록은 **리그만** 유지한다. 새 컵은 `systems.clubCompetitions.current/history`에 보관한다. 통합·대회별·통산·은퇴 기록에서 해당 실제 경기들을 합산하며 경기 ID로 중복을 제거한다. 컵 득점은 리그 순위·리그 득점왕에 섞이지 않는다. NPC의 실제 경기 점수와 시즌 집계도 같은 시뮬레이션에서 만든다.

세계 개인상은 클럽 컵 기록과 실제 우승 성과도 포함한다. 대회 개인상은 해당 본선 또는 클럽대회 기록만 사용한다. FIFA 대회 개인상과 지원 대륙대회 득점왕·최우수 선수·골키퍼상, UEFA 클럽대회 시즌의 선수를 실제 성적으로 평가한다. 유로에는 존재하지 않는 골든 글러브를 추가하지 않았다. 수상 명칭과 별개로 투표·득표 수치는 공식 시상식 재현이 아닌 명시된 게임 평가다. UI는 내 선수의 순위와 선정 여부, 자격·경기력 점수·비교 범위만 표시한다.

훈련 제목 옆 **노화**를 누르면 −1/−5/−10 선택이 열린다. 모든 관련 능력치와 OVR의 전후 수치를 확인해 한 번 적용하거나 취소할 수 있다. 능력치 최솟값은 0이고 OVR은 기존 식으로 다시 계산한다. 날짜·선수·강도·전후 능력치를 보관하며 시즌 이력과 한국어 TXT에 남긴다. 단순 열기·닫기·취소와 시즌 전환은 능력치를 감소시키지 않는다. 정상 성장과 부상에 따른 변화, NPC 세계의 선수 교체는 유지한다. 기존 치트의 노화 중지는 사용자 나이 증가를 멈추는 기능으로 유지했다.

구단 전력은 보존된 기본 전력에 완만한 위상 변화와 실제 유급 재투자를 반영한다. 위상 영향은 ±3, 누적 재투자 영향은 최대 +6이며 성적과 지출에 따라 늘고 감가된다. NPC 대체 세대의 OVR 상승이 구단 기본 전력을 덮어쓰지 않는다. 특정 구단 이름으로 우승 보정을 넣지 않았다.

- 새 6시즌 스트레스 검사: 매년 전체 리그·컵·대표팀 진행 → 실제 수상 → 다음 시즌 참가권 → 은퇴 → 저장·가져오기 → TXT. **클럽 경기 원장 361개, 국대 경기 원장 70개**, 실제 통합 출전 389경기. 61,052,673바이트 저장과 6,770,755바이트 TXT를 생성하고 합계를 대조했다. 국대 원장에는 선수가 결장한 팀 경기도 포함된다.
- 동일 시드 8개씩 EPL·라리가·분데스리가 **24시즌** 비교: 맨시티 평균 2.75위·3회 우승, 바르셀로나 2.625위·1회 우승, 뮌헨 2.125위·4회 우승. 전력에 따른 기대 차이와 이변이 함께 남았다.
- 강팀 합류 효과는 별도 동일 시드 8개씩 비교했다. 맨시티: OVR 97 평균 86.75점·1.125위·7회 우승 / OVR 60 평균 82.625점·1.5위·5회 우승. 뮌헨: 83.375점·1.125위·7회 / 76.875점·1.875위·4회. 이 비교에서는 건강·체력을 고정해 능력 차이를 분리했다.

## 이전 데이터와 적용 시점

이전 저장은 원래 해시를 먼저 확인한다. 불러오기·내보내기만으로 과거 결과를 고치거나 컵 경기를 채우지 않는다. 이전 버전에서 진행 중인 시즌은 끝까지 진행한 뒤 **다음 시즌부터** 컵과 확장 대표팀 일정을 적용한다. 현재 연도 컵 원장이 없는 이유를 대회 상세에 표시한다. 새 커리어는 처음부터 새 대회를 편성한다.

대표팀은 기존 원장과 소집 키를 보존하고, 6~7월 본선이 시즌을 넘을 때 같은 경기·소집을 다시 만들지 않는다. 과거의 소집·벤치 사유처럼 보존하지 않은 정보는 추정하지 않는다. 이전 자동 노화의 과거 기록은 남기며 이후 자동 감소만 중단한다. 확장된 실제 기록을 위해 JSON 저장 한도는 256MiB다.

## 제약과 재현

국내 컵의 지원 범위 밖 지역 예선, UEFA 전체 국가의 실제 계수·예선·추첨 제한, 국가별 실제 월드컵 예선 구조, 연장전 30분과 실제 개최일은 완전 재현하지 않는다. 위 표와 게임 내 규칙을 적용한다. 확인 가능한 대회 없이 우승을 보완 생성하지 않는다.

요청서의 UI 참고 URL은 이 환경에서 403으로 접근할 수 없었다. 해당 사이트 원본 소스·화면과의 직접 대조를 완료했다고 주장하지 않는다. 기존 K볼 소스와 첨부 요청서의 원칙을 기준으로 작업했다.

재현 명령:

```sh
npm run build
KBALL_SKIP_LONG_TEST=1 npm test
npx tsx tests/kball-balance-v26.ts
npx tsx tests/kball-career-v26.ts
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e
npm run build:playable
```

다운로드용 HTML은 `KBALL_TEST_URL=http://127.0.0.1:4180/Kball.html`을 지정해 같은 브라우저 검사로 확인한다. 브라우저를 사용한 자동 검사이며 사람의 수동 플레이를 수행했다고 표기하지 않는다. 이 환경의 관리 브라우저는 `file://` 직접 열기를 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단했다. 로컬 파일 직접 실행 검사는 이 제한으로 완료하지 못했으며, ZIP의 동일한 단일 HTML을 HTTP로 제공해 저장·실제 경기·오프라인 자산 독립성을 검증했다.

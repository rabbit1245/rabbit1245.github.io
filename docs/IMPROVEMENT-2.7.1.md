# K볼 2.7.1 · 실제 구단 로고 누락 수정

AZ 알크마르와 NEC 네이메헌의 원인은 각각 `AZ`, `NEC`라는 보관 명단의 약칭과 `AZ_Alkmaar.svg`, `N.E.C._Nijmegen.svg`의 연결 누락이었습니다. 단순히 기본 아이콘을 표시하는 데 그쳤던 부분을 실제 SVG 파일로 교체했습니다. 런타임의 이름 유사도 추측 대신 고정된 구단 ID로 연결합니다.

같은 방식으로 누락 구단을 점검해 실제 로고 **187개**를 추가했습니다. 기존 597개에서 **784개**로 늘었으며, 국내 명단 913개 중 나머지 129개와 별도 국제대회 초청 구단 87개는 아직 중립 아이콘입니다. 전체 로고 적용 완료라고 표시하지 않습니다. 네덜란드 1부 18팀, MLS 29팀, K리그2 13팀, 일본 1부 20팀과 프랑스·이탈리아·브라질·벨기에 1부는 전 구단 SVG가 연결되었습니다.

서울 이랜드와 수원 삼성에는 각각 확보한 실제 엠블럼을 넣었습니다. YSCC 요코하마에 요코하마 FC를 넣거나, Diyarbekirspor에 별개 구단인 Diyarbakırspor를 넣는 식의 유사 명칭 매칭은 금지합니다. 확인하지 못한 리저브팀에 1군 엠블럼을 임의 적용하지 않습니다.

보관 명단의 이름·ID·선수단·전력·경기 결과·성장·저장 구조는 변경하지 않았습니다. 로고는 최신 확보 자료이므로 2024/FC25 보관 명단의 당시 엠블럼을 재현하는 자료는 아닙니다. 기존 정상 로고 파일은 유지했습니다. 다운로드판은 실제 SVG를 HTML 안에 포함하므로 외부 이미지 서버에 접속하지 않아도 표시됩니다.

## 출처와 재현

- SVG 저장소: [JoseArroyave/football-logos](https://github.com/JoseArroyave/football-logos/tree/5ab11fed47427b3003f4b276554491fe683387b1), 고정 리비전 `5ab11fed47427b3003f4b276554491fe683387b1`.
- [추가 구단별 원본 경로·SHA-256](../data/crest-sources.json). 각 SVG 내부의 원본 출처 주석도 유지합니다.
- [전체 913구단 매핑 검사](validation/kball-2.7.1-crests.json). 고정 구단 ID, 카탈로그·매핑 일치, 실제 파일, 원본 파일명과 해시를 검사합니다.
- `python3 scripts/import-verified-crests.py`로 명시된 파일만 다시 가져올 수 있습니다. 전체 응답을 검사한 후 적용하며 새 구단을 유사 명칭으로 자동 추가하지 않습니다.
- 저장소 라이선스와 원본 출처는 [CREST-LICENSE.txt](../public/CREST-LICENSE.txt)에 보관하고 HTML·ZIP에도 포함합니다. 구단 표장 권리는 해당 구단에 있습니다.

## 검증

`npm run build`의 TypeScript 검사와 웹 빌드, `npm run build:playable`, `npm run test:crests`를 사용합니다. 브라우저 검사는 784개 SVG 디코딩, AZ·NEC 시작 구단 선택, 에레디비시 18팀 전체 순위의 실제 이미지, 모바일 레이아웃, 저장 후 재실행을 확인합니다. 다운로드판에서도 같은 검사를 수행하고, 모든 로고의 실제 인라인 포함과 네트워크를 끊은 뒤의 표시를 확인합니다. 상세 결과는 별도 검증 JSON에 기록합니다.

검사 결과: [2.7.1 검증 보고서](validation/kball-2.7.1.json). 웹·다운로드판 각각 784개 이미지 디코딩과 에레디비시 화면·저장 재실행을 통과했고, 기존 버전 저장 통합 검사 4개도 통과했습니다. 다운로드판의 외부 HTTP 이미지·글꼴 요청과 페이지 오류는 0개입니다.

[검증한 2.7.1 ZIP 다운로드](https://github.com/rabbit1245/rabbit1245.github.io/raw/07807726e0c1f4449eba018d7a0b28e8a3f730f0/Kball.zip?download=1). 실제 HTTP 200 응답, ZIP 크기·SHA-256·압축 무결성, 내부 HTML이 검사한 빌드와 같은지 확인했습니다.

# K볼 2.4 · 도움·성장·수상·치트·한국어 기록

골에 비해 도움이 적게 체감되던 배분, 확인하기 어려웠던 시즌 우승·개인상, 너무 일찍 둔화하던 성장과 은퇴 TXT의 원시 데이터 부록을 수정했습니다. 설정에는 능력치 증가와 노화 중지를 직접 선택하는 치트 모드를 추가했습니다.

## 도움

득점과 마지막 패스의 연결을 유지하면서 포지션·시야·패스·크로스·플레이스타일에 따라 마지막 패스의 비중을 배분합니다. 공격형 미드필더·윙어의 창조성을 강화하고 스트라이커의 연계 도움도 유지했습니다. 페널티킥·직접 프리킥에는 도움을 붙이지 않으며, 헤더·일대일·일반 슈팅의 패스 공급 확률을 구별합니다. 한 골에 도움은 최대 하나이고 자기 골에 스스로 도움을 기록하지 않습니다.

같은 능력·팀·시드에서 포지션별 1,000경기를 비교했습니다. 스트라이커 도움은 209→256, 공격형 미드필더는 228→504, 오른쪽 윙어는 257→411, 중앙 미드필더는 227→297이었습니다. 전체 득점 중 도움을 기록한 비율은 약 73%→75%였고, 이 비교의 득점 수는 같았습니다. 특정 선수에게 도움을 보너스로 더하는 방식은 아닙니다.

## 시즌 우승과 내 개인상

라커룸에 `이번 시즌 우승 · 개인 수상`을 표시합니다. 커리어 → 수상·우승에서도 시즌을 선택해 `우승한 대회`와 `내 개인 수상`을 분리해서 확인합니다. 시즌 도중 1위는 우승으로 표시하지 않습니다. 실제 종료 순위·국대 결승·보존된 우승 메달이 근거입니다. 소속팀 우승과 본인의 메달 획득을 구별하며, 오프시즌에 새 구단과 계약해도 방금 마친 시즌의 우승 팀을 바꾸지 않습니다. 개인상은 실제 확정된 수상만 표시합니다.

## 재능과 전성기 성장

| 재능 | 참고 수준 | 새 커리어 잠재력 | 본격 성장 기간 | 노화 시작 |
|---|---|---|---|---|
| S | 손흥민급 | 89~92 | 29세까지 | 32세 |
| SS | 살라·레반도프스키급 | 94~97 | 31세까지 | 34세 |
| SSS | 호날두·메시급 | 98~100 | 32세까지 | 35세 |

골키퍼의 성장·노화 시점은 각각 3년 늦습니다. 해당 연령 이후 성장은 단계적으로 줄어들며, 실제 출전 시간·행동·훈련·환경·남은 잠재력에 따라 다릅니다. 26세부터 경험 성장을 크게 줄이거나 30세 초과라는 이유로 아예 막던 기준을 제거했습니다. 경험은 포지션 핵심과 실제 행동에 더 크게 반영하며, 기본 경기 경험도 누적됩니다.

15→28세, K2, 경기당 85분·평점 7.2·집중 훈련의 고정 실험 6개 시드에서 S는 90·90·90·90·91·92, SSS는 95·96·96·97·96·96이었습니다. 휴식만 한 S는 46이었습니다. 이는 충분히 출전한 조건의 비교이며, 재능 등급만으로 특정 수치나 실제 선수의 기록을 보장하지 않습니다. 기존 저장은 원래 해시를 확인한 뒤 첫 진행의 복사본에서 새 성장 기준과 최소 잠재력 상한을 적용합니다. 과거 능력치·경기·수상은 다시 계산하지 않습니다.

## 치트 모드

상단 공통 메뉴 → 치트 모드를 켭니다. `능력치 편집 열기` 또는 선수 → 능력치에서 증가량 +1·+5·+10을 선택하고 해당 능력치의 + 버튼을 누릅니다. 최대 100이며 종합 능력·잠재력·몸값에 반영합니다. 직접 조정은 일반 훈련·경험과 다른 원인으로 저장합니다.

`노화 중지`를 켜면 나이 증가와 노화에 따른 능력치 하락을 멈추고 시즌은 진행합니다. 마스터 스위치를 끄면 정상 노화를 재개하고 이미 올린 능력치는 유지합니다. 설정과 사용 이력은 해당 커리어에 저장되어 다시 불러와도 유지됩니다. 은퇴한 선수의 기록을 현역으로 되돌리는 기능은 아닙니다.

## 한국어 TXT

`전체 기록 TXT` 한 번으로 받는 파일에서 원시 JSON 부록을 없앴습니다. 통산·시즌별·클럽/국대·대회별 기록, 우승·개인상·주장·계약·몸값·세부 능력치·성장 원인·전체 순위·경기별 모든 개인 지표를 한국어 항목으로 출력합니다. 주발·소집 상태·계약 유형·주장 제의 상태 등도 번역했습니다. 경기 행동과 승부차기 결과도 문장으로 표시합니다. 다시 게임으로 가져오기 위한 JSON 백업 기능은 그대로 유지합니다.

기존 실제 30시즌 저장 81,104,879바이트에서 한국어 TXT 14,084,757바이트를 생성했습니다. 브라우저에서 가져오기·재접속·다운로드 한 번을 검증했고 클럽 1,020경기·국대 108경기의 주요 개인 지표 합계를 원래 저장과 대조했습니다. 모든 시즌 및 수상 이름이 포함되고, 원시 필드가 없으며, 파일은 UTF-8 BOM·CRLF입니다. 브라우저 파일은 같은 입력을 사용한 엔진의 TXT와 바이트 단위로 일치했습니다. 내보내기는 저장을 바꾸지 않습니다.

## 검증

자동 회귀 검사 174개 통과·실패 0개·30시즌 신규 전체 생성 1개 생략. 마지막 직접 조정·수상·도움 분포·한국어 TXT 검사 7개도 통과했습니다. 기존 30시즌 저장을 사용한 TXT 검사는 별도로 실제 브라우저에서 수행했습니다.

프로덕션과 배포용 단일 HTML 양쪽에서 최종 치트 ON/OFF·능력치 +5·노화 중지 저장·재접속을 확인했습니다. 1366×768과 390×844 화면에서 능력치 이름·수치·버튼이 겹치거나 가로로 넘치지 않았고 브라우저 실행 오류도 없었습니다. 단일 HTML은 외부 코드·데이터·이미지 요청 없이 실행됐습니다. 기존 시즌 진행·전체 순위·계약·은퇴·JSON 가져오기·백업 복원 흐름도 브라우저에서 확인했습니다.

화이트·회색 바탕과 절제한 연두 포인트, 시즌 종료 이적, 구단 기본 전력 보존 방식은 유지합니다. 국내 컵·클럽 대륙대회는 새로 추가하지 않았습니다.

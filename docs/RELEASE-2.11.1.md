# K볼 2.11.1 · 개인 기회 배분·시장 위상·장기 저장

## 조사 범위

사용자는 80 OVR 우측 인사이드 포워드의 레알 마드리드 연속 30골, 2,000억 원 평가와 로테이션 재계약의 불일치, 젊은 나이의 몸값 반감, 256MB 상한으로 인한 자동 저장 실패를 제보했다.

첨부한 `K볼_제롬 발렌시아_2038.json`은 업로드 파일을 이 실행 환경으로 옮기는 도구의 **32MiB 전송 제한**에 걸려 내용을 읽지 못했다. 따라서 해당 선수의 30골이 리그/전체 대회 중 어느 합계인지, 실제 세부 능력·출전 시간·가치 이력을 직접 확인했다고 주장하지 않는다. ZIP 압축본을 요청했으며 아래 검수는 별도 실제 커리어와 통제 사례다. 전송 도구의 32MiB 제한과 게임의 기존 256MiB 제한은 서로 다르다.

## 개인 득점과 팀 캐리력

원래 각 선수는 포지션별 기본 슈팅량에 전술 역할·팀 우세·동료의 빌드업·자신의 움직임을 곱해 기회를 독립적으로 받았다. 강팀의 공급 이점은 동료 간 마무리 경쟁을 충분히 구분하지 못했다.

기존 팀 전체의 기대 슈팅 기회를 유지하면서 공격진 안에서 기회를 나눈다. 슈팅·헤더 수행 능력, 위치 선정·침착성·예측·판단이 배분에 영향을 준다. 기존 헤더 비중과 제공권도 평가하며, 수비수의 세트피스 기회는 이 경쟁에서 제외한다. 주인공과 NPC에 같은 규칙을 적용한다. 새 배분으로 기회를 더 받는 선수도 종전 대비 5% 이내로 제한해 기존 고능력 우위에 큰 보너스를 또 얹지 않는다. 이는 **기회 배분의 추가 보정 한도**이며 골 수의 상한이 아니다.

팀 전력·전술·성향·빌드업·수비·구단 성장과 재투자 산식은 유지한다. 실제 슈팅/선방 이벤트부터 결과를 만들고 경기 후 골·도움을 감산하거나 동료에게 득점을 옮기지 않는다. 기존 확정 경기와 수상은 그대로 남는다.

동일한 실제 선수단과 라리가 38경기 일정, 30개 시드에서 비교했다. 아래는 모든 필드 능력치를 해당 값으로 둔 **매 경기 90분 강제 대조**이며 실제 사용자의 기용이나 세부 능력 조합을 재현한 결과가 아니다.

## 실적·수상과 계약 역할

기존 역할 판정은 `선수 OVR - 구단 전력`만 사용했다. 그래서 실제로 많은 골을 넣고 세계 개인상 상위권에 오른 기존 주전도 강팀 전력보다 OVR이 낮다는 이유로 로테이션 제안을 받을 수 있었다.

이제 실제 기량, 포지션 경쟁자 수준, 최근 여러 시즌의 출전량과 포지션별 실적, 세계 수상 순위를 함께 사용한다. 공격수의 압박·연계·수비 기여와 수비수/GK 지표도 구분한다. 충분히 뛴 기존 핵심 선수의 실적은 재계약 역할에 반영하고, 하위 디비전의 실적을 그대로 최상위 리그의 주전 보장으로 바꾸지 않는다. 역할 설명에도 현재 기량과 실전 위상 근거를 표시한다.

80 OVR·레알·리그 30골·3,000분 사례는 주전 이상, 20골·발롱 8위·충분한 출전 사례는 핵심 선수 제안을 확인했다. 이는 산식 검사용 통제 조건이며 제롬 저장을 읽어 재현한 결과가 아니다. 체결한 계약과 이전 계약 원장은 고치지 않고 미확정 구버전 제안은 이적 창을 열 때 한 번 갱신한다. 기존 기량 중심 베테랑 계약 기간과 예산 한도도 유지한다.

## 몸값의 연속성

이전 몸값은 그 시점의 실적과 나이별 유망주 프리미엄을 매번 재계산해 덮어썼다. 전 시즌의 시장 평가를 유지하는 장치가 없고, 시즌 경계·출전 표본·생일·능력치 버튼으로 가격이 급변할 수 있었다. 실제 수상 확정도 몸값 평가보다 늦어 현재 성취가 계약 가치와 어긋났다.

- 최근 최대 3개 시즌의 출전·실적·기여와 이전 돌파 시즌의 근거를 사용한다. 유망주 프리미엄을 생일이나 0경기 개막으로 즉시 지우지 않는다.
- 현재 표시 몸값과 기초 평가액을 구분한다. 새 시즌 경기와 충분한 근거가 생겨야 평가가 점진적으로 이동한다. 같은 시점의 반복 클릭으로 하락이 누적되지 않는다. 미확정 이적 제안 개수가 다시 몸값을 올리던 순환 참조도 제거했다.
- 기량을 유지한 29세 이하 선수의 실적에 따른 하락은 경과 기간에 비례해 연간 약 12% 범위 안에서 반영한다. 새로운 장기 부상과 실제 기량 저하에는 별도 위험 평가가 있다. 마지막 평가 이후 새 경기가 없는 상태에서는 나이·수동 능력치 변경만으로 표시 몸값을 즉시 낮추지 않는다.
- 실제 세계 수상 순위·팀 우승을 현재 시즌 평가와 새 계약에 연결한다. 결산 때 수상을 먼저 확정한 뒤 가치와 제안을 평가하며 수상 계산을 중복 실행하지 않는다.
- 기존 저장을 처음 열 때는 현재 가격과 과거 가격·계약을 유지하고 이후 평가의 기준점을 만든다. 과거 오류로 추정한 가격 이력을 임의로 다시 쓰지 않는다.

21세·80 OVR·잠재력 95·레알·36경기/3,000분/평점 7.6을 둔 통제 사례에서, 종전 평가 2,000억 원에 리그 30골/10도움·발롱 8위·팀 우승 6개 조건을 평가한 가격은 약 1,809억 원이었다. 다음 개막에는 같은 가격을 유지했고, 다음 시즌 같은 기량·출전·평점에서 20골/10도움이면 약 1,645억 원이었다. 재계약은 핵심 역할이었고 새 경기 없는 능력 감소로 표시 가격이 즉시 하락하지 않았다. 실제 시장가의 정답이나 해당 사용자의 커리어 재현이 아닌 게임 평가 모형 검수다.

## 256MB 저장 실패

기존의 256MiB 상한은 JSON 변환·정규 체크섬·가져오기·IndexedDB Blob 읽기·파일 선택에 걸쳐 있었다. 정상적인 상세 기록이 늘어도 이 상한을 넘으면 저장이 거절됐다. 새 게임 데이터가 손상됐다는 뜻과는 구분된다.

이 자원 보호 범위를 **1GiB**로 통일하고, 큰 내부 스냅샷은 원본 JSON을 무손실 gzip으로 압축한다. 모든 기록과 전체 검증·원래 SHA-256 체크섬·변경 원장·백업·충돌 검사를 유지한다. 압축 크기와 실제 확장 크기를 검증하고, 손상된 압축이나 과도한 확장도 거부한다. 기존 무압축 저장도 계속 읽는다.

JSON은 작은 조각으로 만들어 한 번에 큰 문자열을 생성하지 않는다. 파일 가져오기는 File을 Worker에 전달해 읽고, 내보내기는 Worker가 완전히 검증한 일반 JSON Blob을 직접 반환한다. JSON 다운로드를 위해 저장용 압축을 만들었다 다시 푸는 왕복도 하지 않는다. 사용자 파일 형식은 일반 `.json`으로 유지한다.

상한 확장과 압축만 적용한 중간 개발본은 273MB 저장에서 다음 시즌 전반기까지 자동 저장한 후, **296MB JSON 내보내기에서 Chromium renderer가 종료**됐다. 따라서 상한만 늘리는 것으로 해결됐다고 판단하지 않았다. 경기와 저장 Worker가 각각 전체 커리어를 상주 캐시로 보관하고, 내보내기에서 또 전체 사본을 전달하는 경로가 겹쳤다.

장기 커리어의 경기 결과와 큰 저장 작업은 완료된 뒤 해당 Worker를 종료해 상주 사본을 해제한다. 작업 중인 요청은 중단하지 않고 여러 요청이 있으면 모두 완료한 뒤 해제한다. 짧은 커리어의 기존 캐시는 유지한다. 다음 명령은 현재 상태를 다시 전달해 같은 전체 계산을 수행한다. 내보내기는 중복 요청과 경기 진행을 잠그며, 메뉴/커리어 전환 시 사용하지 않는 경기 Worker도 해제한다. 이는 상세 자료나 계산을 생략하는 변경이 아니다.

별도 실제 8시즌 저장에 개발본에서 6시즌을 더 진행한 14시즌 커리어는 **272,717,105바이트**로 기존 상한보다 크다. 내부 저장은 약 19.7MB로 압축됐으며 전체 검증·원래 체크섬·압축 해제·통산 합계·한국어 TXT 대조를 통과했다. 이전 8시즌의 경기·개인 기록·수상과 모든 능력치를 보존했다. 이 자료를 만든 프로세스는 버전 문자열을 올리기 전 시작해 결과 파일에 2.11.0으로 표시되며, 최종 2.11.1 HTML에서 가져오기·재개는 별도로 검사한다.

이는 무제한 저장이나 모든 기기에서 1GiB 처리를 보장하는 뜻이 아니다. 실제 브라우저 메모리와 디스크 공간이 필요하며, 이미 종료돼 저장되지 않은 진행을 복구하는 기능은 아니다. Windows Edge 직접 검수와 Linux Chromium 검수도 구분한다.

## 최종 검수와 다운로드

전체 코어 359개 중 **358개 통과·실패 0·별도로 실행한 30시즌 검사 1개 제외**를 확인했다. 그 뒤 Worker 수명/저장 검사 28개와 마지막 시장 평가·계약·기록·Worker 검사 56개를 통과했다. 중복 검사를 서로 다른 고유 검사처럼 합산하지 않는다. 별도 실제 30시즌 검사도 43세 은퇴·전체 JSON 재가져오기·한국어 TXT·통산 합계를 통과했다.

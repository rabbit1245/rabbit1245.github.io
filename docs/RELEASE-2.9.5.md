# K볼 2.9.5 · 유럽 개인상 9개 보완

앞선 실행 경로 조사에서 누락으로 확인한 개인상 9개를 연결한다. 기존 발롱도르·FIFA·FIFPRO·리그 수상·클럽 대회 MVP는 유지한다. 능력치·팀 전력·경기 시뮬레이션·성향 산식은 변경하지 않는다.

## 추가 항목

| 구분 | 신규 수상 |
| --- | --- |
| 라리가 | 라리가 시즌 최우수 선수 |
| 분데스리가 | 분데스리가 시즌 최우수 선수 |
| 리그 1 | UNFP 리그 1 올해의 선수 |
| UEFA 챔피언스리그 | 득점왕, 시즌 베스트 11 |
| UEFA 유로파리그 | 득점왕, 시즌 베스트 11 |
| UEFA 컨퍼런스리그 | 득점왕, 시즌 베스트 11 |

실존 수상 명칭을 사용하지만 선정은 실제 게임 경기 기록에 따른 평가 모형이다. 실제 기관의 투표·시상 일정·연도별 모든 세부 규정을 재현했다고 표시하지 않는다. [현재 개인상 전체 목록](AWARDS-2.9.5.md).

## 판정과 기록

리그 최우수 선수는 기존 리그 평가 경로에서 해당 리그 기록만 사용한다. 최소 출전은 기존과 같은 `max(5, floor(리그 전체 라운드 × 0.4))`경기이며, 포지션별 실제 기여·평점·출전량·팀 성적·징계와 기존 스타성의 작은 주관 평가 보정을 유지한다. 컵·국가대표 기록은 섞지 않는다.

UEFA 득점왕은 각 대회의 전체 실제 출전 선수 집계에서 최다 득점을 비교한다. 탈락한 팀의 선수도 대상이다. 득점 동률은 공동 수상하며 능력치·스타성·도움·출전 시간으로 공동 득점자를 탈락시키지 않는다. 0골이거나 실제 출전이 없는 선수는 수상하지 않는다. 승부차기 득점은 기존 경기 원장에서 개인 득점에 포함하지 않는다.

UEFA 베스트 11은 대회 내 최다 출전 경기 수의 절반 이상(올림, 최소 2경기)과 90분 이상을 충족한 선수들을 비교한다. 기존 대회 MVP의 출전 기준과 역할별 경기 기여·평점·징계 산식을 재사용한다. GK 1·DF 4·MF 3·FW 3을 구성하고 좌우 풀백·윙어·중앙 공격수 자리를 우선 고려한다. 동일 선수 중복과 기록이 없는 가상 선정을 막으며 11자리를 모두 채울 수 있어야 확정한다. 능력치나 현재 소속팀의 우승 여부만으로 선정하지 않는다.

대회 개인상은 실제 대회 종료 시점에 확정한다. 기존 MVP의 수상 ID를 유지하고 새로운 두 항목에는 대회·시즌·선수별 ID를 사용해 재실행 중복을 막는다. FA·이적 이후에도 수상 소속팀은 해당 대회 선수 집계의 실제 구단을 기록한다. 시즌 수상 화면·시즌 이력·JSON·브라우저 저장·은퇴 TXT의 개인 수상 경로를 그대로 사용한다. 수상 평가 근거에도 신규 항목의 자격과 실제 확정 결과를 표시한다.

기존 저장 형식은 유지하며 과거 확정 경기·순위·수상을 소급 재판정하지 않는다. 이미 완료된 대회에서 이번에 새로 추가된 항목의 확정 기록이 없으면 수상으로 꾸미지 않는다. 진행 중 대회는 업데이트 후 실제 종료할 때부터 적용한다.

## 성능과 기존 기능

대회 선수 원장을 새로 중복 저장하지 않는다. 이미 계산된 대회별 전체 선수 집계를 대회 종료와 시즌 결산에서만 읽고, MVP와 베스트 11의 역할별 정렬도 한 번 공유한다. 리그·세계·클럽 베스트 팀의 포지션 선정 함수를 공통 모듈로 옮기되 기존 자리 선택 규칙을 보존한다. 경기 계산이나 과거 세부 기록을 생략하지 않는다.

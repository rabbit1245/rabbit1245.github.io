# K볼 2.14.1 — 마무리 기술과 정신적 실행력의 관계 보완

슈팅 68·골 결정력 63에 헤딩과 세트피스도 낮은 OVR 100 수비형 미드필더가 프리미어리그·라리가에서 반복적으로 리그 17~19골을 기록한다는 제보를 반영했습니다. 해당 선수의 현재 저장 파일은 받지 않았으므로 정확한 커리어 재현이라고 주장하지 않습니다. 같은 공격 능력과 종합 점수를 가진 여러 통제 선수로 원인을 분리했습니다.

## 확인한 원인과 수정

- 일대일 슈팅의 선방 판정은 골키퍼 능력과 슈터의 침착성만 사용하고 **골 결정력을 사용하지 않았습니다**. 찬스를 많이 포착하는 높은 정신 능력의 선수가 낮은 마무리 기술의 불이익을 충분히 받지 않았습니다.
- 슈팅 정확도와 최종 마무리는 정신 능력을 선형으로 합산했습니다. 기존 100+ 숙련 실행력 보정이 적용된 매우 높은 침착성·판단력이 낮은 슈팅·결정력·헤딩을 과도하게 대체할 수 있었습니다.
- 실제 슈팅·헤더·세트피스 기술을 중심으로 두고 정신 능력은 한계효용이 줄어드는 보조 기여로 계산합니다. 모든 능력의 양의 영향은 유지합니다. 일대일도 실제 마무리와 상대 골키퍼의 능력이 대결합니다. 동일한 단일 능력의 선수·GK는 기존 일대일 기준 확률을 유지합니다.

보조 품질은 `T + 40 × tanh((M - T) / 40) × w`입니다. T는 해당 행동의 실제 기술, M은 정신적 보조 능력, w는 기존 보조 비중입니다. 능력치 자체나 OVR을 깎지 않으며, 정확도·마무리를 판정할 때만 사용합니다. 예를 들어 침착성과 판단력이 매우 높더라도 결정력 63의 마무리를 무제한으로 끌어올리지 않습니다. 슈팅·결정력이 실제로 높은 선수는 계속 우수한 실행력을 갖습니다.

`ability-contests.ts`와 `match-engine.ts`의 마무리 판정만 보완했습니다. 포지션·유형·플레이스킬·OVR 130·성장·선발·수상·계약·팀 전력 및 수비·조율·캐리 산식과 저장 구조는 유지합니다. 개인의 실제 득점이 달라지면 그 차이는 팀 스코어와 수상 근거에도 정상 반영됩니다. 과거 확정 경기·시즌·수상은 다시 계산하지 않고 이후 경기부터 적용합니다.

## 실제 일정으로 대조

게임의 리버풀·레알 명단과 전력, 38경기 리그 일정을 사용해 조건당 20회 대조했습니다. 전 경기 90분, 컨디션을 초기화한 고정 명단 실험으로, 20년 연속 성장한 실제 커리어가 아닙니다. 약한 마무리 선수는 슈팅 68·결정력 63·헤딩 60·세트피스 45·종합 100입니다. 매우 높은 공간 인지·침착성의 영향을 확인하려고 위치 선정·예측력·판단력·침착성·시야에 120 숙련을 준 통제 사례입니다. ‘공격 기술 우수’ 비교는 나머지 조건을 두고 슈팅·결정력 95·헤딩 90으로 바꾸어 종합 103입니다.

## 검수와 실행 시간

- 경기 엔진·전체 능력치 연결·하부리그 득점·정신 능력·4종 행동·신규 5능력치·상한/OVR·저장 원장의 관련 검사 **102개 통과, 실패 0**. [결과](validation/release-2.14.1/targeted.tap). 이번에는 전체 코어와 새 30시즌 커리어 검사를 재실행하지 않았습니다.
- 낮은 마무리 수미와 실제 공격 기술을 높인 수미의 일대일 전환율이 구분되는지, 정신 능력과 기술이 계속 양의 영향을 주는지, 100 초과 구간과 GK 능력의 영향, 골·헤더·세트피스·팀 득점·원장·저장 왕복 일치를 확인했습니다.
- 최종 단독 HTML에서 PC·모바일 ST/GK의 100/120 상한·130 OVR·스킬 삭제/재선택·치트·재접속, 130 선수의 포지션 변경 후 실제 반시즌·자동 저장, 기존 저장의 과거 기록·경제 보존과 한 번만 이관되는 처리를 확인했습니다. [브라우저 결과](validation/release-2.14.1/browser-ui.json).
- TypeScript 검사·프로덕션 빌드·단독 HTML 빌드 통과. 검수는 Linux Chromium의 localhost이며 Windows Edge의 file:// 직접 실행 검사는 환경 정책상 수행하지 않았습니다.
- 800경기×3회 실행의 중앙값은 전 1.480초, 후 1.495초였습니다. 각 실행 구간이 겹치는 작은 차이이며, 속도가 개선되었다거나 다른 기기에서도 같은 시간이 걸린다고 주장하지 않습니다. 기존 2.14.0의 변경분 저장·배경 체크포인트는 유지합니다. [전](validation/release-2.14.1/engine-before.json) · [후](validation/release-2.14.1/engine-after.json).

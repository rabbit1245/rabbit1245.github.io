# 배포 대기 · 은퇴 기록 정리

> 후속 배포 요청에 따라 2.7.3으로 통합했습니다. 현재 최종 검수·배포 상태는 [2.7.3 릴리스 기록](RELEASE-2.7.3.md)을 확인하세요. 아래는 당시 개발 검증 기록입니다.

상태: **로컬 구현·검증, 배포 보류**. 최초 검증은 `2.7.3-dev.1`이며, 현재는 기존 잠금·부상·팀 기여와 성능 개선을 함께 `2.7.3-dev.2`에 보관합니다. 소스·플레이용 브랜치 푸시, 플레이용 HTML·ZIP 생성 및 업로드는 하지 않습니다.

## 출력 항목

- 기본 정보: 이름·국적·신체정보·최종 팀·능력점수·포지션·세부 역할·부 포지션·은퇴나이.
- 통산: 클럽·국대 합산 스탯의 개수·성공률, 팀 수상. 우승뿐 아니라 실제 저장된 준우승 메달 등도 포함합니다.
- 연도별: 소속팀·당시 몸값·주급·능력점수·주장/부주장 여부·부상 유무·팀 수상·대회별 순위/탈락 단계·개인 수상·통합 세부 스탯의 개수와 성공률.
- 결승: 대회·상대·점수·승패·우승/준우승·승부차기 여부와 점수·내 출전 여부와 세부 스탯·내 승부차기 시도/성공. 두 경기로 치른 결승은 각 경기와 합산 점수를 표시합니다. 결승 전 은퇴는 미진행, 결승 미출전은 미출전으로 구분합니다.
- 은퇴 시즌에는 ‘은퇴’를 표시하고 시즌 도중/시즌 종료 후를 구분합니다. 경기를 뛰기 전 은퇴한 시즌도 빠뜨리지 않습니다.

분 단위 행동 로그, 모든 경기/대진/순위표, 훈련·치트·수동 조정 이력, 상업 기록·내부 재투자 계산은 은퇴 화면과 TXT에서 제외합니다. 원본 저장과 경기·성장 계산에 필요한 기록은 보존합니다. 일반 경기 기록 화면은 계속 사용할 수 있습니다.

당시 스냅샷이나 실제 기록이 없으면 현재 값으로 과거를 채우지 않고 ‘과거 기록 미보존’으로 표시합니다. 시도 0회와 분모가 미보존된 성공률을 구분하며, 서로 다른 경기 범위의 성공 횟수와 시도 횟수를 나누지 않습니다. 선수 실제 경기 스탯에 승부차기 득점을 더하지 않습니다.

## 검증

검증 결과와 화면은 [검증 보고서](validation/pending-retirement.json)에 기록합니다. 30시즌 실제 은퇴 저장을 가져오기·자동 저장·새로고침한 뒤 TXT 한 파일 다운로드, 연도별·통산 세부 스탯 원본 대조, 분 단위 문구 제외, 은퇴 표시, PC·모바일 화면을 확인합니다. 결승 승패·승부차기·두 경기 합산·벤치·국대와 과거 미보존 처리 등은 별도 로직 검사로 확인합니다.

플레이용 ZIP은 기존 공개 버전 2.7.2를 유지합니다. 이번 검증은 로컬 웹 빌드 기준이며 새 다운로드판 검증이나 배포를 완료한 것으로 표시하지 않습니다.

결과: 은퇴 기록 로직 12개, 관련 기존 검사 3개, 현역 UI 검사 5항목이 통과했습니다. 실제 30시즌 저장(클럽 경기 원본 1,020개·국대 108개)에서 연도별·통산 모든 보존 스탯을 대조했습니다. TXT는 86,443바이트이며 1회 다운로드, UTF-8 BOM·CRLF, 재실행, 내보내기 전후 슬롯 ID·리비전·검사값 보존을 확인했습니다. 타입 검사·로컬 빌드가 통과했고 공개 ZIP 해시가 유지됨을 확인했습니다. 전체 테스트 일괄 실행과 새 ZIP 검사는 이번 범위에 포함하지 않습니다.

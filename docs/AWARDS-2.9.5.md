# K볼 2.9.5 · 실제 판정되는 개인 수상

현재 실행 경로의 수상 함수에서 확인한 목록이다. 실존 시상 명칭을 쓰는 상도 게임 기록으로 판정하며 실제 기관의 투표를 재현한 결과는 아니다. 명칭만 선언된 목록을 구현 근거로 세지 않았다.

| 범위 | 실제 판정 항목 |
| --- | --- |
| 세계 개인상 | 발롱도르, The Best FIFA 올해의 선수, 야신 트로피, The Best FIFA 올해의 골키퍼, 코파 트로피, 유러피언 골든슈 |
| 세계 베스트 팀 | FIFPRO 월드 11, The Best FIFA Men's 11 |
| 프리미어리그 | 골든 부트, 플레이메이커(최다 도움), 골든 글러브, 시즌의 선수, PFA 올해의 팀 |
| 세리에 A | 득점왕(Capocannoniere), 시즌 MVP, AIC 올해의 팀 |
| 라리가 | 피치치 트로피, **시즌 최우수 선수(신규)**, 언론 선정 리그 베스트 11 |
| 분데스리가 | 득점왕(Torjägerkanone), **시즌 최우수 선수(신규)**, 언론 선정 리그 베스트 11 |
| 리그 1 | 최다득점상, **UNFP 리그 1 올해의 선수(신규)**, 언론 선정 리그 베스트 11 |
| 그 밖의 지원 유럽 리그 | 언론 선정 리그 베스트 11 |
| 챔스·유로파·컨퍼런스 | 시즌의 선수(MVP), **득점왕·시즌 베스트 11(각 대회 신규)** |
| 그 밖의 지원 클럽 대륙대회 | 해당 대회 시즌의 선수(MVP) |
| FIFA 클럽 월드컵 | 골든볼 |
| 유로 본선 | 득점왕, 대회 최우수 선수 |
| 월드컵·U20 월드컵 | 골든 부트, 골든 볼, 골든 글러브 |

유러피언 골든슈는 지원 유럽 1부의 정규리그 득점×계수로만 판정한다. 득점왕·도움왕·무실점상 같은 기록 상은 스타성이나 OVR로 순위를 바꾸지 않는다. 리그 1 득점 동률의 세부 공식 기준에 필요한 데이터가 없으면 수상을 확정하지 않는 기존 처리도 유지한다.

별도 클럽·언론 평가 모형으로 구단 올해의 선수, 팬 선정 선수, 선수단 선정 선수, 유망주, 올해의 영입, 포지션별 선수, 해결사, 리그 이달의 선수·유망주, 리그 올해의 유망주·신인·영입, 국내 컵 MVP, 국가대표 올해의 선수를 판정한다. 자격·실제 출전·경기 기록이 필요하다. 유니폼 판매 예상 1위는 개인 경기상과 구분하는 상업적 추정 항목이다.

2.9.5에서 이전 목록의 누락 9개를 실제 판정 경로에 추가했다. UEFA 클럽 득점왕은 대회별 실제 득점만 비교하고 동률이면 공동 수상한다. 베스트 11은 해당 대회 최소 출전·역할별 기여·평점·징계를 비교하며 GK 1·DF 4·MF 3·FW 3을 모두 채워야 선정한다. 리그·다른 컵·국가대표·승부차기 기록은 섞지 않는다. 유로의 별도 최우수 골키퍼는 기존과 같이 판정하지 않는다.

# K볼 2.9.0

2026-10-26 · 이적·FA·수동 부상·성장과 은퇴 기록 개선.

## 이적과 FA

제안 팀명 바로 아래에 실제 소속 리그와 국가를 표시한다. 다음 시즌 승강이 확정된 제안은 목적 리그를 표시한다. 주급 산식에서 일률적인 `현재 주급×0.9`를 없앴다. 종전 급여를 감당할 수 있는 구단을 우선 검토하고, 현재 급여·역할·포지션 수요·시장 평가를 반영해 통상 유지·인상 제안을 한다. 고령에 실제 기량과 최근 성적이 하락한 후보 자원, 또는 구단 급여 한도가 부족한 예외에는 감액 사유를 명시한다. 구단 예산 검증은 유지한다.

계약이 끝났는데 새 계약을 맺지 않으면 시즌 결산을 보존한 후 FA가 된다. 현재 유효 계약이 있으면 재계약 없이 그대로 진행한다. 이적창의 **직접 계약 해지 · FA 전환**은 시즌 중에도 사용할 수 있다. 클럽 명단에서 실제로 빠지고 주급·클럽 출전이 중단되며, 나머지 구단의 경기·순위·대회는 정상 진행한다. FA도 반 시즌씩 진행하며 전·후반기 시작에 제안을 갱신하고 이적료 없이 즉시 합류할 수 있다. 소속 선수의 일반 이적은 종전처럼 시즌 종료에 결정한다.

서로 다른 리그의 실제 진행 라운드를 이어받아 새 팀 합류 전에 끝난 경기를 재경기하지 않는다. 시즌 중 FA 제안은 같은 시즌 시작 달력을 쓰는 리그에서 편성하며, 시즌 종료 계약은 기존 달력 전환을 유지한다. 지난 팀의 경기·통계·최종 순위와 이력은 지우지 않는다. 리그별 득점·도움·수상·골든슈 계수는 실제 대회 원장으로 분리하고, 이전 팀의 리그·컵 우승에도 실제 참여 기준에 맞는 메달을 보존한다. 같은 해 서로 다른 리그의 수상 ID도 구별한다. 소속 기간은 `employment` 원장에 작게 보존하고 은퇴 화면과 TXT에 FA 전반기·후반기를 나누어 표시한다. 0경기 FA 시즌도 기록한다.

## 훈련·110 상한·능력치 유지

환경설정에서 치트를 켜면 훈련 탭 **노화 왼쪽**에 치트 버튼이 나타난다. `+1 / +5 / +10`을 고른 뒤 능력치를 누르면 해당 수치만 증가한다. 잠금·모드 OFF·은퇴·개별 상한은 엔진에서도 검증한다. 일반 능력치 100, 해당 플레이스킬 선택 능력치 110을 적용한다.

기존 110 상한 자체는 존재했지만, 초과 숙련의 작은 성장분을 매번 소수 둘째 자리에서 반올림하면서 100 근처에서 성장이 0이 되는 경로가 있었다. 원인별 소수 잔여를 누적해 이 손실을 없앴다. 체크한 항목만 성장하는 규칙과 훈련 0개·잠금은 유지한다. 작은 성장분과 상한 110은 화면에서도 확인할 수 있다. 실제 능력·OVR·경기 판정·세이브의 110/120 범위를 유지한다.

자동 노화는 이미 비활성화였지만, 장기 부상 중 체력·속도/GK 능력을 소수점씩 낮추는 별도 코드가 남아 있었다. 이 자동 감소를 제거했다. 부상은 출전·훈련량에 영향을 주고 능력치를 자동으로 깎지 않는다. 직접 누른 수동 노화만 감소시킨다. 플레이스킬 삭제 시 100 초과 숙련을 종료하는 기존의 명시적 조정은 유지하며 이력도 보존한다. 과거 저장의 이미 기록된 감소는 소급 조작하지 않는다.

## 라커룸 부상 선택

부상을 훈련창에서 라커룸으로 옮겼다. 전·후반기 시작 전에 **5·10·20경기 / 한 시즌**을 선택하며, 오프시즌에는 다음 시즌을 예약한다. 선택 자체가 시즌을 즉시 건너뛰지 않고, 평소 전·후반기 진행으로 실제 팀 경기를 계산한다.

횟수는 **실제 클럽 경기 기준**이고 그 기간 국대도 부상으로 출전하지 않는다. 리그·컵의 실제 클럽 결장을 하나씩 차감하며 5경기 선택이 한 라운드에 겹친 컵 경기 때문에 6경기로 늘어나지 않게 경기 사이에 동기화한다. 한 시즌 선택은 그 시즌의 남은 전체 경기다. 남은 일정이 선택 수보다 적으면 시즌 종료에 복귀하고 실제 결장 수를 기록한다. 다음 시즌으로 숫자를 허위 이월하지 않는다. 기존 182/365일 방식의 부상 저장은 원래 기간과 복귀·결장 원장을 유지한다.

라커룸과 은퇴 화면·TXT에 실제 클럽/국대 결장 수, 시즌 전체 부상 여부를 기록한다. 수동 부상은 능력치 잠금 중에도 작동한다. 지난 시즌의 부상 기록을 매 경기 다시 정렬하지 않고 현재 관련 경기만 재사용한다.

## 로고·국적·은퇴 스킬 설명

구단 로고 **72개**를 추가·연결했다. 국내 913개 중 **856개 표시 / 57개 미확보**다. FCLOGO의 구단명·실제 버전이 맞는 SVG, 일부 과거 Flat UI 구단 배지, 검토한 실제 모구단 공용 리저브 엠블럼을 사용한다. 다른 구단을 유사 철자로 매칭하지 않는다. 파일·출처·공유 모구단·해시를 `data/crest-additions-2.9.0.json`에 고정하고 다운로드 HTML 안에도 포함한다. 카펠런·니노버 등 남은 57개는 구단이 확인된 파일을 확보하지 못해 중립 아이콘을 유지한다. 전부 해결됐다고 표시하지 않는다.

국적 목록 위에 검색을 추가했다. 예를 들어 `포르`로 목록을 좁혀 포르투갈을 선택할 수 있고, 선택한 국적은 검색어가 바뀌어도 유지된다.

은퇴 화면과 TXT의 연도별 스킬은 **엔진(체력 스페셜리스트)**, **스나이퍼(슈팅 스페셜리스트)**처럼 해당 전문 능력을 함께 표시한다. 저장 ID를 바꾸지 않아 기존 저장에도 표시된다. 획득한 연도부터 나타나고 삭제한 연도부터 빠지며 과거 연도는 보존한다. 통산 기본 정보에는 스킬 목록을 넣지 않는다.

## 검수·배포

검증 원문과 다운로드 해시는 `docs/validation/release-2.9.0.json`에 기록한다. 타입·웹/단일 HTML 빌드와 기존 CAREER24 검사를 포함한다. 기존 20/30시즌 저장은 원본 경기·수상·집계를 유지하며 불러오고, 브라우저 TXT를 현재 엔진 출력과 대조한다. 직접 Windows Edge의 `file://` 실행을 측정할 수 없는 관리 환경이므로 동일 HTML을 localhost에서 전달하고 오프라인·Blob Worker·저장·재실행을 검증한다.

- 전체 자동 회귀 **265개 통과·실패 0·1개 생략**. 새 30시즌 생성 대신 보관된 20·30시즌 실제 저장의 불러오기·재실행·전체 통계·TXT를 대조했다.
- FA 해지·계약 만료·반 시즌 진행·재계약·이전 경기 보존, 5/10/20/시즌 부상, 100 초과 미세 성장과 자동 감소 없음, 리그 이동 시 득점·수상·계수 분리를 검증했다.
- 단일 HTML 전체 플레이 11항목과 새 UI 웹·오프라인 단일 HTML 각 6항목 통과. 신규 화면에서 브라우저 오류 0건. 1366×768 훈련 전체와 확정 버튼, 모바일 화면 넘침·기록 다운로드를 확인했다.
- 기존 30시즌 저장 81,104,879바이트의 TXT 86,425바이트, 20시즌 저장 130,888,698바이트의 TXT 92,084바이트가 현재 엔진 출력과 바이트 단위로 일치한다. 20시즌 스킬 전문 능력 설명도 반영하며 전체 기록·합계·성공률·결승을 보존한다. TXT 다운로드는 저장 ID·리비전·해시를 바꾸지 않고 한 번만 발생한다.
- 856개 로고를 브라우저에서 디코딩해 누락·실패가 없음을 확인했다. 새 회색·초록 글자 조합의 대비도 점검했다.

# K볼 2.8.0

2026-10-25. 사용자 요청에 따라 기존 배포 보류를 해제하고 플레이스타일·OVR·경기·저장·수상·은퇴 기록 개선을 통합한다. 최종 배포 주소와 검수 결과는 아래에 기록한다.

## 플레이스타일과 실제 성장

훈련창 하단에 기본적으로 접힌 플레이스타일을 추가했다. 필드 20개·GK 10개를 해당 능력치에 연결하며, 기존 포지션별 전술 역할 `player.style`는 유지한다. 새 선택은 별도 `player.playSkills`에 저장하고 최대 5개를 UI·명령·저장에서 검증한다. 판단력·집중력은 문맥별 이름을 공유하므로 실제 고유 능력치 키는 28개다.

선택은 개별 성장 상한을 100→110으로 해제할 뿐, 능력치·OVR·경기력을 즉시 올리지 않는다. 시즌 훈련은 기존 최대 3개이고 체크한 항목만 성장한다. 0개 훈련도 가능하다. 잠금은 자동 성장·부상 저하·치트 변동을 차단하고, 명시적 수동 노화와 스킬 삭제는 허용한다. 자연 노화 감소는 추가하지 않았다.

스킬은 현역 중 언제든 삭제할 수 있다. 100 초과 숙련을 삭제하면 현재 능력치는 100으로 조정하고, 조정 전후 값을 변경 이력과 성장 원장에 보존한다. 과거 시즌의 능력치·경기·수상은 수정하지 않는다. 다시 선택해도 이전 초과 수치나 OVR을 즉시 돌려주지 않는다. 5개 초과·선택과 초과 능력치 불일치 저장은 원본을 자동 절삭하지 않고 오류와 복구 필요를 안내한다. 기존 정식판에는 이 신규 선택 배열이 없으므로 기존 저장은 0개 선택으로 호환된다.

주요 코드: `play-skills.ts`, `attributes.ts`, `growth.ts`, `engine.ts:setPlaySkill`, `play-skill-validation.ts`, `PlaySkills.tsx`, `TrainingPanel.tsx`.

## OVR 산식과 경기 판정

```text
B = Σ 기존 포지션·전술 가중치 × clamp(세부 능력치, 1, 100)
R_i = min(1, 해당 능력치 가중치 / 다섯 번째로 큰 가중치)
M = Σ [선택한 실제 능력치의 clamp((값 - 100) / 10, 0, 1) × R_i] / 5
OVR = round(min(120, 100 + 4×선택 개수, B + (120-B)×M))
```

핵심 5개의 중요도는 1이다. 5개가 실제 110까지 성장하면 나머지 능력치를 몰래 올리지 않고 OVR 120을 얻는다. 개수별 상한은 100/104/108/112/116/120이다. 100 초과 성장분이 없는 스킬을 추가·재선택해도 기존 숙련이 희석되거나 OVR이 즉시 바뀌지 않는다. 모든 세부 능력치의 기존 포지션 가중치를 기본값에 보존한다.

기본 잠재력과 초과 숙련 성장을 분리했다. 표시 OVR이 100을 넘어도 체크한 능력치가 초과 숙련을 계속 개발할 수 있으며, 일반 성장의 잠재력 판단은 기본 OVR로 한다. 재능·나이·출전·훈련 환경·부상·선택 여부에 따른 속도 차이는 유지한다. S 재능의 새 기본 잠재력 기준은 85~89이며, 기존 저장의 지난 능력치·잠재력은 소급 삭감하지 않는다.

표시 OVR의 초과 환산을 별도 승률 가점으로 넣지 않는다. 팀 전력·선발·국대·주장 비교는 실제 능력 척도를 사용하고 경기 행동은 실제 세부 능력치 110까지 반영한다. 없는 GK 필드 능력치의 대체값도 표시 120을 복사하지 않는다. 성공 확률 상한과 체력·리더십의 0~100 범위는 별도로 유지한다. 구단 기본 전력 보존·경기별 실제 득점·전체 순위·승무패·대회 계산은 유지한다.

0~120 선수 수준표는 24행이며 모든 정수 구간을 한 번만 포함한다. 각 행은 예시 5개이며, 95~99는 공격·수비·GK를 함께 보여주는 5명으로 정리했다. 실명은 전성기를 비교한 주관적 게임 예시이고, 110 이상·하위 구간의 가상 역할 예시는 선수 데이터로 생성하지 않는다.

## 수상과 특별한 성취 평가

발롱도르·FIFPRO 월드 11에 FIFA 올해의 선수, FIFA Men's 11, 야신 트로피, FIFA 올해의 골키퍼, 코파 트로피, 유러피언 골든슈를 별도 ID·주최·자격·평가 결과로 연결했다. FIFA Men's 11과 FIFPRO는 별도 선정이다. 국내 리그·컵·국대의 기존 기록과 시상도 유지한다.

발롱도르는 개인 성과 50·팀 성과 30·능력 20의 모형으로 정규화하고, 상별로 비중을 달리한다. 실제 출전량·역할별 성과·징계·리그 수준·우승 기여를 반영한다. 개인 점수에 포함됐던 팀 승점 부분은 별도 팀 평가와 중복하지 않는다. 국가대표 우승은 실제 본선 원장의 개인 출전 기여로만 인정한다. 수비수·GK는 역할별 지표로 비교하며, 높은 OVR만으로 수상을 보장하지 않는다.

골든슈는 지원 유럽 국내 최상위 리그의 실제 정규리그 득점×계수만 비교한다. 컵·국대·승부차기 득점, 능력·특별한 성취 가점은 순위에 넣지 않는다. 동점은 적은 출전 시간, 완전 동률은 공동 선정으로 처리하는 모형이다. 지원 상위 5리그 계수 2, 나머지 지원 유럽 리그 1.5를 사용하며 미래 실제 협회 순위 변화까지 검증한 규정이라고 주장하지 않는다.

언더독 우승·실제 승격 이력·약체 UCL 우승·노장 활약·부상 복귀·관측된 무관 종결·국대 이변·장기 소속과 성취·결승 활약·관측된 기록 경신은 실제 보존 자료가 있을 때만 제한적으로 평가한다. 최소 실적과 근접 경쟁 기준이 있으며 총 +10, 같은 우승 서사는 감경한다. 기록이 없는 과거 무관 기간이나 역사적 기록을 만들어 내지 않는다. 이 내부 평가의 문구·점수는 은퇴 UI·TXT에 출력하지 않는다.

추가 데이터는 현재 시즌 시작 전력·예상 순위, 관측 시작 연도·최근 우승, 기존 최고 기록, 부상 요약, 본선 시작 전력 등이다. 시즌 종료에 한 번 평가하고, 우승 기여·결승 근거는 한 번 색인해 재사용한다. 모든 NPC에게 세부 능력치 배열을 추가하거나 매 화면 렌더에서 과거 경기를 재계산하지 않는다.

공식 명칭을 사용하는 결과도 **게임 경기 기록으로 산정한 모형**이다. France Football·FIFA·FIFPRO의 실제 투표 결과나 모든 연도의 공식 평가 기간을 재현했다고 표시하지 않는다. 코파 나이는 생일 자료가 없는 게임의 시즌 연령 기준이며, 미래 규정은 실제 검증된 규정과 구별한다. 첨부 공식 링크의 이번 환경 접근은 403으로 막혀 연도별 원문 규정 확인은 완료하지 못했다. 기타 평가는 언론·클럽·팬 등 주체와 모형 여부를 표시한다. 과거 원본 ID·결과는 유지하면서 예전 자체 선정 명칭은 표시 단계에서 정리한다.

국제대회에서 실제 뛴 초청 구단의 가상 선수도 후보가 될 수 있다. 저장은 정적 초청 명단의 ID·구단·포지션·이름을 검증해 허용하며 임의로 조작한 신원은 거부한다. 이 경우 저장이 막히던 경로를 실제 실패 시드로 재현해 수정했다.

## 은퇴 기록과 저장·성능

플레이스타일은 획득한 시즌부터 연도별 기록에만 표시한다. 삭제한 시즌부터 제외하고, 이전 시즌은 보존한다. 시즌 종료 후 변경은 다음 시즌부터 반영한다. 통산 기본 정보에는 새 스킬 목록이나 능력점수를 추가하지 않는다. 개인상은 본인의 후보·순위·수상 결과를 남기고 가상 후보 전체 목록은 새로 출력하지 않는다. 분 단위 로그·내부 평가 이력은 은퇴 문서에 출력하지 않으며 원본 JSON 원장은 유지한다.

기존 Blob 저장·작은 변경 저널·체크섬·직전 백업·배경 Worker 합치기를 유지했다. 스킬 선택은 경량 명령 경로를 사용한다. 선택·삭제·시즌 전환·재실행·JSON 내보내기에서 현재 선택과 연도별 변경 이력을 함께 검증한다. 110 세부 능력치와 120 OVR은 경기 참여자·성장 원장·연도별 상세·수동 조정·주장 평가 등 저장 범위를 함께 확장했다.

앞서 미배포였던 국대 척도·26인 선발·누락된 국적·세리에 A 수상·팀 장기 재투자와 통산 기본 OVR 제외도 통합한다. 이전의 경기·대회·세부 기록·로고·원화 표시 기능을 줄이지 않았다.

## 검수와 배포

검증 결과와 최종 ZIP 해시는 [검증 종합](validation/release-2.8.0.json)에 기록한다. 관리형 브라우저는 직접 `file://` 이동을 차단하므로 단일 HTML은 같은 파일을 localhost로 전달하고 오프라인·Blob Worker·저장·재실행을 검사한다. 실제 Windows Edge의 로컬 파일 실행을 직접 측정한 결과와 구별한다.

- 자동 회귀 **253개 통과·실패 0**, 이전 형식의 새 30시즌 생성 1항목은 생략하고 이번 기능을 포함한 새 20시즌 전체 진행으로 대체했다. 마지막 110 범위·GK·성장·정신 능력 저장 검사 45개와 국제 초청 선수·저장 검사도 통과했다.
- 필드 16개 포지션·기존 전술 160조합의 상한을 확인하고, 모든 포지션에서 실제 훈련·경험 함수로 120까지 성장했다. 이 테스트는 출전을 통제한 성장 검사다. 별도로 실제 세계·리그·컵·국대 전체를 치트·강제 결과 없이 20시즌 진행해 **33세에 120**에 도달했다. 삭제 2036~2037시즌은 스킬이 빠지고 2038 재획득부터 다시 표시된다.
- 포지션·OVR별 같은 240시드, 합계 **5,760경기**를 비교했다. 120은 90보다 역할별 주요 실제 기록이 높으며 한 선수로 승리가 보장되지 않는다. 골·수비·선방·기회 생성의 효과를 함께 확인했다.
- 웹·단일 HTML 전체 플레이 **각 11항목**, 신규 스킬·잠금·재선택·GK·모바일·오프라인 검사 통과. 낮은 PC 화면에서도 기존 훈련 20개와 확정 버튼·접힌 스킬 영역을 표시한다. 새 스킬 색 조합의 최소 대비는 **5.224:1**이다.
- 새 20시즌 **130,888,698바이트** 저장의 클럽 1,137경기·국대 209경기를 보존했다. **89,038바이트 TXT**가 브라우저 다운로드와 바이트 단위로 같으며 모든 연도·통산 세부 스탯·성공률·결승·수상을 대조했다. 스킬의 연도별 획득·삭제·재획득, 통산 제외·낭만 문구 제외도 실제 은퇴 화면에서 확인했다.
- 기존 30시즌 **81,104,879바이트** 저장도 가져오기·재실행·전체 기록 대조·**86,425바이트 TXT** 다운로드를 통과했다. TXT 다운로드는 저장 ID·리비전·체크섬을 바꾸지 않고 한 번만 발생한다.
- 20시즌 단일 HTML에서 스킬 변경 20회의 저장 완료는 중앙값 **198.25ms**, 최대 **271.95ms**였다. 재실행 후 선택과 변경 이력을 복원하고 전체 과거 시즌의 SHA-256이 동일함을 확인했다. 다른 검사와 함께 실행한 환경의 측정이며 실제 Windows Edge 로컬 파일의 확정 속도나 이전 버전과의 통제 비교로 해석하지 않는다.

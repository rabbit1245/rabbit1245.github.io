# K볼 2.9.2

FA 선수가 국가대표로 뛴 뒤 자동 저장이 실패하던 오류와, 능력치를 유지한 베테랑이 1년 계약만 받고 계약 만료 때마다 기존 팀의 제안을 잃던 문제를 수정한다.

## 확인한 원인

국대 경기 명단은 `teamId`에 출전 국가, `clubId`에 당시 클럽 소속을 각각 보관한다. FA 선수의 `clubId: 'FA'`는 올바른 과거 기록이지만 저장 검사가 이를 실존 클럽 ID로만 제한했다. 따라서 현재 경기뿐 아니라 `national.history.matches[…].performer.clubId`가 포함된 과거 시즌도 저장·가져오기 검사에서 막혔다.

계약 생성은 32세부터 능력·활약과 무관하게 항상 1년을 제시했다. 시즌 종료 시 계약이 만료되면 먼저 FA로 전환한 다음 제안을 생성했으므로, 기존 클럽의 재계약 제안도 사라졌다. 나이가 선수 방출 조건인 것은 아니었지만 두 동작이 결합해 고령 선수가 매년 팀을 떠나게 만들었다.

수정 전 재현 검사에서 FA 국대 저장 거부, 32세 기량 유지 선수의 1년 제한, 계약 만료 후 전 소속팀 제안 누락을 각각 확인했다.

## 변경

- 국대 경기 선수의 당시 클럽 소속에 FA를 허용한다. 현재·과거 국대 경기와 다른 국가의 경기에도 동일 검사를 사용한다. 국가대표 출전 팀, 스코어·득점 원장·선수 기록, 알려지지 않은 클럽 ID 검증은 유지한다. 과거 FA 기록을 새 팀 소속으로 덮어쓰지 않는다.
- 현재 기량, 이전 2시즌의 기량, 실제 출전·평점, 제안 팀의 핵심·주전·후보 역할을 계약 기간에 반영한다. 기량을 유지한 주전은 32세 이후에도 보통 2~3년 계약을 받는다. 실제 기량 하락과 부진, 제한적인 후보 역할은 단기 계약의 근거가 될 수 있다.
- 계약 만료는 자연스럽게 FA가 된다. 같은 시즌 종료 시장에 전 소속팀 제안을 별도로 남겨 선택할 수 있게 한다. 자발적 계약 해지에 재계약을 보장하지 않으며, 제안을 수락하지 않고 무소속으로 계속 진행할 수 있다. 구단 급여 예산 검사는 유지한다.
- FA에서 전 소속팀으로 돌아오면 화면에는 `전 소속팀 재계약`으로 표시한다. 원장에는 실제 `FA → 전 소속팀`의 이적료 0 재입단을 남겨 계약·이적 기록을 일치시킨다.
- 기존 저장의 미수락 계약은 계약 창을 열 때 한 번 새 기준으로 갱신한다. 갱신은 별도 명령으로 저장하며 체크섬 검증 전 원본을 변경하지 않는다. 체결한 계약, 과거 경기·시즌·수상 기록에는 소급 적용하지 않는다. 같은 상태의 제안 재검토는 결정적이어서 다시 열기로 조건을 뽑지 않는다.

## 검증

- FA의 실제 국대 출전 → 시즌 기록 보존 → IndexedDB 저장·불러오기 → JSON 내보내기·가져오기 → 새 클럽 계약 이후 과거 FA 기록 보존.
- 현재 국대 경기와 과거 국대 기록 각각 검사. 존재하지 않는 클럽 ID와 FA를 경기 참가 팀으로 바꾼 데이터는 계속 거부.
- 32·35·38·42세의 기량 유지 선수에게 다년 계약, 실제 기량 하락·부진 사례의 단기 계약, 자발적 FA의 별도 처리.
- 실제 시즌 계약 만료 → FA 유지 또는 전 소속팀 재입단 → 다음 시즌 출전·시즌 종료 → 잔여 계약 기간과 저장 원장 일치.

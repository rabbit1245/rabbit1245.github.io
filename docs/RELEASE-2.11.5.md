# K볼 2.11.5 · 100+ 숙련 연동·국대 활동 선택·큰 경기 기여

## 조사 범위

사용자는 이사기 요이치가 능력 108에도 은퇴까지 발롱도르를 받지 못했고, 40세에는 2부에서 벤치가 많았다고 제보했다. 판단력 중심 선수의 실전 반영과 승부사 효과, 국대 소집 거절·은퇴 설정도 요청했다.

**첨부 `K볼_이사기 요이치_2050.json`은 파일 전송 도구의 32MiB 제한으로 내려받지 못했다.** 게임의 저장 한도와 별개이며 ZIP 재첨부가 필요하다. 실제 저장의 능력 배분·피로·폼·선발 경쟁자·연도별 수상 후보·실행 버전은 아직 직접 대조하지 못했다. 아래 자료는 코드 조사와 별도 통제 선수/새 실제 시즌의 결과다. 이사기의 실제 커리어를 읽거나 재현한 결과로 표현하지 않는다.

## 1. 100+ 능력과 수상 평가

`overall`은 실제 100 초과 숙련을 0~120 OVR에 반영하지만, `playingAbility`는 능력치가 하나라도 100을 넘으면 표시 OVR을 쓰지 않고 별도의 가중 평균으로 되돌아갔다. 이 값은 선발·세계 구단 전력·국대 경쟁·계약 위상 등 여러 경로에서 사용됐다. 동일 선수의 화면과 실전 비교 척도가 달랐다.

독립 통제 ST는 피지컬/기술 65, 위치 선정·예측·판단·침착·시야 110, 집중·팀워크 100, 실제 습득 스킬 5개로 계산 OVR **108**이다. 구판은 이 선수를 비교 평가에서 **83.7113**으로 읽었다. 새 코드는 이미 얻은 100+ 숙련 OVR을 비교 평가에도 인식한다. OVR 산식·스킬 선택/성장 상한·선택만으로 점수를 주지 않는 규칙은 유지한다. 슈팅·드리블·속도·패스 등 개별 판정은 실제 개별 능력치를 계속 사용한다.

수상 쪽에는 별도의 포화도 있었다. 2.11.4의 역할 평가에서 행동 채널을 2.5, 상대 기여를 2.2에서 잘랐고, 10점으로 제한된 경기 평점에서 득점·도움의 선형 기여를 계속 빼고 있었다. 매우 높은 실제 성과를 구분하지 못하고 높은 득점이 배경 평점 비교를 과하게 낮출 수 있었다.

- 실제 역할의 큰 기여는 종전 기준 구간을 유지하고 그 이상에서 `log1p`의 완만한 증가를 적용한다.
- 원래 포지션 동료 대비 특이성 보정은 기존 2.2 한도를 유지한다. 희귀한 조합이라는 이유만으로 점수가 무한히 커지지 않는다.
- 평점에서 분리하는 직접 득점·도움 성분은 제한된 평점 척도에 맞게 `tanh`로 압축한다. 실제 득점과 도움은 원래 행동 채널에서 계속 평가한다.
- 수비·압박/창조·전진/마무리 비교, 실제 포지션으로 구성하는 XI, 출전·대회·리그 수준·징계·성과 근거와 모든 NPC에 같은 식을 적용하는 규칙은 유지한다. 헤더 득점은 전체 득점의 하위 기록으로 유지한다.

## 2. 40세 선수의 출전

현행 클럽 선발식에서는 나이를 이유로 출전 확률을 직접 낮추는 분기를 확인하지 못했다. 실제 능력 비교·포지션 경쟁자·신뢰·폼·부상·피로가 작동한다. 위의 100+ 비교 점수 불일치는 나이와 관계없이 출전에 불리할 수 있었다. 이 경로를 바로잡고, 능력·몸 상태가 같을 때 27세와 40세의 선발·경기 결과가 같은지 회귀 검사를 추가했다.

별도 동일 조건 매치 대조 6쌍은 수정 전후 모두 나이만 27→40으로 바꿨을 때 전체 결과 해시가 같았다. 이 대조는 동일 연도의 같은 선수단·능력·조건·시드이며, 수십 년의 세계 변화를 재현한 검사는 아니다.

독립 실제 40세·세군다 시즌에서는 구판도 42경기 선발·38골을 기록했고, 새 경기 판정은 42경기 선발·60골을 기록했다. **사용자의 “40세라서 대부분 벤치·10골 미만”을 이 대조로 재현하지 못했다.** 첨부 저장을 읽지 못한 상태에서 해당 벤치 원인을 나이라고 확정하거나 사용자 저장에서 해결했다고 주장하지 않는다. 실제 파일의 경쟁 구단 전력·피로·폼·개별 능력·진행 버전 대조가 남아 있다.

## 3. 판단력 중심 선수의 실제 행동

기존 슈팅 기회는 위치 선정·예측·판단과 속도·드리블·볼 컨트롤을 한 평균으로 묶었다. 볼 없이 공간을 읽는 선수도 드리블 약점 때문에 그 경로의 기회까지 낮아졌다.

이제 공간을 읽는 오프더볼 경로와 볼을 가지고 돌파하는 경로를 구분해 한 슈팅 기회에 더 적합한 경로를 사용한다. 실제 시야·판단·예측·위치 선정이 팀과 상대의 통상 수준을 넘으면 찬스 공급과 실제 일대일 상황 선택에도 반영한다. 추가 인지 보정은 95 이상에서 양 팀의 정상 수준도 넘는 탁월한 읽기 능력에 적용한다. 실제 패스·공중볼·슈팅 성공은 각 기술과 상대 판정을 유지한다.

조건별 240경기의 독립 매치 대조에서, 85 수준 상대의 위 108 두뇌형 ST는 선발 173→237회, 득점 82→177, 도움 20→39였다. 조건별 피로·폼을 매번 초기화했으므로 실제 커리어 시즌 성적으로 환산하지 않는다. 같은 대조의 균형 90 선수는 선발 230회·140골·32도움이었고 수정 전후 매치 전체 해시가 같았다. 두뇌형의 드리블 성공은 균형 90보다 낮게 남아 있어 개별 약점도 유지한다. 65/85 상대 및 27/40세의 일반 90 선수 네 조건은 모두 전체 매치 해시가 같았다.

## 4. 국대 소집 거절·국대 은퇴

부상 버튼 옆에 두 체크박스를 배치했다. 체크 중에는 실제 대표팀 후보 명단에서 제외하고, 이미 진행 중인 소집도 다음 실제 경기에서 출전하지 않도록 확인한다. 두 항목이 모두 해제되면 다음 소집 평가에 다시 참가한다. 두 항목이 함께 켜져 있으면 은퇴 상태를 우선 표시하며, 은퇴만 해제해도 소집 거절이 남아 있으면 불참을 유지한다.

국가대표의 전체 일정·나라별 경기·선발 경쟁은 계속 진행한다. 과거 결장한 경기를 소집이나 출전으로 다시 쓰지 않는다. 국대 은퇴는 해당 주장단 재직을 종료하고, 체크 중 새 국대 주장단 제의를 막는다. 복귀할 때 이전 임명이 자동 복원되지 않는다.

설정·해제 날짜와 해당 시즌을 저장하고 국대 경력/시즌 이력/라커룸과 한국어 은퇴 TXT에 표시한다. 다음 해에도 체크를 유지하면 그 해에 유지 상태를 기록한다. 두 항목을 모두 유지한 해에는 둘 다 기록한다. 과거 자료에 없는 설정 이력은 만들지 않는다. 해제 직후 이전 소집 결과가 남아 있으면 새 평가 대기로 표시한다.

작은 설정은 기존 대형 국대 원장과 분리해 변경분으로 즉시 저장한다. 세계·국대 과거 경기의 큰 객체를 다시 복사하지 않는다. 기존 JSON은 기본적으로 두 항목이 해제된 상태다.

독립 HTML에서 전반기 두 체크 중 국가대표 실제 출전 0·국가 경기 진행, 저장 후 재접속, 두 항목 해제 후 다음 소집의 실제 출전, 기존 결장 경기 불변을 확인했다. PC와 390px 모바일 표시를 확인했다. 기존 **272,717,105바이트·14시즌** 저장에서도 네 번의 체크 변경·두 번 재접속·기량/과거 클럽 및 국대 시즌 기록 보존·전체 저장 준비 Worker로 보내지 않는 경량 변경 경로를 검증했다.

## 5. 승부사의 큰 경기 기여

기존에도 승부사는 큰 경기의 슈팅 기회·조준과 선방/승부차기에 작동했다. 패스·차단·압박 중심 선수의 수행에는 연결이 적었다. 한국어 `4강`도 큰 경기 단계 목록에서 빠져 있었다.

큰 경기 동안 판단·침착·집중·예측·위치 선정·시야·팀워크의 압박 대응을 실제 경기 수행 판정에 연결했다. 해당 경기의 성공한 패스·전진·차단·압박 회수·처리·실점 방어에 영향을 준다. 이 보정은 출전 중 경기 맥락에서만 쓰고, 저장 능력치·성장·OVR이나 과거 경기에는 쓰지 않는다. `4강`을 같은 큰 경기 경로에 포함했다.

240경기씩의 결승 통제 대조에서 CM 승부사 5→10은 전진 패스 1,325→1,486, 도움 45→55였고, CB는 차단 907→966이었다. 실제 패배한 결승에서도 성공한 기여가 남는 사례를 확인했다. GK 선방과 기존 공격수 효과도 유지한다. 큰 경기가 아닌 같은 조건에서는 승부사 변경 전후 전체 매치가 같다. 결승의 득점·승패·개인상은 실제 경기 결과를 따른다.

## 검수와 보존

코어 **381항목 중 380개 통과·실패 0·30시즌 전체 재시뮬레이션 1개 제외**다. 마지막 국대 표시/조회 보완 뒤 관련 **29개**, 두 체크의 다음 해 유지 기록 보완 뒤 해당 **3개**를 다시 확인했다. 마지막 저장 검증에서 FA 이적 시 같은 시즌의 라운드가 재매핑될 수 있음을 고려해, 새 설정 이력은 공통 시뮬레이션 날짜 순서로 검증했다. 국대·저장 **34개**를 추가 확인했고 최종 독립 HTML의 체크·재접속도 다시 통과했다.

기존 30시즌 체크포인트를 이용한 별도 은퇴·통산/연도 합계·한국어 TXT 검사도 통과했다. 이 검사는 30시즌을 이번 버전에서 다시 계산한 것과 구분한다.

PC/모바일 일반 실제 플레이 **11흐름**을 통과했다. 새 실제 108 선수 커리어도 은퇴·전체 JSON 체크섬/모든 필드 왕복·클럽/국대/통합 수치 일치·한국어 국대 활동 TXT·원본 능력 보존을 통과했다. 플레이스킬·성장·수동 노화·부상·성향·FA/계약·컵·클럽 성장·로고·세부 지표 원장·기존 확정 기록은 유지한다. 새 경기와 이후 미확정 심사부터 적용한다.

검수 브라우저는 Linux Chromium이며 관리형 file:// 제한으로 같은 독립 HTML을 localhost로 전달했다. Windows Edge에서 로컬 파일을 직접 실행해 검수한 결과와 구분한다. 첨부 이사기 원본 대조는 압축본 재첨부가 필요하다.

## 성능 확인

새 판정의 초기 구현은 등가 능력치를 사용하는 NPC도 모든 개별 속성 조회와 압박 보정 경로로 풀어 처리했다. 해당 NPC는 모든 개별 능력이 자신의 OVR과 같으므로 동일 가중합을 원래 스칼라로 대수적으로 묶었다. 실제 세부 능력치를 가진 선수와 실제 압박 맥락은 원래 개별 판정을 유지한다. 국가대표 참가 여부의 빈번한 조회도 작은 불리언 필드만 읽는다.

같은 273MB·14시즌 저장을 조용한 환경에서 순차 한 번씩 측정했다. 전반기 엔진 단독 계산은 2.11.4 **12.84초**, 새 기능 최초 **15.04초**, 등가 연산 최적화 후 **13.50초**였다. 최적화 전후 선수·시즌·세계·국대·컵 JSON 해시 5개는 모두 같았다. 독립 108 실제 시즌을 최적화 후 다시 진행한 결과도 소요시간을 제외한 보고 필드가 전부 같았고 발롱 1위였다.

단일 표본의 최종 시간이 이전보다 약 0.66초 길었다. 전체 저장 준비는 7.77→8.30초, 압축은 6.76→7.31초였으며 새 기능으로 모든 처리가 빨라졌다는 주장은 하지 않는다. 현재 파일의 작은 체크 변경은 즉시 안전하게 변경분 저장을 사용하고, 기존 대형 원장/배경 합치기 조율·Worker 사본 해제·모든 경기와 기록은 유지한다. 이 측정은 Node의 단독 단계이며 Windows Edge의 전체 클릭 시간을 측정한 결과가 아니다.

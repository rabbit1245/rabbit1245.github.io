# K볼 2.10.1 · 능력치와 실제 경기 성과 연결 점검

## 기준과 범위

이번 기준은 **90=전성기 손흥민급, 95~100=케인·벤제마·네이마르급, 100~110=메시·호날두급**의 기량 비유다. 선수 수준표의 예시도 이에 맞췄다. 공식 선수 평가나 고정 득점·우승 보장을 뜻하지 않는다. 기존 0~120 OVR 산식, 플레이스킬 5개와 110 상한, 성장·수동 노화·성향·수상 판정·실존 NPC 명단은 유지한다. 과거 확정 기록은 재계산하지 않고 새 경기부터 적용한다.

## 확인한 원인과 수정

### 고능력 구간의 판정이 너무 일찍 포화됐다

기존 패스·드리블·공중볼·헤더 일부 판정은 능력치를 선형으로 더한 뒤 상한에 잘랐다. 예를 들어 CM의 집중력을 90→100으로 올려도 통제된 300경기의 패스 성공 합계가 **17,669→17,669**로 같았다. OVR 100 이상에서 관련 능력치를 더 육성해도 판정 차이가 줄어드는 구간이 있었다.

패스·드리블·태클·공중볼·GK 배급·핸들링·슈팅 정확도를 능력치와 상대 수준을 함께 보는 매끄러운 성공률 곡선으로 바꿨다. 유리한 선수는 더 성공하지만 항상 성공하지는 않으며, 90→100→110에서도 능력치 차이가 이어진다. 후반 체력·실제 출전 시간·기존 역할은 계속 적용한다. 체력처럼 이미 충분하면 피로 효과가 작아지는 항목과, GK 포구/펀칭처럼 행동 선택이 달라지는 항목을 구분한다.

### 일반 슈팅에서 마무리 실력 차이가 묻혔다

일반 선방 확률은 골키퍼 능력치를 강하게 더하고 공격수의 슈팅·침착성은 작게 빼는 형태였다. 우수한 골키퍼를 상대할 때 높은 마무리 기량의 이득이 약했다.

선방·반사신경·GK 위치 선정·집중력·핸들링과 슈팅/헤더·침착성·판단력을 대결시킨다. 실력 차이의 영향은 유한하게 둬 약한 하부 리그 GK를 상대한다고 거의 모든 슈팅이 골이 되지 않게 했다. 일대일·페널티의 기존 별도 판정과, 실제 슈팅→선방/득점 이벤트 원장은 유지한다. 기록을 경기 후 늘리는 보정은 없다.

### 한 명이 강해지면 동료의 기대치까지 올라갔다

팀 전개/수비를 평가하는 기준에 주인공을 포함한 팀 전력이 쓰였다. 강한 GK를 넣어 팀 전력이 높아져도 다른 공격수 능력은 그대로인데 기대치가 함께 올라가 기여를 깎을 수 있었다. 통제 측정에서 GK 80→110 동안 본인 팀 득점 환산이 48.51→42.56으로 내려가는 사례를 확인했다.

이 기준은 출전한 필드 선수 기량의 중앙값으로 분리했다. 한 명의 높은 수치가 동료 열 명의 기여를 상쇄하지 않으며, NPC와 주인공에 같은 규칙을 사용한다. GK의 실제 배급·판단도 팀 전개에 연결한다. 수비수·미드필더·압박형 공격수의 수비 및 공 소유 기여를 보완했다.

### 팀이 약하다는 이유로 뛰어난 개인의 찬스도 함께 눌렸다

모든 선수의 슈팅 기회에 팀 전력 차이가 적용됐지만 개인이 직접 기회를 만드는 능력의 반영은 약했다. 위치 선정·예측력·판단력·속도·볼 컨트롤·드리블로 직접 찬스를 만드는 효과를 추가했다. 기존 포지션별 슈팅 빈도와 팀·상대의 공급/수비 효과는 유지한다. GK에게 필드 선수용 직접 찬스 증가를 적용하지 않아 드문 공격 가담이 불필요하게 늘지 않도록 했다.

### 실제 포지션 경쟁에 비해 출전 확률이 낮았다

주전 확률이 주로 팀 평균 전력과 비교돼, 건강한 최상급 선수도 필요한 수준의 출전을 확보하지 못할 수 있었다. 실제 포지션 경쟁자와 기량·감독 신뢰·폼을 비교하도록 고쳤다. CB는 두 자리를, 윙백은 대응 풀백을 고려하며 나이를 직접 감점하지 않는다. 부상·체력·퇴장·경쟁·로테이션은 계속 적용한다.

## 능력치별 연결

필드 20개 + GK 10개 맥락, 총 30개를 같은 OVR·동일 상대·동일 시드·90분 출전에서 하나씩 90→100으로 비교한다. 표시 OVR을 올리는 것과 세부 능력치 자체의 효과를 구분한다. 각 능력치의 관련 기록과 경기 결과로 이어지는 경로는 다음과 같다.

| 체력 | 후반 활동·압박·피로 | 행동 유지·찬스·수비·출전 가능 상태 |

## 같은 상대를 둔 반복 경기

리버풀의 실제 보정 선수단과 맨시티를 두고 동일 시드 300경기·강제 90분 출전으로 대조했다. 아래는 **38경기 환산값**이며 실제 38경기 시즌 기록과 구별한다. 세부 능력치는 100까지 해당 포지션 전 항목을 같은 값으로 두고, OVR 110은 기본 100 + 포지션 핵심 5개 105의 숙련 프로필이다.

| OVR | ST 득점 이전→수정 | LW 득점 이전→수정 |
|---|---:|---:|
| 90 | 11.65 → 14.06 | 10.13 → 11.91 |
| 95 | 14.57 → 22.93 | 12.03 → 19.13 |
| 100 | 18.49 → 36.35 | 13.93 → 28.50 |
| 110 | 20.39 → 41.42 | 14.57 → 31.16 |

개인별 강점이 다르면 같은 OVR에서도 다른 기록을 낸다. GK·CB·CAM·RWB의 결과와 팀 득실점/승점은 위 전체 대조에 있다. 건강한 95 ST/LW의 자동 선발은 실제 포지션 경쟁을 사용한 300경기에서 215→298회로 변했다. 부상·컨디션과 실제 시즌 피로는 별도 적용한다.

주인공 없는 EPL 실제 일정 3시즌의 경기당 득점은 **2.782 → 2.767**였다. 같은 세 시드의 우승팀은 수정 전후 맨시티·맨시티·리버풀로 같았다. 다른 리그/모든 미래 시즌의 결과를 보장하는 검사는 아니다.

## 실제 세계 전체 7시즌

포르투갈 국적·27세·훈련 0개·능력치 잠금·기본 성향 5로 시작했다. 각 프로필의 기본 능력치는 해당 OVR까지 같은 값이며 110만 위의 숙련 구성을 쓴다. 유효한 주장 제의와 잔류 재계약을 검수 드라이버가 수락했다. 실제 성장으로 도달하는 과정이나 사용자의 특정 세이브 재현을 뜻하지 않는다. ## 성능

다른 검사를 끝낸 동일 기계에서 2.10.0과 최종 코드를 번갈아 측정했다. 전체 세계/커리어 2라운드는 양쪽 모두 리그 726경기를 실제 계산했다.

- 세계 전체 진행 3회 중앙값: **1208.01 → 1256.16ms** · +3.99% · +48.15ms.
- 원본 보존 경기 1,000회·5회 중앙값: 1120.62 → 1167.18ms · +4.16%.
- 집계 뒤 버리는 NPC 경기 1,000회: 1016.09 → 1067.33ms · +5.04%.

새 판정의 추가 계산 비용은 있으며 기존 Worker·작은 변경 저장·경기 원본 보존을 유지한다. 계산·기능을 생략하는 최적화는 추가하지 않았다. 수치는 Linux Node 20이며 Windows Edge 직접 측정이 아니다. 브라우저 검수도 같은 다운로드용 HTML을 Linux Chromium에 HTTP로 전달해 수행했다. ## 다운로드

검수한 ZIP의 공개 다운로드 주소와 무결성 확인 결과를 여기에 기록한다.

기존 게임에서 JSON 내보내기 → 새 ZIP 압축 해제 → `Kball.html`에서 JSON 불러오기로 이어 한다. 하단 **K볼 2.10.1**을 확인한다. 이전 확정 기록은 유지하고 이후 경기부터 새 판정을 사용한다.

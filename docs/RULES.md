# K볼 2.3 규칙과 자료 범위

현재 2.6의 대회·대표팀·수동 노화 규칙과 검증은 [2.6 변경 보고서](IMPROVEMENT-2.6.md)를 참조하세요. 아래는 해당 버전 당시의 기록입니다.


기준일: 2026-10-22. 게임은 기존 2024/FC25 명단을 보존한다. 시작 연도 2026은 게임 달력이며, 실제 2026/27 명단·규정의 검증 완료를 뜻하지 않는다.

## 확인 상태

이번 환경에서 FIFA·FIFPRO·France Football·Premier League의 공식 웹사이트에 접속을 시도했으나 네트워크 프록시가 403을 반환했다. 따라서 **2026/27 공식 규정·평가 기간·메달 조건 전체 확인은 미완료**다. 링크만 추가한 것을 공식 검증으로 취급하지 않는다. 각 항목의 수치 산식과 아래 예외는 게임 모형으로 공개한다.

새 수상은 `kball-awards-2.1` 모형 버전과 실제 평가한 게임 시즌 또는 본선 기간을 보관한다. 이전 저장에 없던 버전·평가 기간은 추정해 채우지 않는다. `official`은 기존 데이터의 실제 수상 **명칭** 구분이며, 현실의 수상 결과·현재 규정 인증을 뜻하지 않는다.

## 승강·달력 예외

- K2↔K3, 네덜란드 2↔3부는 참가 자격·라이선스·연결 규정 확인 전 자동 승강하지 않는다.
- MLS·USL·MLS NEXT Pro는 별도 폐쇄형 대회로 취급한다.
- 일본의 2026 특별대회·추춘제 전환은 별도 재현하지 않고 7월 시작 정상 시즌으로 단순화한다.
- 정규리그는 홈·원정 2회전이다. 분리리그·일부 플레이오프·등록 제한 전체·국내 컵·클럽 대륙대회는 재현 범위에 포함되지 않는다.
- 클럽 경기는 각 리그의 12개월 시즌 안에 배치한다. 6월 5~25일, 11월 5~15일을 게임의 국제경기 휴식기로 비우고, 국대는 해당 날짜에 도달한 경기만 처리한다. 국대 피로·부상은 뒤따르는 클럽 경기에 적용한다.

## 성장·경제

- 집중훈련은 선택한 최대 3개 능력치에만 적용한다. 나이·재능·잠재력·강도·실제 클럽 출전·구단 수입과 선수층으로 근사한 훈련 여건을 반영한다.
- 실제 출전 경험은 30세 이하의 경기 시간과 행동으로 계산하며 능력치마다 시즌 +0.35 이내다. 발달은 24세 이하의 미선택 정신 능력치 일부에만 적용하며 시즌 +0.12(18세 이하) 또는 +0.06 이내다.
- 장기 부상 중 신체 손실은 능력치당 시즌 -0.20 이내이며, 노화는 시즌 사이에 별도로 계산한다. 보고서는 원인별 실제 변화량을 합산하며 노화와 시즌 중 변화를 중복 집계하지 않는다.
- 기존 저장의 과거 성장 원인·계약 변경 이력·시즌 시작 몸값이 없으면 미집계로 둔다. 실제로 남아 있는 값만 기준으로 삼아 이후 기록을 추가한다.
- 몸값은 평가액, 주급은 계약 금액이다. 새 계약에서만 주급이 바뀐다. 이적료는 구단 거래이고 선수 급여·보너스 수입과 별도다.

## 시즌 종료 계약·참여 대회

- 이적·재계약 제안 생성과 수락은 시즌 종료 후에만 가능하다. 전반기 종료 때는 후반기를 그대로 진행한다. 이전 저장에 남은 시즌 중 계약 제안은 원래 해시를 검증해 읽고, 첫 새 명령에서 해제한다. 기존에 확정된 계약·주급·변경 이력은 보존한다.
- 다음 시즌은 잔류 또는 계약 결정과 연간 훈련 확정 후 시작한다. 이미 확정한 훈련의 라커룸 바로가기는 숨기고 선수 → 훈련에서 조회한다.
- 상단 클럽 대회는 현재 시즌 소속·리그·U19 구분과 실제 출전을 기준으로 한다. 오프시즌에 새 구단과 계약해도 끝난 시즌을 새 구단 기록으로 바꾸지 않는다.
- 국대 대회는 해당 시즌에 확인된 실제 소집·출전 기록만 표시한다. 나이에 맞는 U20·성인 대표팀, 예선·본선과 미선발·관찰·부상 상태를 구별한다. 이전 시즌의 `called` 값만으로 새 시즌 참여를 만들지 않는다. 국내 컵·클럽 대륙대회는 표시할 실제 진행 기록이 없으며 구현 범위 밖이다.
- 라커룸 하단의 통합 세부 기록은 해당 시즌 클럽 기록과 중복 제거한 국대 경기 기록을 합산한다. 이전 저장에 없는 상세 행동·분모는 미집계로 남기고 실제 상세 기록이 있는 경기만 성공률·90분당 계산에 사용한다.

## 주장단 제의

클럽 위상은 실제 세계의 팀 전력과 소속 선수단 상위 11명의 OVR로 근사한다. 사용자 OVR·실력 순위·주장단 후보 경쟁, 최근 실제 출전 12경기의 시간과 평점, 연령·근속·리더십·신뢰를 함께 평가한다. 국대는 현재 연령대 대표팀 발탁과 해당 팀 실제 출전 경력이 필요하다. 후보 순위는 사용자와 동료 모두 같은 시즌의 기록과 같은 실력·리더십·연령·성과 가중치로 비교한다. 동료의 근속·신뢰는 기록이 없어 추정하지 않고 사용자 자격 조건으로만 사용한다. 이 평가는 현실 구단의 주장 선임 규정이 아닌 게임 모형이다.

- 성인 주장단의 최소 기준은 21세, 근속 1시즌, 리더십 65, 팀 신뢰 65다. 클럽은 실제 15경기 경력과 최근 6경기·360분, 국대는 실제 8경기 경력과 최근 4경기·240분, 최근 평균 평점 6.50 이상을 요구한다. 팀 주전 수준과 후보 순위 조건도 모두 충족해야 하므로 높은 리더십만으로 강팀의 주장이 되지 않는다.
- 정식 주장은 더 높은 연령·근속·실력·리더십·출전·평점 기준과 후보 1위를 요구한다. U20 국대는 연령별 완화 기준을 사용하며, 유소년 소속 때 성인 클럽 주장 제의를 하지 않는다.
- 조건 충족 시 제의를 기록하며, 수락해야 정식 역할과 임기가 시작된다. 수락 시 현재 소속·시즌·평가를 다시 확인한다. 거절한 같은 팀·시즌의 제의는 반복하지 않고 다음 시즌에 재평가한다. 이적·시즌 전환·은퇴 시 대기 중인 제의를 만료한다.
- 제의 당시 평가, 수락·거절·만료 이력과 정식 임기·실제 완장 출전 수를 보존한다. 임시 경기 주장은 별도 경력이다. 이전 저장에 없던 과거 제의나 평가 근거는 만들어 채우지 않는다.


## 2.3 기존 대회 정상화 범위

사용자 선택에 따라 국내 컵·클럽 대륙대회를 새로 만들지 않고 기존 정규리그와 국대 대회부터 정리했다. 국대 본선 상대는 실제 모의 예선 경기로 결정하고, 본선은 중립 구장으로 계산한다. 전 세계 공식 예선 전체를 재현하는 방식은 아니며, 제한된 대표 조를 사용한다. 4강을 구성할 수 없는 작은 지역 대회는 실제 예선 통과국끼리 결승을 치른다. 존재하지 않는 컵·대륙대회 기록과 과거에 저장되지 않은 지표는 생성하지 않는다.

# K볼 2.1 규칙과 자료 범위

기준일: 2026-10-21. 게임은 기존 2024/FC25 명단을 보존한다. 시작 연도 2026은 게임 달력이며, 실제 2026/27 명단·규정의 검증 완료를 뜻하지 않는다.

## 확인 상태

이번 환경에서 FIFA·FIFPRO·France Football·Premier League의 공식 웹사이트에 접속을 시도했으나 네트워크 프록시가 403을 반환했다. 따라서 **2026/27 공식 규정·평가 기간·메달 조건 전체 확인은 미완료**다. 링크만 추가한 것을 공식 검증으로 취급하지 않는다. 각 항목의 수치 산식과 아래 예외는 게임 모형으로 공개한다.

| 항목 | 게임에서 적용하는 범위 | 공식 참고 기관 |
|---|---|---|
| 발롱도르 | 같은 게임 시즌의 클럽·국대 기록, 역할별 기여·팀 성적·징계로 30인 후보와 순위 선정. 실제 시상식의 고정 평가 기간이나 투표 결과를 재현하지 않음 | [France Football](https://ballondor.com/) |
| FIFPRO 월드 11 | 실제 게임 경기 기록으로 GK 1·DF 3·MF 3·FW 3 + 남은 필드 1명. 게임의 최소 출전 조건 적용 | [FIFPRO](https://fifpro.org/en/supporting-players/player-influence/world11) |
| 리그 개인상 | 같은 리그·게임 시즌의 실제 출전 선수 기록 비교. 득점·도움·무실점은 해당 지표, MVP·베스트 11은 역할별 기여 사용 | `src/game/award-rules.ts`의 항목별 기관 링크 |
| FIFA 대회 개인상 | 4팀 축약 본선에서 실제 출전한 양 팀 선수 비교. 골든 부트는 골→도움→적은 출전 시간. 승부차기 제외. 골든 볼·글러브는 별도의 역할별 모형 | [FIFA](https://www.fifa.com/) |
| 우승 경력 | 실제 우승 결과 + 사용자 출전 조건. EN1 메달은 게임에서 5경기, 미확인 리그는 1경기 조건. 국가대표 우승은 실제 본선 출전 필요 | `src/game/league-rules.ts`의 국가별 기관 링크 |
| 승강 | 세계의 실제 계산된 성적을 다음 참가 리그·상대·일정·예산에 적용. 지역조·플레이오프 일부 단순화 | 같은 파일의 국가별 기관 링크 |
| 국대 달력 | 게임용 6월·11월 창에서 경기일별 진행. 실제 FIFA 국제경기 달력 전체를 재현하지 않음 | [FIFA](https://www.fifa.com/) |

새 수상은 `kball-awards-2.1` 모형 버전과 실제 평가한 게임 시즌 또는 본선 기간을 보관한다. 이전 저장에 없던 버전·평가 기간은 추정해 채우지 않는다. `official`은 기존 데이터의 실제 수상 **명칭** 구분이며, 현실의 수상 결과·현재 규정 인증을 뜻하지 않는다.

## 승강·달력 예외

- K2↔K3, 네덜란드 2↔3부는 참가 자격·라이선스·연결 규정 확인 전 자동 승강하지 않는다.
- MLS·USL·MLS NEXT Pro는 별도 폐쇄형 대회로 취급한다.
- 일본의 2026 특별대회·추춘제 전환은 별도 재현하지 않고 7월 시작 정상 시즌으로 단순화한다.
- 정규리그는 홈·원정 2회전이다. 분리리그·일부 플레이오프·등록 제한 전체·국내 컵·클럽 대륙대회는 재현 범위에 포함되지 않는다.
- 클럽 경기는 각 리그의 12개월 시즌 안에 배치한다. 6월 5~25일, 11월 5~15일을 게임의 국제경기 휴식기로 비우고, 국대는 해당 날짜에 도달한 경기만 처리한다. 국대 피로·부상은 뒤따르는 클럽 경기에 적용한다.

## 성장·경제

- 집중훈련은 선택한 최대 3개 능력치에만 적용한다. 나이·재능·잠재력·강도·실제 클럽 출전·구단 수입과 선수층으로 근사한 훈련 여건을 반영한다.
- 실제 출전 경험은 30세 이하의 경기 시간과 행동으로 계산하며 능력치마다 시즌 +0.35 이내다. 발달은 24세 이하의 미선택 정신 능력치 일부에만 적용하며 시즌 +0.12(18세 이하) 또는 +0.06 이내다.
- 장기 부상 중 신체 손실은 능력치당 시즌 -0.20 이내이며, 노화는 시즌 사이에 별도로 계산한다. 보고서는 원인별 실제 변화량을 합산하며 노화와 시즌 중 변화를 중복 집계하지 않는다.
- 기존 저장의 과거 성장 원인·계약 변경 이력·시즌 시작 몸값이 없으면 미집계로 둔다. 실제로 남아 있는 값만 기준으로 삼아 이후 기록을 추가한다.
- 몸값은 평가액, 주급은 계약 금액이다. 새 계약에서만 주급이 바뀐다. 이적료는 구단 거래이고 선수 급여·보너스 수입과 별도다.

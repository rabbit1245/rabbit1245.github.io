# K볼 2.3.1 · 구단 기본 전력 보존

브레멘이 장기간 독주하고 바르사가 하위권으로 밀리던 문제는 구단 전력 입력 오류에서 시작됐습니다. 선수단 자료가 연결되지 않은 구단에 리그 자체의 평가 점수를 선수 OVR처럼 사용했습니다. 브레멘은 실제 선수 자료가 있어도 `SV Werder Bremen` 명칭이 연결되지 않아 가상 선수단으로 대체됐습니다. 원래 전력 88.10으로 시작해 뮌헨 84.66보다 강했고, 후속 영입도 그 잘못된 수준을 물려받았습니다. 기존 기능·저장 검증으로 이 자료의 타당성을 충분히 확인하지 못했습니다.

## 최종 동작

- 구단 기본 전력은 교정된 2024/FC25 자료를 기준으로 보존합니다. 매년 NPC 선수들의 능력치를 평균내 구단 정체성을 다시 결정하지 않습니다.
- 실제 시즌 성적으로 쌓인 위상을 완만하게 반영하며, 누적 팀 성장·하락은 기본 전력 대비 ±3으로 제한합니다. 그 시즌의 컨디션은 ±2 이내이며 부상과 내 선수의 한계 기여도 반영합니다. 구단 이름에 따라 승리·우승·잔류를 보장하는 규칙은 없습니다.
- 경기에서 NPC 선수는 해당 구단 전력 기준으로 계산합니다. 개인 간 상대적인 차이와 실제 경기 기록은 유지합니다. 교체 세대의 저장 OVR이 높아져도 그것이 구단 전체를 최강 팀으로 바꾸지 않습니다. 클럽 주장 평가와 스카우팅도 같은 기준을 씁니다.
- 내 선수의 능력치와 실제 득점·도움·경기 행동은 그대로 경기 결과에 반영합니다. 이적 시 내 선수의 기여는 새 팀으로 이동합니다.

## 시작 자료 교정

`scripts/extract_kball_data.py`에서 소속 국가를 함께 검사하고, 확인된 구단명 별칭과 유일하게 식별되는 접두어·창단 연도 차이를 연결합니다. `Athletic Club` 스페인/브라질, `Liverpool` 영국/우루과이, `Barcelona SC` 에콰도르 등의 이름 충돌을 해외 구단에 연결하지 않습니다. 모호한 이름은 미매칭으로 남깁니다.

실제 선수의 원본 OVR은 바꾸지 않습니다. 자료가 없는 구단은 같은 리그의 확인 가능한 선수단 중앙값을 기준으로 보완하며, 표본이 없는 하부 리그는 같은 국가의 관측 리그에서 단계별로 추정합니다. 일본·브라질 국내 선수단은 이 원본에 없으므로 명시적인 비교 리그 추정치를 사용합니다. 이런 수치는 실제 현재 선수단의 확인된 평가라고 표시하지 않습니다.

현재 자료는 913구단·43리그 단계·50진행 그룹을 유지합니다. 원본 선수 16,161명 중 9,430명을 연결하고 실제 명단에 8,688명을 보존합니다. 부족한 선수단은 가상 선수 9,850명으로 보완합니다. 실제 2026/27 선수단을 새로 검증한 자료가 아닙니다.

## 기존 저장

읽기·검증·내보내기로 기존 해시를 바꾸지 않습니다. 실제 명령을 실행할 때 만들어지는 복사본에서 구단 기준과 관련 재정 규모를 한 번 보정합니다. 모든 NPC 개인 수치까지 그대로 보존하며, 개인 능력치·계약·경제 이력·국대·과거 경기·전체 순위·우승·수상 기록은 수정하지 않습니다. 이미 강등된 구단을 임의로 복귀시키지 않습니다. 이후 경기에 새 전력이 적용됩니다. 구단 과거 성장 보고서도 보존하고, 중간 시즌에 없던 시작 기대 순위는 만들지 않습니다.

구버전 HTML에서 JSON을 내보낸 다음 새 HTML의 저장 가져오기로 불러오면 됩니다. 다음 진행부터 `구단 기준 전력 보정` 안내가 기록됩니다.

## 검증

재현 명령은 `python3 -B -m unittest discover -s tests -p test_extract_kball_data.py`, `KBALL_SKIP_LONG_TEST=1 npm test`, `npx tsx scripts/validate-league-balance.ts`, `npx tsx scripts/validate-roster-save.ts <기존 저장 경로>`입니다. 장기 리그 실험은 독일·스페인 1~3부의 실제 경기와 승강을 진행하고, 다른 국가 경기는 진행하지 않는 진단입니다. 사용자 선수가 그 리그에 참여하지 않으므로 개인 캐리 효과를 섞지 않습니다.

- 같은 세 시드로 각 15시즌, 리그별 45시즌을 비교했습니다. 기존 버전에서 브레멘은 45회 모두 우승했습니다. 수정 후에는 우승 0회였으며 팀 전력은 73.24~77.02였습니다. 우승팀은 뮌헨 16회, 레버쿠젠 13회, 도르트문트 10회, 라이프치히 5회, 아우크스부르크 1회였습니다.
- 바르사는 기존 6~17위에서 수정 후 1~5위 범위였고, 45시즌 모두 1부에 남았습니다. 라리가 우승은 레알 34회·아틀레티코 9회·바르사 2회로, 이 자료와 모형에서는 레알 쏠림이 남습니다. 이 수치를 현실의 장기 우승 확률로 검증한 것은 아닙니다. 결과를 특정 비율로 맞추는 보정은 추가하지 않았습니다.
- 자동 회귀 검사 171개 통과, 실패 0개였습니다. 30시즌 전체 신규 생성 검사는 이번 실행에서 생략하고, 이미 생성된 실제 30시즌·81,104,879바이트 저장의 원본 해시·전체 개인 수치·경기·국대·경제 이력·모든 NPC 보존과 보정의 멱등성을 검사했습니다. 마지막 개인 기여 계산 정리 후 관련 전력·성장·세계 검사 24개도 다시 통과했습니다.
- 구단명 연결·국가 간 이름 충돌·모호한 이름 거부, 실제 OVR 원본 보존, 누락 선수단의 과도한 전력 방지, NPC OVR을 모두 99로 올려도 구단 기본 전력이 보존되는 경우, 성장 상한과 기존 저장의 첫 명령 보정을 회귀 검사합니다.
- 제작 빌드와 배포용 단일 HTML에서 각각 브라우저 시나리오 10개를 통과했습니다. PC·모바일, 반시즌 진행, 전체 순위, 시즌 종료 계약·훈련, 저장·복원·손상 해시 거부, 다음 시즌·은퇴·TXT 다운로드를 확인했고 페이지 오류는 없었습니다. 단일 HTML의 외부 자산 요청은 0개였습니다. 관리형 브라우저의 `file://` 제한으로 동일 파일을 HTTP로 제공해 자동 검증했습니다. 기존 화이트·회색·연두 팔레트의 스타일 파일은 변경하지 않았습니다.

장기 결과는 기본 전력·경기·승강에 대한 제한된 표본이며 모든 리그의 실제 미래 성적이나 장기 우승 분포를 보장하지 않습니다.

리그 결과는 추출 자료와 게임 모형에 따른 결과이며 실제 미래 성적 예측은 아닙니다. 국내 컵·클럽 대륙대회는 추가하지 않았습니다. 기존 화이트·회색 바탕과 연두 포인트를 유지합니다.

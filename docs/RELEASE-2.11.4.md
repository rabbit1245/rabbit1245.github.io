# K볼 2.11.4 · 장기 커리어 응답과 다양한 경기 기여 평가

## 확인 범위

20대 후반·30대에 커리어가 길어지며 모든 클릭이 느려진다는 제보와, 수비 전문 윙어 등 포지션과 다른 강점이 개인상에 충분히 반영되지 않는다는 요청을 함께 검수했다. 사용자 첨부 `K볼_홍민준_2044.json`은 전송 도구의 32MiB 제한으로 읽지 못했다. 아래 결과는 확보된 별도 장기 저장과 명시한 독립 대조이며 홍민준 커리어를 재현한 결과가 아니다. 압축된 원본을 받으면 해당 저장에 대한 추가 대조가 가능하다.

## 장기 커리어 병목과 변경

31세·14시즌·272,717,105바이트 실제 저장에서 CPU 프로파일을 수집했다. 국가대표 선발의 `poolFor`가 국가마다 세계 선수 전체를 다시 읽으며, 커리어 중 늘어나는 생성 선수의 국적을 반복 판별했다. 최초 프로파일에서 이 검색에 약 8.3초, 국적 조회에 약 1.9초가 사용됐다. 이 비용은 나이 자체의 페널티가 아니라 누적 세계 명단 크기에 따라 증가한다.

동일 국가대표 일정 처리 안에서 생성 선수의 **국적별 소속만 한 번** 묶는다. 선발 후보 기량·나이·부상·폼·출전·실제 점수는 매 조회에서 다시 계산하고 순서도 유지한다. 일정 처리가 끝나면 임시 인덱스를 버린다. 다음 명령·이적·신규 생성·국적 변경을 가로질러 낡은 판정을 재사용하지 않는다. 경기·대회·국가·참가 선수 수를 줄이지 않았다.

같은 저장과 명령·시드로 조용한 환경에서 순차 측정한 전반기 엔진 계산은 **22.90초 → 14.91초(약 35% 감소)**였다. 후보 검색 최적화만 적용한 별도 대조는 선수·시즌·세계·국가대표·컵 기록의 전체 JSON 해시 5개가 모두 일치했다. 최종판은 아래 수상 요청 때문에 새 필드플레이어 무실점 집계를 추가하므로 이 해시 일치 결과와 구분한다.

작은 잠금·수동 조정도 기존에는 1.5초 뒤 대용량 저장 전체를 풀고 검증·체크섬·재인코딩하는 배경 합치기를 시작했다. 화면 클릭은 작아도 다음 명령과 배경 Worker가 메모리·CPU를 경쟁할 수 있었다. 이제 변경분은 그대로 즉시 IndexedDB에 안전하게 기록하고, 32MiB 이상은 15초 조용한 입력 구간과 전체 저장 후 최소 60초 간격으로 묶는다. 저널이 64개 또는 256KiB에 이르면 우선 합치므로 기존 512개/4MiB 안전 한계에 가까워질 때까지 방치하지 않는다. 시즌 진행·가져오기·내보내기·전체 저장은 대기 합치기를 일시 정지하고 불필요한 진행 중 합치기를 취소한 뒤 실제 작업을 실행한다. 작업 후 남은 변경분의 합치기는 재개한다.

저장 안전 검사는 모든 키·노드·깊이를 계속 확인하면서 원시 값마다 만들던 임시 스택 객체를 없앴다. 6,400만 노드·깊이 64·위험 키·체크섬·저장 충돌·직전 정상 백업 검증은 유지한다. 더 빠른 JSON 직렬화도 대조했지만 전체 시간 개선이 없어 채택하지 않았다. 저장 인코딩과 모든 과거 원장은 유지한다.

전체 저장은 여전히 큰 기록 전체의 검증·압축이 필요하다. 이 표본의 전체 준비는 9.76→9.37초, 압축 단계는 7.38→7.20초였으며 전체 저장이 즉시 끝난다고 주장하지 않는다. 클라우드의 작은 클릭은 수정 전에도 약 0.1~0.2초였으므로 사용자의 Edge 지연 크기 자체를 재현했다고 볼 수 없다. 기능을 생략하지 않고 확인된 반복 검색과 배경 작업 경쟁을 줄인 변경이다.

## 포지션과 다른 강점의 개인상 평가

기존 평가는 포지션군을 먼저 정해 그 역할의 고정 가중치를 적용했다. 윙어의 압박·차단·무실점이나 센터백의 득점·창조 기여가 다른 포지션의 같은 성과보다 적게 인정될 수 있었다. 세계 투표의 개인 성과는 1.35에서 평평해져 그 이상의 활약도 같은 점수가 됐다. 8위라는 고정 순위 제한은 없었지만 탁월한 성과를 더 구분하지 못하는 구간이 있었다.

새 평가는 실제 기록에서 다음 기여를 읽고, 가장 뛰어난 하나의 기여와 제한된 보완 기여를 평가한다.

- 수비·압박: 태클·차단·성공한 압박·공중볼·출전 중 무실점.
- 창조·전진: 도움·키패스·성공한 전진 패스·패스 정확도·드리블.
- 마무리: 실제 득점. 헤더 득점은 전체 득점의 하위 기록이므로 별도 중복 가산하지 않는다.

해당 기능을 수행하는 선수들과의 실제 기여 비교와 원래 포지션 동료 대비 우수성을 함께 반영한다. 평점의 직접 골·도움 성분을 배경 평점 비교에서 분리하고 실제 골·도움 채널로 인정해 공격 기록만 중복 강화하지 않는다. 출전 시간·리그 수준·실제 팀/대회 성취·능력·징계·스타성·자격과 XI의 실제 포지션 구성은 유지한다. 주인공과 NPC가 같은 식을 사용하며 포지션 자체나 OVR·능력치·플레이스킬·성장·선수 유형을 바꾸지 않는다.

개인 점수는 기존 상한 이하의 척도를 유지하고 그 위에서 완만하게 계속 증가한다. 뛰어난 시즌 여러 개가 같은 상한에 묶이지 않는다. 리그·세계 개인상·대회 MVP·월간/국대 평가에 같은 기여 모형을 연결하며, 표본 분포·후보 점수는 심사당 한 번 계산한다. 후보마다 세계를 다시 스캔하지 않는다. 객관적인 득점왕·도움왕·골든슈 기준과 GK 판정은 유지한다.

출전 중 무실점은 60분 이상 실제 뛴 모든 필드 포지션에 생성한다. 공격수나 미드필더도 수비 기여의 근거를 가지며 교체 후 실점은 구분한다. 이 항목으로 경기 평점·득점·팀 승패를 추가 가산하지 않는다. 과거 경기의 누락된 무실점이나 확정 수상을 소급 생성하지 않는다.

능력 90 이상이 뛰어난 선수라는 기준은 유지한다. 특정 OVR만으로 수상이나 후보 진입을 보장하지 않으며, 실제 성과가 다양하게 인정되는 것이 이번 변경의 목적이다.

## 경기 기여 대조

별도 실제 세계 전체 리그·클럽 컵·국대가 진행된 시즌 2개를 생성하고, 동일한 선수·시즌 기록을 고정한 분석용 재심사를 했다. 주인공 외 참가자도 같은 새 평가식으로 심사했다.

| 독립 선수 | 실제 리그 기록 | 이전 → 새 발롱 순위 | 새 주요 평가 |
|---|---|---|---|
| 91 RW·수비 능력 100 | 35경기·30골·15도움·48태클·46차단·52압박 성공·93전진 패스 | 2 → 1 | 창조·전진 |
| 94 CB·슈팅/헤딩 100 | 32경기·6골·2도움 | 11 → 7 | 수비·압박 |

RW는 수비에 투자했지만 실제로 공격 성과도 크게 낸 사례다. 홍민준과 같은 저득점 수비 전문 윙어의 실제 저장 대조라고 주장하지 않는다. CB의 공격 능력이 높아도 센터백 역할을 유지하며 6골을 기록했고, 자동으로 스트라이커나 득점왕으로 바꾸지 않는다. 분석용 재심사 전후 선수 능력과 시즌 JSON은 각각 동일했다. 수상은 상대 선수의 실제 기록에 따라 일부 추가되거나 제외될 수 있으며 모든 상을 일괄 상향하지 않는다.

회귀 검사에서는 별도로 낮은 골·도움의 높은 수비 기여 윙어, 많은 골을 넣는 센터백, 전진 패스/창조 기여 센터백을 구성해 각각의 실제 강점을 평가하는지 확인했다. 헤더 중복 가산 방지·누락된 과거 지표 유지·기록 불변·탁월한 이형적 활약의 세계 투표 1위 가능성·이전 개인 점수 상한을 넘는 추가 성과 구분도 검증했다. 이 통제 자료는 실제 시뮬레이션 시즌과 구분한다.

## 검수

273MB·14시즌 저장에서 경량 변경 20회의 중앙값은 **60ms**, 최대 **115ms**였다. 이는 수정 전과 다른 계측 루틴이므로 비율 대조로 사용하지 않는다. 수동 노화·기존 시즌/경기 식별자/기록 보존·변경 직후 재접속·배경 합치기 완료·합치기 후 재접속·모바일 가로 넘침 없음·브라우저 오류 없음도 확인했다. 동작 종료 후 GC를 요청한 메인 JS 힙은 약 336MB로, 브라우저 전체 사용량이나 사용자 PC의 필요 메모리를 뜻하지 않는다.

같은 독립 HTML을 조용한 환경에서 단독 검수해 훈련 선택/확정·이적창·재계약·다음 시즌·전후반기·JSON 내보내기·진행한 저장 재접속을 통과했다. 훈련 선택 50ms·확정 146ms·이적창 97ms였고, 전체 재계약 21.2초·다음 시즌 18.3초·전반기 28.6초·후반기 31.7초였다. **이는 전체 UI+Worker 복사+안전한 전체 저장 시간**으로 위의 엔진 단독 35% 개선 수치와 섞어 비교하지 않는다. 이적/시즌 명령 전체가 즉시 끝난다는 주장은 하지 않는다. 실제 경기·미세 기록을 유지한 성능 개선이며, 사용자의 PC에 따라 체감은 다를 수 있다. 진행/저장 종료 뒤 남은 전용 Worker는 0개였고 외부 요청·브라우저 오류는 없었다.

검수 브라우저는 Linux Chromium이다. 관리형 브라우저의 file:// 제한으로 같은 독립 HTML을 localhost로 전달했다. Windows Edge의 로컬 파일 실행을 직접 검수한 결과와 구분한다. 아스트라 소스나 새 실행 환경 비교를 다시 했다고 주장하지 않는다. 이번 변경은 확인한 K볼의 병목과 평가 경로에 한정한다.

코어 전체 373항목을 실행해 최초 371개 통과·1개 실패·30시즌 전체 재계산 1개 제외였다. 실패 항목은 과거 요청의 “새 행동 지표를 수상에 반영하지 않는다”는 전제였고, 이번 요청에서 실제 압박/전진 기여를 평가하도록 명시적으로 바뀐 조건이다. 헤더 하위 득점/관계없는 GK 기록의 중복 가점 방지는 유지하고, 이 조건을 갱신한 해당 파일과 새 기여 평가 검사 **16개를 재실행해 전부 통과**했다. 최종 서로 다른 코어 항목 상태는 **372개 통과·실패 0·전체 30시즌 재시뮬레이션 1개 제외**다. 판정 코드를 구기준 테스트에 맞춰 무력화하지 않았다.

저장 합치기 완료와 새 변경이 겹칠 때 타이머 재설정도 같은 슬롯 쓰기 큐에서 조정해 새 합치기 예약이 지워지는 경쟁을 예방했다. 이 최종 보완 뒤 저장/Worker/스케줄 검사 **34개**를 통과했다. 최종 독립 HTML에서는 **배경 합치기가 실제로 진행 중일 때 재계약을 시작해 Worker를 중단**하고 새 전체 저장·이전 변경·계약·시즌/경기 기록·재접속을 보존하는 통합 검사도 통과했다.

43세·30시즌의 실제 기존 체크포인트를 현재 코드로 검증해 429,191,805바이트 호환 저장을 만들었다. 이 독립 HTML에서 변경 20회·수동 조정·장기 기록·배경 합치기·모바일·두 번의 재접속을 통과했다. 이 검사는 기능 검사들과 병행했으므로 31세의 조용한 환경과 시간 비율을 비교하지 않는다. 같은 기존 체크포인트로 별도 은퇴·기록 합계·UTF-8 한국어 TXT 검사도 통과했다. 30시즌을 이번 버전에서 다시 진행했다고 주장하지 않는다.

PC/모바일 일반 실제 플레이 **11흐름**·타입 검사·배포용 빌드·독립 HTML 구문/Worker 검증·ZIP CRC·동봉 HTML 동일성도 확인했다. 기존 저장 스키마·원장·기량/성장/플레이스킬과 확정 수상은 유지한다. 변경분 저장은 즉시 안전하게 확정하고 큰 합치기만 조율한다.

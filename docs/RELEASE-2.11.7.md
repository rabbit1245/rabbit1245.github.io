# K볼 2.11.7 · 포지션 변경·구단 영구결번·슈퍼 발롱도르

## OVR 기여도 표시

능력치 화면과 훈련/선수 생성 화면에서 현재 포지션·선수 유형의 기존 OVR 가중치를 **↑ / ↑↑ / ↑↑↑**로 표시한다. 같은 가중치는 같은 단계를 받고, 큰 가중치가 작은 단계로 표시되지 않는다. 화살표 툴팁은 실제 비중(%)을 보여준다. 낮은 기본 비중의 항목은 표시를 생략한다. 기존 OVR/숙련 보정·성장 속도·능력치 산식은 바꾸지 않는다.

16개 포지션의 모든 유형에 대해 가중치와 화살표 순서가 일치하는지 확인했다. 1366×768에서 훈련의 능력치 이름/현재 값은 기존 17px 이상 가독성을 유지하고, 화살표 간격을 조정해 훈련 확정과 플레이스킬 접기까지 화면 안에 둔다.

## 포지션 변경과 기록

훈련 화면 상단 **포지션 변경**에서 새 주 포지션과 유형을 고르고 전후 OVR을 미리 본 뒤 적용한다. 실제 능력치·선택한 플레이스킬·훈련 선택·성장 원장·잠금·체결한 계약·과거 경기/수상은 유지한다. 기존 능력치를 새 포지션·유형의 실제 가중치로 평가하며 다음 경기와 선발 경쟁에 새 포지션을 사용한다. 이전 주 포지션을 부 포지션에 반영하되 기존 최대 2개 규칙을 지킨다.

현재는 같은 능력치 계열 안에서 변경한다. **일반 필드 선수는 필드 포지션끼리 변경 가능하며 골키퍼↔필드 전환은 제외**한다. 없는 전용 능력치를 임의로 생성하거나 서로 다른 스킬/훈련 원장을 지우지 않는다. 골키퍼의 유형 변경은 가능하다.

변경 날짜·시즌·전후 포지션·유형·OVR을 선택 확정 시 기록한다. 같은 포지션의 유형 변경도 기록한다. 커리어의 **이적 · 주장** 화면 상단, 해당 시즌 이력, 연도별 은퇴 결산과 한글 TXT에서 확인할 수 있다. 시즌 종료 후 변경은 그 사실을 표시하며 이미 확정된 과거 시즌의 포지션과 경기 원장을 다시 쓰지 않는다. 기존 저장에 없는 변경 이력은 만들지 않는다. 현재 목록에 없는 구형 유형명도 이전 유형으로 보존한다.

변경은 기존 경량 명령/저장 변경분 경로를 사용한다. 대형 세계·국대·과거 경기 전체를 복사하거나 전체 저장 Worker로 다시 보내지 않는다. 독립 HTML에서 기존 2.11.6 저장을 가져와 PC/모바일 각각 두 번 변경·두 번 재접속·OVR 미리보기 일치·능력/계약/과거 기록 불변·TXT 이력을 확인했다.

## 구단 영구결번

실제 성인 클럽 경기 원장과 해당 구단의 수상·주장 재임·확인된 약체 우승 서사를 바탕으로 시즌 결산과 은퇴 때 평가한다. 재적 시즌은 실제 900분 이상 뛴 해로 센다. 출전량·평균 평점·팀 우승과 주요 대회 우승·구단 올해의 선수·주장단 경력·기대 순위가 낮았던 구단의 우승을 종합한다. OVR이나 나이만으로 부여하지 않는다.

구단의 원래 전력과 팬 기반으로 역사적 위상을 정하므로 사용자가 작은 팀을 키웠다는 이유로 목표선이 계속 높아지지 않는다. 일반 경로의 최소 조건 예시는 아래와 같으며, **조건 숫자만 채운다고 자동 수상하지 않는다.** 누적 평가점수·경기력·우승 등 추가 조건을 함께 충족해야 한다.

| 구단 | 실제 기여 시즌 | 출전 | 누적 평가 기준 | 일반 우승 기준 |
|---|---:|---:|---:|---:|
| 레알 마드리드 | 9 | 384 | 111.8점 | 5회 |
| 맨체스터 유나이티드 | 8 | 356 | 106.3점 | 4회 |
| 서울 이랜드 | 5 | 197 | 74.5점 | 2회 |

장기 헌신 경로와 위상이 낮은 팀의 역사적 도약 경로도 둔다. 도약은 실제 기대 순위 6위 이하의 우승 근거와 최소 3개 기여 시즌/90경기 등이 필요하다. 빅클럽의 기준을 이 경로로 우회할 수 없다.

수상 ID와 구단 ID를 함께 확인해 **같은 구단은 통산 한 번만** 수상한다. 이적·재입단해도 다시 주지 않으며 다른 구단은 그 구단 경력을 따로 평가한다. 개인 수상·연도별 기록·TXT에 남긴다. 실제 구단의 등번호 운영 규정과 구별되는 K볼 특별 수상이며 실제 등번호 배정 체계를 새로 만드는 기능은 아니다.

## 슈퍼 발롱도르

**2030·2035·2040년처럼 5년마다** 해당 연도를 포함한 최근 5시즌을 평가한다. 예를 들어 2030년 시상은 2026~2030년이다. 각 시즌의 이미 확정된 세계 평가점수와 30인 후보 순위를 사용하므로, 기존 포지션별 경기 기여·클럽 리그/컵·국가대표 성적의 평가를 이어받는다.

연간 점수는 해당 연도 1위 대비 실제 평가점수 65%와 후보 순위 35%를 합산한다. 5년 총점으로 모든 후보를 비교하며 후보 밖 연도는 0점이다. 동점은 연간 1위 횟수→후보 횟수→고정 ID 순으로 정한다. 한 번의 우승이나 마지막 해만으로 자동 수상하지 않는다. 5개 연도의 확정 후보 자료가 모두 없으면 평가를 보류하며 없는 과거 성적을 만들지 않는다.

화면 수상명은 **슈퍼 발롱도르**, 연도별 은퇴 기록과 TXT는 **슈퍼 발롱도르(최근 5년 내 성적으로 집계 수상)**으로 표기한다. 수상 기준은 기존과 같이 기본 접힘 상태에서 펼쳐 볼 수 있다. 현실의 시상 주기와 구별하는 K볼 5년 통합 특별상이다. 과거 완료 시즌의 수상을 소급해서 다시 심사하지 않는다.

## 최종 검수 중 확인한 골키퍼 저장 오류

브라우저의 실제 GK 반시즌 검수에서 `신규 행동 원장 · 골키퍼 출전 공백·중복`으로 저장이 거부됐다. 교체 투입된 선수가 다시 부상/퇴장으로 나갈 때 첫 교체만 편성하고 이후 출전 구간을 편성하지 않는 경로를 확인했다. 같은 오류를 **60분 투입·75분 이탈**로 격리해 재현했다.

수정 전 GK 구간은 0~60분·60~75분으로 끝났다. 이제 다음 교체를 편성해 75~90분도 실제 선수의 출전/행동으로 처리한다. GK 퇴장은 별도 필드 선수 한 명을 빼 10명을 유지하고, 부상은 정상 교체로 11명을 유지한다. 일반적인 경기·선발·완주 경로의 계산식은 바꾸지 않는다. 경기 후 통계를 덧붙이거나 저장 검증을 느슨하게 하지 않는다.

## 검사 근거

- 전체 코어는 **398항목 중 397개 통과·실패 0·30시즌 전체 재진행 1개 제외**다. [전체 결과](validation/release-2.11.7/core.tap).
- 구형 유형명 호환 보완 후 포지션/저장 **32개**를 통과했다. [결과](validation/release-2.11.7/position-storage.tap).
- GK 재교체 수정 후 골키퍼·행동 원장·경기 엔진·포지션/수상 **69개**를 추가 확인했다. [결과](validation/release-2.11.7/keeper-actions-position.tap). 같은 능력치 계열의 전환 제한을 확정한 뒤 포지션/수상 **11개**를 다시 확인했다. [결과](validation/release-2.11.7/position-final.tap).
- 기존 실제 **30시즌 체크포인트**의 경기→연도별→통산 기록 일치와 은퇴/TXT 보존을 별도로 통과했다. 이는 저장된 실제 체크포인트 재검증이며 이번에 30시즌을 다시 시뮬레이션했다는 뜻은 아니다. [결과](validation/release-2.11.7/thirty-checkpoint.tap).
- GK 수정 후 독립 HTML의 PC/모바일 **12개 흐름**을 통과했다. 실제 시즌 진행·계약·JSON 왕복·백업 복원·재접속·은퇴/TXT·GK·치트·외부 HTTP 자산 요청 없음까지 포함한다. 서비스 Worker 캐시 재접속 1항목은 독립 HTML에 해당하지 않아 제외했다. [결과](validation/release-2.11.7/browser.json).

영구결번과 5년 평가 자격은 통제된 경기 이력/연간 후보 원장으로 검증한다. 새 수상 이름·접기·TXT의 브라우저 표시는 별도의 **표시 전용 수상 fixture**를 사용하며, 그 표시를 실제 시뮬레이션에서 해당 수상을 획득한 근거로 표현하지 않는다. 포지션 변경 후 실제 경기에서도 새 포지션의 수행을 확인했다.

검수 환경은 Linux Chromium이며 동일 독립 HTML을 localhost로 실행했다. Windows Edge의 직접 `file://` 실행 검사와 구분한다. 빌드·타입 검사·ZIP CRC/내부 HTML 일치를 확인한다.

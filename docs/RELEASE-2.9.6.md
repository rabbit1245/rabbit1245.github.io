# K볼 2.9.6 · 성향 일괄 저장·압박형 공격수·주장 제의

성향 버튼마다 큰 커리어를 경기 Worker로 전송하던 지연을 제거한다. 성향 화면은 기본 접힌 상태이며, 여러 값을 초안으로 조정한 뒤 저장 한 번으로 적용한다. 수비에 기여하는 공격수의 실제 기록을 팀 운영·평점·수상에서 인정하고, 클럽 주장 제의의 검토 시점과 같은 시즌 승격 제한을 보완한다.

## 확인한 원인과 조사 범위

- 기존 성향 버튼은 클릭마다 게임 명령을 보냈다. 저장 계층은 이미 작은 변경 경로를 지원했지만 `client.ts`의 빠른 명령 목록에 성향이 없어 경기 Worker 왕복에서 큰 커리어의 복사·전송이 먼저 발생했다.
- 공격수의 리그 수상 기여 점수는 골·도움·드리블만 사용했다. 대회 투표도 공격수의 태클·차단·키패스·공중볼 기여를 직접 점수에 넣지 않았다. 공격수의 수비 영향 가중치는 고정 0.12여서 실제 성공한 압박을 충분히 활용하지 못했다.
- 클럽 주장 제의는 주로 시즌 시작과 중간에 생성하고 시즌 말에는 새 제의를 생성하지 않았다. 같은 팀·시즌에 제의가 한 번이라도 있으면 부주장 이후의 주장 승격 제의까지 차단했다.

제보한 퀸즈 폴 JSON은 이 대화와 접근 가능한 작업 공간에서 확인되지 않았다. 사용자 Edge의 저장소를 직접 읽을 수 없으므로 그 선수의 포지션별 능력치·실제 경기 기록·당시 버전·수상 평가 결과를 직접 확인했다고 주장하지 않는다. 아래 선수와 수치는 명시한 통제 검사이며 사용자 세이브 재현이 아니다. 실제 JSON이 제공되면 별도로 진단해야 한다.

## 성향 수정과 저장

훈련 아래의 커리어 성향을 펼쳐 +/−로 여러 항목을 수정한다. 수정 버튼은 React의 초안만 바꾸며 경기 명령·저장·진행 이력을 발생시키지 않는다. 접었다 다시 펼쳐도 현재 화면의 초안을 유지하고, 접힌 요약은 적용 중인 값과 미저장 표시를 구분한다. 변경 취소는 저장된 값으로 되돌린다.

성향 저장은 다섯 값을 검증한 뒤 한 번의 명령·한 번의 리비전으로 적용한다. 부분 값·범위 밖·정수가 아닌 값·추가 키·상속받은 필드·은퇴 후 수정은 적용하지 않는다. 기존 단일 항목 명령과 새 일괄 명령 모두 경기 Worker를 거치지 않고 작은 변경 저장 경로를 사용한다. 별도의 저장 Worker와 백업·JSON 검증은 유지한다.

각 성향은 여전히 독립적인 1~10, 기본 5이며 능력치·OVR·성장 상한을 바꾸지 않는다. 저장된 다섯 값이 바뀔 때만 편집 초안을 동기화한다. 항목을 누를 때마다 전체 경기나 과거 시즌을 다시 계산하지 않는다.

## 압박형 공격수와 수상

프레싱 포워드 등 압박 역할은 태클·차단을 더 시도하고 실제 수비 능력·예측·피지컬·체력으로 성공 여부를 계산한다. 성공한 압박의 빈도와 실제 수비 능력이 상대 찬스 억제에 반영된다. 역할 이름만으로 성공 기록이나 팀 승리를 부여하지 않는다.

공격수 평점은 성공한 태클·차단에 더 많은 기여를 인정한다. 리그·세계 개인상 평가에는 골·도움·드리블에 실제 태클·차단·키패스·공중볼 경합을 추가하고, 대회 MVP·베스트 11 등에도 같은 보완을 적용한다. 같은 포지션군 선수에게 동일하게 적용하며, 실제 출전과 성과가 필요하다. 득점왕·도움왕·골든슈는 계속 실제 해당 기록만으로 판정한다. 능력치 95라는 이유만으로 개인상을 확정하지 않는다.

## 주장 제의

클럽은 6라운드마다와 시즌 경계에서 검토한다. 기존 평가를 재사용해 같은 검토에서 큰 이력을 중복 검색하지 않는다. 첫 시즌에도 팀 내 실력·멘털·최근 활약·신뢰와 실제 출전이 충분한 선수는 제의를 받을 수 있다. 부주장은 클럽 실제 12경기 이상부터 검토하며, 멘털과 활약이 매우 좋은 주전급 선수의 주장 검토는 총 24경기 이상, 일반 경로는 32경기 이상을 사용한다. 컵 출전도 실제 소속팀 경기로 센다. 나이 가점은 추가하지 않는다.

같은 시즌에 부주장으로 수락한 뒤 더 좋은 평가를 받으면 별도의 주장 제의가 올 수 있다. 미응답 부주장 제의도 새 주장 제의로 갱신할 수 있다. 임시 자격 미충족으로 만료된 제의는 이후 검토에서 회복할 수 있지만, 거절한 팀·시즌에는 반복 제의를 보내지 않는다. 제의는 자동 임명이 아니며 수락해야 주장 경력과 역할이 바뀐다. 실제 팀 수준·출전·기량·멘털·신뢰·후보 비교는 유지한다.

다음은 기본 5와 비교한 성향 10의 보정이다. 범위·실제 출전 시간·기존 확률 상한을 적용하며 수상·우승을 확정하지 않는다.

| 성향 | 반영 |
| --- | --- |
| 리더십 | 멘털 리더십 평가 최대 +10 및 후보 점수 +6. 이미 지출한 선수단 재투자의 성장 효율 +40%. 구단 돈을 새로 만들지 않는다. |
| 스타성 | 시장가치 +30%, 팬 평가 +25%, 주관적 세계 개인상 투표 +10%, 리그 투표 +8%. 기록 상의 득점·도움 수는 바꾸지 않는다. |
| 페어 능력 | 기존 유지. 10은 카드 없음, 5는 기존 기준, 1은 거친 플레이. |
| 승부사 | 큰 경기에서 본인의 슈팅 기회 +15%·유효 슈팅 확률 계수 +9%, 골키퍼 선방·승부차기 보정 강화. 일반 경기에는 적용하지 않는다. |
| 유관력 | 본인의 실제 출전 시간에 비례해 팀 찬스 공급 최대 +10%, 상대 찬스 계수 최대 -10%. 부재 중에는 적용하지 않는다. |

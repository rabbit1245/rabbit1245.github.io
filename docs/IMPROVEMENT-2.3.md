## 장기 저장·다운로드·화면 검증

- TypeScript 및 프로덕션·단일 HTML 빌드 통과.
- 실제 브라우저에서 1366×768·1920×1080·390×844의 경기 진행·저장·재접속·기존 저장 가져오기·은퇴·TXT 한 번 다운로드·전체 순위표·모바일 마지막 승점 열 접근을 확인했다. 프로덕션 오프라인 재접속과 단일 HTML 외부 HTTP 자산 요청 0건도 통과했다.
- 124개 화면·텍스트 13,102개를 검사해 대비 미달 0개, 최소 대비 4.760:1, 잘림 0개, 알림 겹침 0개, 브라우저 오류 0개다. 비활성 표본 354개, 가로 스크롤 접근도 확인했다.

엔진·저장 검사 **167개**를 통과했다(빠른 검사 166개와 실제 30시즌 검사 1개). 전체 빠른 검사와 수정 후 저장/TXT·국대 회귀 검사를 합산한 중복 없는 검사 수다.

신규 커리어는 **14세부터 43세까지 30시즌**을 실제 진행했다. 중간 14시즌 체크포인트에서 재개했으며 보존된 앞선 경기들도 다시 검증했다. 클럽 **1,020경기**, 국대 **108경기**, 국대 타 팀 **177경기**, 시즌 상세 스냅샷 **30개**를 보존한다. JSON **81,104,879바이트**, 전체 TXT **57,871,592바이트**이며 JSON 왕복·시즌 합계·은퇴 전후 통산과 한글/BOM/CRLF를 검증했다. 본선 상대에 해당하는 실제 예선 조 45개의 기록도 대조했다.

단일 HTML의 실제 브라우저에서 신규 81MB 저장을 가져오고 재접속한 뒤 TXT 버튼을 한 번 눌러 **57,871,592바이트 파일 1개**를 받았다. 다운로드 SHA-256이 엔진에서 만든 전체 TXT와 일치한다. 클럽 30시즌뿐 아니라 국대의 대회·개인 지표·팀 결과, 성장 보고서, 계약·주장·수상·개인 순위도 원본과 대조했다. 브라우저 오류는 0개다.

## 과거 기록과 지원 범위

- 과거 저장에 시즌 전체 순위표·당시 계약·개인 득점/도움 순위·시작/종료 능력치 원본이 없으면 이를 추정하지 않는다. 이미 있는 경기 원장에서 확인 가능한 내 팀 승무패·득실과 개인 지표만 계산한다. 새 스냅샷은 새로 마치는 시즌부터 저장한다.
- 오래된 경기의 상세 행동·시도 분모가 없으면 성공률을 0%로 꾸미지 않는다. `과거 기록 미보존`·`미집계`와 상세 기록이 있는 경기의 집계 범위를 표시한다. 보존 시점 사이의 세부 능력치 최고값도 추정하지 않는다.
- 유소년 전체 타 팀 개인 원장이 없어 U19 전체 개인 순위를 만들지 않는다. 본인의 출전·골·도움과 팀 순위는 보존한다.
- 국내 컵·클럽 대륙대회는 미구현이다. TXT에서도 미구현을 명시하며 참가·탈락·우승·개인 기록을 생성하지 않는다.
- 명단은 기존 2024/FC25 기반이다. 리그 일정·승강·국대 예선·본선·시상 평가는 명시된 게임 모형이며 2026/27 공식 규정 전체를 재현한 결과가 아니다.

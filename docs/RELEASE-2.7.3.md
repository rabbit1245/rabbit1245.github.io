# K볼 2.7.3

2026-10-25 · 최종 검수 완료. 사용자의 배포 보류 해제와 최종 검수·배포 요청에 따라 기존 다운로드 브랜치 `kball-playable`의 ZIP을 갱신합니다. 소스는 기존 `codex/kball-white-green-20261021` 브랜치에 보관합니다.

## 반영한 변경

- 장기 저장의 잠금·훈련·수동 노화·치트 조작은 변경 기록을 먼저 원자적으로 저장한 뒤 조작을 받습니다. 전체 스냅샷은 Worker에서 완전히 검증하고 배경에서 합칩니다. 구버전 슬롯을 읽고 변환하며 JSON 파일 형식·검사값 규칙·직전 정상 백업을 유지합니다.
- 전체 세부 기록은 JSON Blob으로 저장해 IndexedDB의 중첩 객체 복사를 줄였습니다. 동일한 결정론적 폼 값과 스탯 생성 구조, 은퇴 원장을 재사용하고 펼친 은퇴 기록만 세부 UI를 생성합니다. 실제 경기·개인 성장·NPC·팀 전력·컵·국대 계산과 기록 보관 범위는 유지합니다.
- 능력치를 잠근 상태에서도 반 시즌·한 시즌 부상 처리가 가능하며 잠금과 능력치는 유지됩니다. 오프시즌에는 다음 시즌의 실제 소속 리그 달력에 맞춰 부상을 예약합니다. 긴 진행은 라운드별 응답으로 시간 제한을 갱신합니다.
- 출전 중인 주장·부주장의 조직력과 고능력 윙백의 실제 기회 생성·수비 커버를 반영합니다. 충분한 실제 출전·성적을 낸 핵심 선수는 구단 수입과 제한된 재투자의 근거가 됩니다. 기존 구단 기본 전력과 과거 성적은 바꾸지 않으며 상위권·우승을 보장하지 않습니다.
- 은퇴 화면과 TXT는 기본 정보, 통산 총합, 팀 수상, 연도별 소속·몸값·주급·능력·완장·부상·대회 성적·개인 수상·세부 스탯과 성공률, 결승 점수·승부차기·내 기록, 은퇴 시즌을 남깁니다. 분 단위 로그와 내부 조정 이력은 출력하지 않으며 원본 기록은 저장에 보존합니다.

개별 설계와 이전 검수 근거: [팀 기여·부상](PENDING-TEAM-IMPACT.md), [은퇴 기록](PENDING-RETIREMENT-RECORD.md), [성능](PENDING-PERFORMANCE.md). 해당 문서의 ‘배포 보류’는 이 요청 이전의 작업 상태입니다.

## 파일과 이전 저장

ZIP을 풀고 `Kball.html`을 최신 Chrome 또는 Edge에서 엽니다. 게임 하단의 `K볼 2.7.3` 표시를 확인합니다. 파일을 바꾸기 전 기존 버전의 저장 관리에서 JSON 백업을 내보내고, 새 파일에서 가져오면 별도 슬롯으로 이어서 진행할 수 있습니다.

같은 파일 위치·브라우저의 기존 IndexedDB 슬롯은 전체 검증 후 새 저장 표현으로 변환합니다. 새 내부 저장 표현을 읽지 못하는 이전 HTML로 되돌아갈 경우 보관한 JSON 백업을 사용해야 합니다. 기존 JSON 내보내기 스키마는 그대로이며 과거에 보존하지 않은 기록은 새로 만들지 않습니다.

다운로드판은 GitHub Pages 메인 사이트 배포와 별개입니다. 기존 `kball-playable` 브랜치의 `Kball.html`, `Kball.zip`, `Kball.zip.sha256`, `PLAY-KBALL.md`만 갱신합니다.

# K볼 2.7 · 신규 개선 요청 10개 항목

기준 소스: 2.6 (`9b78cbb`). 국내 14개국 913구단·50개 리그 진행 그룹과 기존 선수 커리어를 유지합니다. 2024/FC25 보관 명단을 실제 2026 명단이라고 표시하지 않습니다.

## 조작·성장·부상

- 훈련 탭의 노화 버튼은 팝업을 열지 않습니다. −1/−5/−10을 선택하고 세부 능력치를 누르면 그 항목 하나만 감소합니다. 0에서 멈추고 포지션별 기존 계산식으로 OVR을 다시 계산합니다. 과거 버전의 전체 감소 이력은 ‘이전 방식’으로 보존합니다.
- 각 능력치 자물쇠는 저장됩니다. 중앙 능력치 변경 함수에서 훈련·경험·발달·부상·수동 노화·치트 증가를 모두 차단합니다. 해제할 때 수치를 바꾸거나 밀린 성장을 한 번에 지급하지 않습니다.
- 선수 나이 증가·전성기 종료·시즌 전환은 능력치를 낮추지 않습니다. 나이는 성장 속도·이적 가치·계약·유망주 자격에 계속 쓰입니다. NPC 선수의 세대교체는 유지합니다. 자연 부상으로 인한 소폭의 신체 능력 저하는 성장 원인 ‘부상’으로 따로 기록하고 자물쇠도 적용합니다.
- 부상 버튼의 반 시즌/한 시즌은 달력상 182일/365일입니다. 해당 날짜 구간의 모든 클럽·국대 경기에서 선수를 제외하고 실제 팀 경기는 정상 계산합니다. 부상 이전 기록과 급여·팀 성적을 보존합니다. 부상 중 출전·골·도움·평점을 생성하지 않습니다.
- 시즌 중 부상이 다음 해까지 이어지면 오프시즌의 계약·훈련 결정을 거친 뒤 남은 기간을 자동 진행합니다. 다른 구단으로 이적해도 남은 부상 기간은 같습니다. 복귀가 두 경기 사이에 있으면 그 날짜까지 컵·국대 경기를 처리하고 복귀시킵니다. 부상 시작·복귀·시즌별 실제 출전·클럽/국대 결장을 한국어 TXT에도 남깁니다.

## 수상 20종의 근거

요청서의 20종을 평가 대상으로 지원하며, 실제 참가/출전 이력이 없는 대회나 자격 미달 후보에게 상을 만들지 않습니다. 구단 10종, 월간 2종, 리그 유망주·신인·영입, 국내 컵 MVP, 기존 대륙대회 시즌의 선수, 클럽 월드컵 골든볼, 성인 국가대표 올해의 선수, 유니폼 판매 예상 1위입니다.

구단·리그 시즌 평가는 기본적으로 최소 8경기 또는 리그 경기 수의 35%, 720분, 평점 6.65를 요구하고 같은 범위 후보를 비교합니다. 월간은 해당 월 실제 리그 경기만 최소 2경기·120분·평점 6.8이며 유망주는 23세 이하입니다. 포지션 수상은 공격/중원/수비/GK 후보를 분리합니다. 신인·영입은 확인된 참가·이적 이력으로 제한하고 초기 NPC의 알 수 없는 과거 이력을 만들어내지 않습니다. 해결사는 실제 승리 경기의 결승 득점이 최소 3회 있어야 합니다.

수상 점수는 기존 포지션별 경기 평가를 재사용합니다. 구단 팬/동료 평가는 실제 활약·재적 기간·명성·팀워크의 추정치이며 공식 투표 결과라고 부르지 않습니다. 유니폼 판매는 명성·실적·주요 수상·재적 기간·공격적 매력·팬 규모를 반영한 **예상 순위**입니다. 판매량을 생성하지 않으며 개인상과 별도 상업 기록으로 표시합니다. 같은 상을 이름만 바꿔 중복 생성하지 않습니다.

기존 발롱도르·골든부트·베스트 11은 유지합니다. 추가 내부 상은 ‘K볼 선정’, `official:false`로 구분하고 연도·소속·평가 근거·범위를 저장합니다. 수상 화면에서 구단/리그/월드·대회/국대/상업 기록으로 조회하고 TXT에도 포함합니다. 모든 시즌 조회는 네 시즌씩 표시해 긴 DOM을 피합니다.

## 로고

전체 913개 ID와 SVG 연결을 검사했습니다. 기존 601개 매핑 중 서울 이랜드→FC 서울, 수원 삼성→수원 FC, YSCC 요코하마→요코하마 FC, Jong Cercle Brugge→Club Brugge의 오연결 4개를 제거했습니다. 정상 597개를 보존하고 316개는 통일된 중립 방패 아이콘을 사용합니다. 별도 국제대회 초청 87개 구단도 고유 ID와 중립 아이콘 사용을 확인했습니다. 공식 엠블럼을 새로 확보했다고 주장하지 않습니다. 구단명을 엠블럼처럼 그리지 않습니다. 국가대표는 국기를 유지합니다. 이적 시 구단 ID 변경에 맞춰 이미지 오류 상태도 초기화합니다.

전체 ID·파일·원본 파일명·해시: [로고 검사](validation/kball-2.7-crests.json). 외부 스크립트·이미지 참조 없이 파일 내에 포함하고 브라우저에서 이미지 디코딩도 검사합니다.

## 승강제: 확인된 구현과 남은 규정 확인

K3가 무조건 승격하지 않던 원인은 기존 규칙이 K2↔K3 연결을 차단했기 때문입니다. 새 코드는 2026년 이후 해당 시즌 K3 우승팀의 **확인된 K2 라이선스 승인 명단과 결정전 규정**이 있으면 실제 경기를 치르고 결과에 따라 다음 시즌 K2/K3 참가 구단을 교환합니다. 기록·선수·일정·소속 ID를 유지합니다. 자격이 없거나 자료를 확인하지 못한 경우를 구분해 사유를 보존합니다. 승강 결과는 이적시장 전에 한 번만 결정하고 다음 시즌에 적용합니다.

**현재 공식 승인 명단은 미확인입니다.** 공식 사이트와 검색 사이트가 실행 환경에서 HTTP 403으로 차단되어 최신 연도별 라이선스·승강전 원문을 검증하지 못했습니다. 사용자에게 원문을 요청한 상태이며, `VERIFIED_KOREAN_LICENSES`는 의도적으로 비어 있습니다. 테스트의 승인 자료는 조건 분기 검증용이며 현실의 승인 명단이 아닙니다. 미확인을 탈락으로 기록하거나 특정 구단을 강제 승격하지 않습니다. K4는 기존 카탈로그에 없으므로 K3↔K4 실경기·승강은 미지원입니다.

기타 승강 경계도 코드와 규정 안내를 대조했습니다. 리저브팀의 독일 2부·스페인/포르투갈/이탈리아/네덜란드/벨기에 1부 승격을 차단했고 일반 구단 이름의 BSC를 리저브 B팀으로 오판하지 않습니다. 미국은 폐쇄형, 네덜란드 2↔3부는 자격 미확인 차단, 지역조는 정원 보존, 나머지 국가의 직접 교환·단순 플레이오프는 기존 **게임 모형**입니다. 국가별 연도별 승강 인원·모든 실제 플레이오프·K1/K2 준PO까지 공식 규정으로 완전 재현했다고 주장하지 않습니다. 이 부분은 규정 원문 확인이 남아 있습니다.

## 클럽 국제대회

기존 국내 컵/리그컵 17개와 UEFA 3개를 유지하고 AFC 챔피언스리그 엘리트, 리베르타도레스, CONCACAF 챔피언스컵, CAF 챔피언스리그, OFC 챔피언스리그를 실제 경기 원장으로 연결했습니다. 지원 국내 리그는 실제 게임 순위, 첫 시즌은 명시된 전력 시드로 편성합니다. AFC 엘리트는 동·서 각각 12팀·리그 8경기(홈 4·원정 4·중복 상대 없음), 권역 상위 8팀 16강, 16강 홈원정·8강 이후 단판입니다. 녹아웃 권역별 추첨은 통합하는 게임 모형입니다.

미지원 국가의 대회 참가에는 실존 초청 구단명·명시된 추정 전력·(가상) 선수단을 사용합니다. 이 구단에 가짜 국내 리그 순위·우승·이적 제안을 만들지 않습니다. 예선·국가별 배분·추첨 일부는 지원 범위에서 축약합니다. AFC 2·수다메리카나의 충분한 중복 없는 적격 필드를 만들 수 없는 경우 편성하지 않습니다. 모든 대륙의 하위 컵까지 추가했다고 주장하지 않습니다.

- **FIFA 클럽 월드컵:** 2029년부터 4년 주기. 지난 네 게임 시즌의 대륙 우승팀을 우선하고 실제 대륙 경기 점수로 나머지를 선정합니다. UEFA 12·남미 6·AFC 4·CAF 4·CONCACAF 4·OFC 1·개최국 1, 국가별 두 팀 상한에 복수 우승팀 예외를 적용합니다. MLS의 캐나다 구단은 카탈로그 리그 그룹과 구별해 캐나다로 계산하며 미국 개최국 참가권을 받지 않습니다. 32팀·8개조·조 2위까지 16강·단판 결승, 총 63경기입니다. 최초 평가 기간에 보존되지 않은 2025 결과는 만들지 않습니다. 미래 개최국은 확인되지 않아 게임에서 추첨하며 해당 리그 실제 순위의 최상위 미진출 구단에 개최국 자격을 줍니다(우승팀이 대륙 자격으로 이미 진출했으면 차순위). 개최일은 소속 리그 달력 안의 6월/8월로 조정하는 게임 모형입니다.
- **FIFA 인터컨티넨털컵:** 매년, 직전 6대륙 최상위 대회에서 실제 우승한 팀만 참가. AFC↔OFC→CAF 경로와 남미↔북중미 경로의 승자가 맞붙고 UEFA 우승팀과 결승을 치릅니다. 총 5경기이며 클럽 월드컵과 별도 기록입니다. 보존된 우승자가 없으면 자격을 만들지 않습니다.
- **슈퍼컵:** 지원 국가 중 실제 개최하는 11개국의 리그/국내 컵 우승·준우승 자격과 UEFA 챔피언스/유로파 우승자 슈퍼컵을 편성합니다. 중복 우승 때는 대회에 표시한 리그 후순위 대체를 적용합니다. 이전 시즌의 실제 우승/결승 정보가 있어야 편성합니다. 모든 국가에 슈퍼컵을 만들지 않습니다.

대회별 참가권·경기·스코어·승부차기·우승·개인상·커리어 합계를 연결합니다. 승부차기 득점은 개인 득점에서 제외하며 정규 90분/합계 동점 때 연장을 생략하는 게임 규칙을 표시합니다. 리그 개인 기록·순위에는 컵/국대 기록을 섞지 않습니다. 진행 중인 기존 저장에는 새 과거 경기를 소급 생성하지 않고 다음 시즌부터 적용합니다.

## 금액·이적·성능

금액 저장과 계산 단위 EUR는 그대로 두고 **1 EUR = 1,500 KRW**의 일관된 게임 환율로만 표시합니다. 상세에는 전체 쉼표 숫자와 작은 억·만 보조 단위, 좁은 화면에는 한국어 단위를 사용합니다. 과거 생성된 유로 문장도 표시/TXT에서 환산하고 원본 기록은 바꾸지 않습니다. 예: 150,397,200 EUR → 225,595,800,000원 / 2,255억 9,580만 원.

외부 이적은 정확히 6개(동급 3·하위 1·상위 1·극단 랜덤 1), 현재 구단과 중복을 제외하고 실제 구단·재정·포지션 수요·활약을 반영합니다. 재계약은 별도입니다. 극단 제안은 강/약 양쪽으로 번갈아 다양화하며 최상위 선수는 존재하는 최상위 경쟁 구단으로 대체합니다. 재정이 낮은 팀은 실제 예산 안의 낮은 입찰·낮은 주급을 제시하고 선수에게 그 사실을 설명합니다. 제안을 맞추기 위해 구단 예산이나 가상 구단을 만들어내지 않습니다.

단순 능력치/훈련 설정은 월드를 복사하거나 경기 Worker에 전체 커리어를 보내지 않습니다. 확정된 과거 경기/시즌을 불변으로 공유하고 변경할 컨테이너만 복사합니다. 저장의 중복 검증을 제거하고 원래의 전체 검증·정규 해시를 별도 Worker에서 수행합니다. 연속 진행은 같은 Worker의 직전 상태를 재사용합니다. 상단 요약과 화면 집계를 변경된 커리어에 대해서만 다시 계산하고 기록 목록을 페이지로 제한합니다. 경기 수식·난수·훈련 계산을 단순화하지 않습니다.

## 검증

실행 결과는 [검증 보고서](validation/kball-2.7.json)에 기록합니다. 기존 30년 저장 호환성 자료는 덮어쓰지 않습니다. 새 20시즌 커리어는 별도 경로에 보관하며 1·10·20시즌 실제 저장으로 메뉴 반응과 메모리를 비교합니다. 같은 기존 저장/난수로 2.6과 2.7의 기존 대회 경기·성장·팀/선수 통계가 일치하는지도 비교합니다. 웹 빌드와 자체 포함 HTML을 각각 PC·모바일로 검사한 뒤 ZIP의 실제 내려받기와 해시를 확인합니다.

개발 검증을 재현할 때는 `npm ci`, `KBALL_SKIP_LONG_TEST=1 npm test`, `npx tsx tests/kball-career-v27.ts` 순서로 실행합니다. 성능 비교는 이 20시즌 실행이 만든 1·10·20시즌 저장과 2.6 소스 스냅샷(`/tmp/kball-p26-perf`, 커밋 `9b78cbb`의 `src`, `package.json`, `tsconfig.json` 및 현재 `node_modules` 연결)을 준비한 뒤 `npx tsx tests/kball-performance-v27.ts`와 `node tests/kball-performance-ui-v27.mjs`로 재현합니다. Playwright는 설치된 Chromium 경로를 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정할 수 있습니다.

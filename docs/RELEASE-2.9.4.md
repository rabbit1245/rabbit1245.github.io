# K볼 2.9.4

주인공이 없는 리그의 장기 전력 격차를 보존하고, 능력을 유지한 베테랑의 출전·계약·시장가치를 개선하며, 뛰어난 실적이 개인상 평가에서 지나치게 눌리는 부분을 조정한다. 훈련 바로 아래에 능력치와 독립적인 성향 5개를 추가한다.

## 구단 기반과 선수 영향

주인공이 직접 뛰는 구단과 과거 충분한 출전·핵심 선수 기여가 기록된 구단은 실제 성적·재투자로 쌓은 전력을 유지한다. 이전 구단의 예외는 일정한 실제 출전 시간과 뛰어난 기량·평점 또는 확인된 핵심 선수 영향이 있어야 하며, 짧은 교체 출전만으로는 적용하지 않는다. 그 밖의 구단은 투자가 무한히 누적되는 대신 원래 기반 전력 가까이에서 제한적으로 움직이고 회귀한다. 자율 리그의 투자 전력은 최대 2.5, 위상에 따른 변동은 -1~+1.5로 제한한다. 기존 저장에서 비정상적으로 크게 쌓인 자율 구단 투자도 미래 경기의 전력 계산에서는 이 범위를 적용한다. 과거 순위·경기·우승은 소급 변경하지 않는다.

요청한 토트넘·맨유·맨시티·리버풀·아스널, 밀란·인테르·유벤투스·나폴리·로마, 세비야·아틀레티코·레알·바르셀로나·발렌시아, 도르트문트·레버쿠젠·바이에른, PSG·마르세유·리옹과 첼시를 포함한 22개 구단에 작은 기반 안정 보정을 적용한다. 부상·당해 폼·실제 경기 결과는 계속 반영한다. 순위나 승강을 자동으로 보장하지 않으며, 부상으로 낮아진 현재 전력과 건강한 선수단의 기반 전력을 구분한다.

기존 저장은 원래 체크섬을 먼저 검증한다. 첫 진행 명령의 복사본에서 현재 구단 전력을 정리하고 균형 버전을 기록한다. 이 최초 변환은 완전한 저장 검사를 거치고 이후 성향·훈련·잠금 클릭은 기존의 작은 변경 기록 저장을 사용한다. 매 경기마다 장기 이력을 재검색하지 않도록 주인공 영향 구단 집합을 캐시한다.

## 베테랑과 수상

기존 주전 선정에는 나이 차감이 없었다. 이를 유지하면서 실력과 체력이 높은 핵심 선수의 불필요한 조기 교체 확률을 줄인다. 기량을 유지하고 피지컬과 가용성이 충분한 주전은 고령이어도 다년 계약을 받을 수 있다. 몸값의 고령 계수는 기존 최소 0.12 대신 완만하게 하락하도록 바꾼다. 실제 부상·역할·폼·출전량·구단 예산은 계속 반영한다. 나이만으로 선수 능력치를 깎지 않는다.

세계 개인상은 뛰어난 실적이 상한에서 같은 점수로 눌리는 구간을 완화하고 개인 실적 비중을 높인다. 실제 출전과 성적이 없는 선수에게 능력치나 성향만으로 상을 주지 않는다. 팀 성적·큰 대회·포지션별 비교·페어플레이는 유지한다. 기록 상은 득점·도움 등 실제 기록으로만 판정한다. [현재 실제 수상 목록과 미구현 항목](AWARDS-2.9.4.md).

## 커리어 성향

각 항목은 1~10, 기본값 5이며 총점 공유 제한 없이 독립 조정한다. 훈련 아래의 별도 카드에서 +/−로 바꾼다. 이미 확정한 훈련을 바꾸거나 치트를 활성화할 필요가 없다. 은퇴 뒤에는 편집하지 못한다. 능력치·OVR·성장 상한·지난 경기·지난 수상은 변경하지 않으며, 이후 계산에 적용한다.

| 성향 | 실제 반영 |
| --- | --- |
| 리더십 | 주장 평가에 보조 점수, 실제로 지출한 재투자의 성장 효율 |
| 스타성 | 시장가치, 팬 평가, 주관적인 세계 개인상·리그 시즌 평가에 작은 보정 |
| 페어 능력 | 실제 경고·퇴장 확률. 5는 기존 기준, 10은 카드 없음, 1은 거친 플레이 |
| 승부사 | 결승·주요 토너먼트·강팀 맞대결에서 실제 슈팅 기회·유효 슈팅·선방 및 승부차기 |
| 유관력 | 실제 출전 시간에 비례한 팀 찬스 공급·경기 운영. 부재 중에는 영향 없음 |

기본 5는 성향 보정 0이다. 극단값도 우승이나 주관적 개인상을 확정하지 않는다. 스타성의 세계 투표 보정은 10에서 약 +4%, 리그 주관 평가 약 +3%이며 기록 상에는 적용하지 않는다. 성향은 JSON과 브라우저 저장에 보존하고, 기존 저장에 필드가 없으면 5로 읽는다. 과거 저장 원본에 임의로 기본 필드를 주입하지 않는다. 은퇴 TXT에 별도의 성향 나열은 추가하지 않았다.

## 검증

성향의 독립 조정·범위·능력치 보존·변경 기록 저장·JSON 왕복, 강팀 기반과 주인공이 성장시킨 이전 구단 보존, 40세 고능력 선수의 가치·계약·나이만 다른 선수와 동일한 선발·출전 시간, 카드 0과 거친 플레이, 큰 무대와 일반 경기 구분, 부재 중 유관력 미적용, 팬·투표와 기록 상 구분을 검사한다.

12시즌 리버풀 검사는 모든 필드 능력치가 98인 ST, 초기 28세, 모든 성향 기본 5, 능력치 잠금, 이적 없이 재계약 및 주장 제의 수락이라는 통제 조건이다. 사용자 제보 세이브의 재현이나 일반적인 수상 확률 보장은 아니다. 전체 세계·클럽 대회·대표팀을 실제 진행하고 연도별 순위·득점·도움·개인상·구단 전력·다른 리그 구단 전력의 변화를 기록한다.

이 조건에서 12시즌 리그 8회·챔스 4회, 발롱도르 10회·FIFA 올해의 선수 10회·FIFPRO 월드 11 12회·리그 시즌의 선수 7회를 기록했다. 리버풀 현재 전력은 87.06→93.59, 마지막 시즌 종료 시점의 누적 재투자 전력은 +4.07이었다. 39세 마지막 시즌에도 리그 36경기·3,002분을 뛰었으며 잠근 능력치는 그대로였다. 주인공이 없는 구단들의 기준 대비 최대 전력 상승은 3.51이었다. 요청한 주요 구단들의 건강한 기반 전력도 유지됐다. 부상으로 잠시 낮아진 현재 전력을 기반 붕괴로 간주하지 않는 조건으로 검사했다.

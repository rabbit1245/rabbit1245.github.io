# K볼 2.13.0 — 개별 상한과 종합 OVR 재설계

기본 능력치 상한은 100, 선택한 최대 5개 플레이스타일의 해당 능력치만 120까지 성장합니다. 순수 능력 OVR은 최대 120, 실제 숙련 보정은 합계 최대 10으로 종합 OVR 130에 도달합니다. 훈련 선택·잠금·수동 노화·부상·기존 경기 및 수상·이적·국가대표 기능은 유지합니다.

## 산식과 도달 조건

1. 0~100 구간: 각 능력치를 100에서 제한한 포지션·선수 유형별 가중 평균. 2.12.1의 16포지션·160유형·3,850개 가중치를 유지해 모든 항목이 기여합니다.
2. 전문화 구간: 선택한 능력치의 실제 100 초과 성장으로 개당 최대 4, 5개 합계 최대 20을 더합니다. 각 항목의 진행률 `u = (능력치−100)/20`, 포지션 비중에 따른 계수 `b = clamp((가중치 × 항목 수−1)×0.25, −0.25, 0.25)`에 대해 `4u(1+b(1−u))`입니다. 포지션에 중요한 항목은 중간 구간의 기여가 더 높지만 어떤 5개 조합도 완전히 성장하면 같은 천장에 도달합니다. 선택을 더하는 것만으로 다른 슬롯의 기여가 감소하지 않습니다.
3. 숙련 구간: 선택 후 실제 훈련·경험·직접 조정으로 쌓은 숙련과 현재 100 초과 수치 중 작은 값에 0.1을 곱합니다. 개당 2, 합계 10입니다. 수동 노화로 능력치가 내려가면 현재 수치에 맞게 보정도 줄어듭니다.
4. 마지막에 종합 값을 반올림합니다. 수치 자체와 숙련을 올리지 않고 선택만 해서는 OVR이 늘지 않습니다.

| 상태 | 순수 능력 OVR | 숙련 | 종합 |
|---|---:|---:|---:|
| 모든 능력치 90, 선택 없음 | 90 | 0 | 90 |
| 모든 능력치 100, 선택 없음 | 100 | 0 | 100 |
| 나머지 100 + 선택한 5개만 120 | 120 | 0 | 120 |
| 위 상태 + 5개 숙련 완성 | 120 | 10 | 130 |

나머지 능력치가 부족하면 위 표의 최고점에 도달하지 않습니다. 5개의 선택만으로 약점이 사라지거나 즉시 130이 되는 구조는 아닙니다. GK도 10개 전용 항목과 동일한 다섯 슬롯 원리를 사용합니다. 포지션·유형 변경 시 원래 능력치와 선택을 유지하고 새 비중으로 OVR을 다시 평가합니다. 기존의 필드 포지션 간 변경 범위는 유지합니다.

## 실제 경기와 연결

- 100 이하의 원래 판정과 세계 시뮬레이션은 유지합니다. 표시용 점수만 확장하지 않고, 전문화로 얻은 순수 능력·숙련을 판정용 능력에도 반영합니다.
- 판정용 가중 평균이 반올림 전 OVR과 일치하도록 전문화의 실행 보정을 계산합니다. 80 이하의 약한 항목에는 이 보정을 주지 않습니다. 예를 들어 판단력·시야가 뛰어나도 낮은 드리블이나 속도를 자동으로 세계 정상급으로 바꾸지 않습니다. 표시 능력치는 바뀌지 않습니다.
- 슈팅·침투·패스·창출·드리블·압박·볼 회수·제공권·골키퍼 대응 등 기존 행동 판정이 결과를 만듭니다. 경기 후 득점·도움·평점을 가산하거나 개인 수상·승리를 확정하지 않습니다.
- 경기 판정용 변환은 경기 내 선수 객체마다 한 번 계산하고 약한 참조로 캐시합니다. 과거 경기 전체를 클릭 때마다 재계산하지 않습니다. 2.12.1의 차등 Worker 전송, 원장 참조 재사용, 저장 직렬화 개선은 유지합니다.
- 100~110 미만 메시·호날두, 95~100 미만 수아레스·레반도프스키·네이마르·노이어·반다이크 등 요청한 수준표와 예시를 적용했습니다. 70 미만은 수준별 가상 사례 다섯 개, 0은 별도 기준값이며 120과 130도 구분합니다.

## 저장·기록 호환

- 현재 산식은 `ovrVersion: 3`입니다. 2.12.0과 2.12.1의 산식은 그대로 남겨 당시 체크섬과 OVR을 검증한 다음 한 번만 전환합니다.
- 기존 미선택 능력치가 100을 넘었다면 현재 수치를 새 상한 100으로 조정합니다. **이전 능력치 전체와 시즌 시작·성장 기준값은 `systems.abilityRulesUpgrade`에 보존합니다.** 당시 이미 선택한 능력치와 숙련은 유지합니다.
- 상한 조정과 산식 차이는 실제 성장·노화에서 구분합니다. 이전 경기 원장·시즌·수상·계약·몸값 내역은 수정하지 않습니다. 산식 전환만으로 장기 부진이나 실력 하락으로 오인하지 않도록 비교 척도를 맞춥니다.
- 새로 스킬을 삭제하면 해당 능력치는 기본 상한 100으로 복귀하고 숙련을 종료합니다. 명시적 스킬 변경이므로 잠금 중에도 적용합니다. 다시 선택해도 능력치가 자동 복구되지 않습니다. 획득·삭제 연도와 전후 값은 기존 변경 이력에 남습니다.
- 은퇴한 기존 저장은 당시 능력치·점수 그대로 유지합니다. 기존의 연도별 플레이스타일 표기와 세부 기록 집계·미집계 구분도 유지합니다.

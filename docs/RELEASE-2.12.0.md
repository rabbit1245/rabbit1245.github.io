# K볼 2.12.0 · 세부 능력치와 경기 기록 · OVR 130

## 능력치와 실제 행동

필드 능력치를 20개에서 25개로 확장했다. 기존 저장 키 `defending`은 유지하며 화면과 TXT 이름을 **수비지능**으로 바꿨다.

| 추가 능력치 | 실제 판정 |
|---|---|
| 골 결정력 | 유효 슈팅을 득점으로 마무리하는 골키퍼와의 대결. 슈팅 기술·정확도는 기존 슈팅이 담당한다. |
| 오프더볼 움직임 | 공격 침투와 수비 이탈로 얻는 슈팅 기회. 위치 선정·예측·판단과 함께 작용한다. |
| 압박 능력 | 추격 기회와 볼 처리 방해. 실제 후속 볼 회수가 확인되어야 압박 성공이다. |
| 태클 기술 | 출전 중 실제 상대 볼 소유자와의 직접 경합. 수비지능·판단·신체 능력도 함께 평가한다. |
| 개인기 | 좁은 공간 돌파. 열린 공간의 볼 운반은 기존 드리블·속도·컨트롤을 사용한다. |

포지션·유형에 따른 OVR 비중과 화살표, 훈련/잠금/수동 노화/치트, 경기 경험과 플레이스킬에도 새 항목을 연결했다. 체크하지 않은 능력치는 자연 성장하지 않는다. 포지션 변경·국대 설정·FA·이적·기존 수상·유니폼·구단 성장 기능을 유지한다.

## 경기 원장과 표시

**프리킥 득점·프리킥 도움·페널티킥 득점·결정적 기회 창출·압박 성공률·볼 회수**를 같은 경기 원장으로 집계한다. 경기 상세, 라커룸, 대회·클럽·국대·시즌·통산, 은퇴 TXT와 저장/불러오기에 반영한다. 필드 화면은 기존 12칸 다음에 새 6칸을 붙여 PC 6열×3행으로 표시한다. GK는 기존 10칸을 보존하고 공통 신규 6칸을 추가한다. 모바일은 3열로 배치한다.

직접 프리킥/페널티 득점은 슈팅의 분류를 기록하고 기존 득점 처리에서 한 번만 개인·팀 득점을 올린다. 프리킥 도움은 실제 프리킥 공급→공중 경합→헤더→골→도움의 연결로 확인한다. 결정적 기회는 실제 동료 슈팅으로 연결한 공급 이벤트이며 득점하지 않아도 남는다. 이 기록을 붙였다는 이유로 슈팅 성공률을 추가로 올리지 않는다.

태클·차단은 상대 소유자와의 실제 경합 뒤 회복 이벤트를 남긴다. 압박은 시도와 팀 회수를 구분하고 유도자/회수자를 보존한다. 하나의 소유권을 두 번 회복할 수 없다. 수상·평점에서 도움과 그에 포함된 결정적 기회, 태클·차단과 그에 포함된 회수에 온전한 가점을 각각 중복 부여하지 않는다. 기회 창출과 수비 기여는 기존 역할별 평가에 연결한다.

새 지표의 집계 경기/분과 압박 성공/시도를 따로 보존한다. 과거 시즌은 **미집계**, 신규 경기의 실제 0회는 **0**이다. 과거와 신규가 섞인 합계는 집계 범위를 표시하고 성공률과 90분당 수치는 새 지표를 실제 집계한 경기끼리 계산한다. 내부 연결용 카운터는 은퇴 TXT에 그대로 나열하지 않는다.

## OVR 120 + 숙련 10

사용자가 확정한 **개별 능력치 최대 120 + 실제 숙련 보정 최대 10 = 종합 OVR 최대 130**을 적용했다. 모든 능력치가 120까지 성장할 수 있고, 선택한 플레이스킬은 최대 5개다. 선택한 능력치의 실제 훈련·경험·명시적 증가로 쌓은 숙련과 100 초과 원능력에 따라 개당 최대 2, 합계 최대 10을 더한다. 선택만으로 보정이 생기지 않는다. 원능력이 상한이어도 실제 숙련 훈련은 가능하고 잠금은 이를 막는다.

선택 해제는 해당 숙련 보정을 종료하고 원능력을 보존한다. 재선택 시 숙련을 다시 쌓아야 한다. 수동 노화는 원능력을 내리고 그 원능력에 연결된 보정도 제한한다. 실제 경기의 해당 행동에도 숙련을 적용한다. 110에서 개별 판정을 잘라내던 상한을 확장했다.

표시 기준은 75 미만의 기존 구간을 보존하고, 85~89 손흥민·마네·마레즈·스털링, 90~94 아자르·즐라탄·벤제마·홀란드·음바페, 95~99 레반도프스키·수아레스·네이마르·카카·반다이크·노이어, 100~109 메시·호날두·펠레·마라도나, 110~119 그 전성기를 넘어서는 수준, 120~130 전례 없는 초월 수준으로 적용했다. OVR만으로 우승·발롱도르를 부여하지 않는다.

## 카드 관리

기본 5의 위험 배수는 정확히 1이다. 0~2는 높은 위험, 3~4는 평균보다 높은 위험, 6~9는 점차 낮은 위험, 10도 양의 위험을 유지한다. 실제 태클 시도·실패·압박·차단·스위핑과 판단에 따라 경고 위험을 계산하며, 5 자체의 별도 추가 경고 추첨을 제거했다. 압박형 공격수와 적극적인 수비수도 카드를 받는다. 다른 성향의 기존 1~10 범위는 유지한다.

## 기존 저장과 확정 기록

원본 체크섬을 먼저 검증한 뒤 현역 커리어를 한 번 확장한다. 기존 20개 값은 보존하고 새 5개는 관련 기존 능력치의 가중 평균으로 초기화한다. 이 도입은 경기력 향상으로 소급 기록하지 않으며 도입 연도·라운드·전후 OVR을 남긴다. **현재 OVR은 새 25개 비중과 숙련 산식으로 다시 계산되어 이전 점수와 달라질 수 있다.**

과거 경기/수상/계약 금액과 완료 시즌의 능력점수는 다시 쓰지 않는다. 새 경기 통계를 과거에 추정해 넣지 않는다. 기존 숙련은 실제 남아 있는 100 초과 능력을 바탕으로 이관한다. 현재 시즌 성장 기준에는 도입한 능력치만 추가하고, 기존 노화 보고서 원본의 20개 값은 그대로 검증한다. 몸값의 지속 기량 하락 평가에서는 산식 전환을 실제 기량 상실로 오인하지 않도록 이전 척도를 비교한다. 이미 은퇴한 파일은 과거 체계 그대로 열고 출력할 수 있다.

## 검수와 실행 범위

- 전체 코어 첫 실행: 414개 중 412개 통과, 장기 재시뮬레이션 1개 제외. 변경된 카드 모형에 맞지 않는 절대 경고 수 기대 1개를 수정한 뒤 해당 파일 **9개 전부 통과**했다. 실제 180경기 대조는 카드 관리 1에서 19장, 10에서 2장이었으며 카드 면역을 요구하지 않는다. [전체 첫 실행](validation/release-2.12.0/core-first-pass.tap), [카드 재검수](validation/release-2.12.0/card-management.tap).
- 캐시 보완 후 경기/행동 원장 **63개 통과**. 연도별 숙련 메타데이터 검증 보완 후 능력치/숙련/구형 저장/은퇴 집계 **16개 통과**. [경기 원장](validation/release-2.12.0/match-ledger.tap), [숙련·아카이브](validation/release-2.12.0/archive-mastery.tap).
- 5개 능력치를 각각 45/115로 두고 OVR·상대를 같게 한 160경기씩의 대조에서 득점/슈팅/압박/태클/개인기 차이를 확인했다. 프리킥·페널티·프리킥 도움·득점하지 않은 결정적 기회가 실제 사건으로 발생하고 회수 원장과 집계가 일치한다.
- 같은 동료/상대 85 전력, 90분 선발로 각 OVR **600경기**를 비교했다. 개인 득점은 85→100→110→120→130 순으로 **266→788→1,262→1,624→1,653골**, 팀 패배는 **182→81→28→18→16회**였다. 통제 대조이며 일반 커리어의 실제 시즌 예측값은 아니다. [원자료](validation/release-2.12.0/ability-controls.json).
- 65/70 능력의 3부 스트라이커를 실제 세 리그 일정에서 20시즌씩 비교한 기존 득점 과다 방지 검사도 통과했다.
- 실제 2.11.7 중도 세이브의 기존 능력·경기 전체 해시·스탯·수상 보존, 한 번만 도입, PC/모바일 재접속, 과거 미집계/18개 지표 표시를 확인했다. 120에서 5개 선택만으로 점수가 오르지 않으며 실제 숙련 130 fixture의 표시·저장도 확인했다. [추가 UI](validation/release-2.12.0/expanded-ui.json).
- PC 전체 진행은 생성·전후반기·결산·이적·다음 시즌·은퇴·TXT·백업 복원까지 통과했다. 첫 UI 실행의 GK 검사만 이전 10칸 기대가 남아 있었으며 16칸으로 고쳐 모바일 GK 반시즌/세부 기록/순위와 PC·모바일 치트/재접속을 다시 통과했다. [PC 첫 실행](validation/release-2.12.0/desktop-browser-first-pass.json), [모바일 최종](validation/release-2.12.0/mobile-browser.json).
- 구버전 도입 저장에서 `QuotaExceededError`를 강제해 저장 실패 표시·화면의 25개 능력치·원래 저장의 20개 값 보존을 확인했다. 실패를 정상 저장으로 표시하지 않는다. [실패 주입 검사](validation/release-2.12.0/upgrade-save-failure.json).
- 기존 실제 30시즌 체크포인트의 기록·저장·은퇴 TXT 검증을 별도로 통과했다. 새 버전으로 30시즌을 처음부터 재시뮬레이션한 검사와 구분한다. [결과](validation/release-2.12.0/thirty-checkpoint.tap).

타입 검사와 Vite/독립 HTML 빌드, ZIP CRC·내부 HTML 일치를 확인한다. 검수 브라우저는 **Linux Chromium에서 동일 독립 HTML을 localhost로 실행**했다. Windows Edge의 직접 `file://` 실행은 이 환경에서 검수하지 않았다. 외부 코드·데이터·이미지 HTTP 요청 없이 실행하는 기존 배포 구조를 유지한다.

## 성능 측정

새 기록을 위해 실제 압박 실패·수비 경합·회수 원본도 저장하므로 원본 사건 수가 증가한다. 400경기×5묶음 대조의 경기당 CPU 중앙값은 2.11.7 **2.32ms**, 신규 모형 캐시 전 **3.09ms**, 경기 중 고정 능력/출전 명단 캐시 후 **3.00ms**였다. 같은 조건의 원본 이벤트는 약 164→433개, 비압축 경기 JSON은 약 64→155KB다. 이 추가 기록에는 실제 처리·저장 비용이 있다. 장기 기록 전체를 클릭마다 다시 계산하는 경로를 추가하지 않으며 기존 변경분 저장 구조를 유지한다.

능력·출전 구간은 한 경기 안에서 재사용하고 캐시는 약한 참조로 해제 가능하다. 계산·원본 사건을 생략하지 않았다. 최적화 전후 60경기의 결과·모든 이벤트 SHA-256이 동일했다. CPU 시간은 공유 클라우드의 통제 실험이며 Edge 실기기의 클릭 시간으로 환산하지 않는다. [기존판](validation/release-2.12.0/performance-2117.json), [캐시 전](validation/release-2.12.0/performance-before-cache.json), [캐시 후](validation/release-2.12.0/performance-after-cache.json), [동일 이벤트 해시](validation/release-2.12.0/events-after-cache.sha256).

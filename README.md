## 2.6 대회와 커리어 기록 연결

국내 컵·리그컵 17개와 UEFA 챔피언스리그·유로파·컨퍼런스리그를 실제 경기·대진·우승·다음 시즌 참가권에 연결했습니다. 대표팀은 연 5회 소집 기간에 예선·친선을 치르고 조별리그와 본선 토너먼트를 진행합니다. 소집·선발·교체·벤치·미발탁은 구분하며 출전 원장만 통산 기록에 합산합니다.

나이는 계속 늘지만 능력치는 자동 노화로 감소하지 않습니다. 훈련의 **노화**를 눌러 −1/−5/−10을 미리 보고 직접 적용하거나 취소할 수 있습니다. 화이트·회색과 연두 포인트 화면은 유지합니다. 구체적인 지원 대회·게임 모형·기존 저장 적용 시점과 검증 결과는 [2.6 변경 보고서](docs/IMPROVEMENT-2.6.md)에 기록합니다.

## 2.3.1 구단 기본 전력 보존

구단 기본 전력을 보존하고 시즌 성적에 따른 누적 변화는 ±3 이내로 반영합니다. 시즌 컨디션·부상과 내 선수의 기여를 더하며, NPC 선수 교체가 팀 전체의 전력 기준을 올리지 않습니다. 경기·주장 평가·스카우팅에 같은 구단 기준을 적용합니다.

브레멘·라리가 등에서 누락 선수단이 최상위 전력으로 생성되던 자료 연결 오류도 수정했습니다. 기존 JSON 저장은 해시 확인 후 다음 진행의 복사본에서 구단 기준을 한 번 보정합니다. 모든 개인 선수 수치·계약·과거 경기·순위·우승 기록을 보존합니다. [원인과 검증](docs/IMPROVEMENT-2.3.1.md)을 참고하세요.

## 2.3 경기 기여·구단 성장·전체 기록

- **경기와 팀 성적:** 개인 득점·도움은 같은 경기 원장에서 팀 점수와 승점으로 이어집니다. 좋은 시즌의 실제 순위와 기대 순위 대비 성과가 추가 수입을 만들고, 예산 안에서 동료 훈련과 선수 보강에 쓰입니다. 기본 전력·실제 선수단 전력·누적 위상을 구별하며 이적한 선수의 전력은 새 소속으로 이동합니다.
- **전체 순위와 개인 경쟁:** 라커룸의 `전체 순위 더보기`에서 모든 팀의 경기·승·무·패·득점·실점·득실·승점을 확인합니다. 리그 득점/도움/무실점 순위도 실제 리그 개인 원장만 사용합니다. 발롱도르와 FIFPRO 화면은 내 순위·선정 여부만 표시합니다.
- **성장과 스카우팅:** 포지션·실제 행동·출전·나이·재능·훈련 환경에 따라 경기 경험이 다르게 쌓입니다. 최근 최대 3시즌 활약·성장·개인 수상·잠재력과 영입 구단의 포지션 수요를 함께 평가하고, 관심과 실제 제안을 구별합니다. 계약은 계속 시즌 종료 후에만 선택합니다.
- **국대:** 본선 상대도 실제 모의 예선을 통과해야 합니다. 본선은 중립 구장으로 계산하고 대표팀 전체 선수단 전력을 사용합니다. 2.6부터 국내 컵·UEFA 대회와 확장된 대표팀 본선이 실제 경기·진출권·수상에 연결됩니다.
- **TXT:** 커리어의 `전체 기록 TXT` 버튼 한 번으로 UTF-8 파일 하나를 받습니다. 프로필·전체/클럽/국대 통산·모든 시즌·이적·국대·수상·주장·몸값/계약·능력치·전체 순위·경기별 모든 지표를 한국어로 포함합니다. 새 시즌부터 전체 순위표·당시 계약·개인 순위·능력치 스냅샷도 보존합니다. 구버전에 없던 원본은 `과거 기록 미보존`으로 표시합니다.

화이트·회색 바탕과 진한 본문, 연두 포인트를 유지합니다. 상세 원인·반복 실험·장기 저장·화면 검증과 제한은 [2.3 완료 보고서](docs/IMPROVEMENT-2.3.md)에 정리합니다.

## 2.2 시즌 진행·주장 제의 개선

- **화면:** 화이트·중립 회색 배경에 연두 포인트와 Pretendard, 본문·능력치명 17px, 주요 수치 20~24px를 유지합니다. 팀 현황과 라커룸의 중복 하위 메뉴를 정리하고, 시즌 현황 하단에 이번 시즌 클럽·국대 통합 세부 기록 9개를 표시합니다. 훈련은 선수 화면에서 관리하며, 미확정 오프시즌에만 라커룸 바로가기를 제공합니다.
- **참여 대회:** 상단에 현재 시즌 클럽 대회와 실제 국대 소집·출전 대회를 표시합니다. U19·U20·성인, 예선·본선, 이전 시즌 소집 상태를 구별하며 미선발 대회를 참여 중으로 표시하지 않습니다.
- **주장:** 선수 → 주장에서 팀 전력과 주전 수준, 팀 내 실력 순위, 실제 성적·출전 시간, 나이·근속·리더십·신뢰를 확인합니다. 정식 주장·부주장은 제의를 수락한 뒤 임기를 시작하며 거절 이력도 보관합니다.
- **훈련·계산:** 생성 마지막 단계에서 실제 시작 수치를 확인하고 계획을 확정합니다. 이후 오프시즌에 한 번 확정하며 시즌 중에는 조회합니다. 훈련·출전 경험·발달·부상 손실과 수동 노화를 구분해 저장하고 보고합니다. 사용자 능력치의 자동 노화 감소는 없습니다.
- **일정·계약:** 이적과 재계약은 시즌 종료 후에만 검토합니다. 반시즌에는 계약 제안 때문에 진행을 멈추지 않습니다. 첫 계약·재계약·이적의 이전/새 조건과 날짜, 시즌 시작 몸값을 보존합니다. 국대는 실제 게임 경기일에 진행해 이후 클럽의 체력·부상·선발에 반영합니다.
- **호환:** 기존 v1·배포된 v2 저장의 해시와 과거 기록을 그대로 검증합니다. 없던 과거 성장 원인이나 계약 이력은 만들지 않고 새 진행부터 추적합니다.
- **규정 확인:** 2026/27 공식 규정 전체 확인은 완료하지 못했습니다. 현재 공식 사이트가 이 환경의 네트워크에서 403으로 차단됩니다. 실제 명칭과 게임 모형을 구분하고 평가한 게임 기간·모형 버전을 보관합니다. [규칙과 미확인 범위](docs/RULES.md)를 참고하세요.

Pretendard는 [SIL Open Font License](public/FONT-LICENSE.txt)로 배포하며 사이트·단일 HTML·ZIP에 라이선스를 포함합니다.

## 실행

Node.js 20.19 이상이 필요합니다.

```sh
npm ci
npm run dev
```

프로덕션 빌드를 실행하려면 다음 명령을 사용합니다.

```sh
npm run build
npm run preview
```

GitHub Pages에는 `dist/`를 배포합니다. 저장소 Settings → Pages의 Source를 GitHub Actions로 선택한 뒤, `Publish Kball to GitHub Pages` 워크플로를 수동 실행할 수 있습니다. 다운로드 파일을 보관하는 `kball-playable` 브랜치와 메인 사이트 배포는 별개입니다.

## 파일로 바로 플레이

[K볼 2.9.4 다운로드](https://github.com/rabbit1245/rabbit1245.github.io/raw/808db805f045fa47e24c5ce24ba160cee2109a1d/Kball.zip?download=1)을 내려받아 압축을 풀고 `Kball.html`을 최신 Chrome 또는 Edge로 엽니다. 게임 코드, 선수 명단과 구단 로고가 파일 안에 포함되어 있습니다. 사용자에게 Node.js나 Python 설치는 필요하지 않습니다. 저장 데이터는 브라우저에 보관되므로 파일 이름·위치 또는 브라우저를 바꾸기 전에 JSON으로 내보내세요.

개발자가 이 파일을 다시 생성하려면 Node.js와 Python 3가 설치된 환경에서 다음 명령을 사용합니다.

```sh
npm run build:playable
```

생성물은 `play/Kball.html`과 `play/Kball.zip`이며 Git에서 제외됩니다. 단일 파일은 외부 자산 요청 없이 Blob Worker, 경기 진행, 저장, 파일 백업과 오프라인 진행을 검증합니다. 이 클라우드의 관리형 브라우저는 `file://` 주소 열기를 차단하므로 여기서의 자동 검증은 동일한 HTML을 HTTP로 전달해 수행합니다.

## 플레이

1. 새 커리어에서 선수 정보, 포지션, 플레이스타일, 재능, 시작 구단과 첫 훈련 계획을 선택합니다.
2. **라커룸**에서 전반기와 후반기를 진행합니다. 상단에서 이번 시즌 참여 대회를, 시즌 현황 하단에서 클럽·국대 통합 세부 기록을 확인합니다. 순위는 내 팀 주변과 승강 경계부터 보여주고 전체 표는 페이지로 확인합니다.
3. **선수**에서 능력치의 시작값·현재값·변화, 훈련, 성장 원인, 시장가치·계약·주급과 주장 제의를 확인합니다. 훈련은 시즌 중 고정되며 다음 오프시즌에 한 번 확정합니다. 몸값 변동은 계약 주급을 자동으로 바꾸지 않습니다.
4. **커리어**에서 통합·클럽·국대 세 줄을 선택해 같은 자리의 역할별 9개 지표를 바꿔 봅니다. 기간·대회·소속·연령 단계를 선택하고 시즌 이력, 수상, 주장 임기와 이적 기록을 확인합니다.
5. 시즌 종료 후 라커룸에서 이적·재계약 또는 잔류를 선택하고 다음 시즌 훈련을 확정하면 새 시즌을 시작합니다. 주장 제의는 선수 → 주장에서 별도로 수락·거절하며 시즌 진행을 막지 않습니다. 저장·불러오기·새 커리어와 연출 줄이기는 상단 공통 메뉴에 있습니다.

진행은 각 선수의 별도 IndexedDB 슬롯에 자동 저장합니다. 저장 관리에서 수동 저장, 이전 정상본 복구, JSON 내보내기·가져오기를 제공합니다. 브라우저의 사이트 데이터를 삭제하면 슬롯도 지워지므로 중요한 커리어는 파일로 내보내세요. 가져오기는 기존 슬롯을 덮어쓰지 않습니다. 처음 온라인에서 빌드를 연 뒤 오프라인 캐시가 준비되면 같은 주소에서 다시 접속해 플레이할 수 있습니다. 서버나 로그인, 외부 API는 필요하지 않습니다.

반시즌은 내부에서 개별 경기를 순서대로 계산하고, 이미 확정된 결과를 짧은 장면으로 보여줍니다. 연출 건너뛰기·움직임 줄이기는 경기 결과나 기록을 바꾸지 않습니다. 현역 때 보는 통산 기록과 은퇴 후 기록도 같은 경기 원장을 합산합니다.

## 경기와 이어지는 시스템

- 필드 20개·GK 10개 능력치를 실제 패스, 기회 창출, 슈팅, 돌파, 경합, 저지와 선방 판정에 사용합니다. 특정 능력치 하나만 바꾸고 상대·출전·다른 능력치를 고정한 반복 경기로 효과 방향을 검증합니다.
- 필드·골키퍼 각각 9개 핵심 지표와 공통 출전·선발·시간·평점·MOM을 제공합니다. 성공률은 합산한 성공과 시도로 다시 계산하고 90분당 기록을 함께 보여줍니다. 골키퍼의 득점·도움도 보존합니다.
- 913개 구단의 선수단·연령·부상·전력·선수층·재정과 세계 경기 기록을 유지합니다. NPC의 다음 시즌 성장·노화·은퇴·대체 영입과 실제 재투자는 선수단과 전력에 반영되며 승강은 참가 리그·상대·일정·수입·영입 예산을 바꿉니다.
- 유소년은 별도의 U19 개발 경기와 순위를 사용합니다. 성인 팀은 별도 경기로 성적과 승강을 결정합니다. 실제로 보관된 어린 선수와 명시된 가상 아카데미 선수가 U19 명단을 구성하며, U19 기록으로 성인 리그 개인상이나 발롱도르를 수상하지 않습니다.
- 국대는 국적·연령·포지션 경쟁·출전·평점·부상을 보고 발탁합니다. 예선·본선·대륙대회·친선 경기의 실제 결과가 기록, 피로, 명성과 수상 평가에 반영됩니다. U20과 성인 대표 경력을 구별합니다.
- 시장가치의 현재·이전·최고 값과 이력을 보존합니다. 계약에서 결정한 주급, 구단 간 이적료, 선수의 급여·보너스 수입을 따로 계산합니다. 제안은 구단 예산과 급여 여력, 현재 계약, 기대 역할을 반영합니다.
- 클럽·국대 주장과 부주장은 팀 전력·주전 수준에 맞는 실력, 실제 성적·출전 시간, 근속·리더십·신뢰·나이와 같은 팀 후보 경쟁을 함께 평가해 제의합니다. 제의만으로 역할이 바뀌지 않으며 수락 시점부터 정식 임기를 기록합니다. 거절한 같은 팀·시즌의 제의를 반복하지 않고 이적·시즌 전환 시 대기 제의를 만료합니다. 임시 경기 주장과 정식 역할을 구별합니다.
- 실제 상의 명칭·기관·기준을 관리하고 같은 범위의 경쟁자 실제 기록으로 선정합니다. 득점·도움·무실점상은 각 지표를 비교합니다. 계산에 쓰는 발롱도르 30인과 포지션별 FIFPRO 월드 11은 보존하며 화면에는 내 연도별 순위·선정 여부만 표시합니다. 선정 투표와 MOM 평가는 게임 모형이며 실제 공식 수상 결과라는 뜻은 아닙니다. 구단 최다 득점은 일반 기록으로 표시하고 가상의 성장 트로피는 만들지 않습니다.

## 데이터와 모델의 범위

- 기존 2024/FC25 자료를 바탕으로 한 14개국, 913개 구단, 43개 리그 단계 및 복수 그룹을 분리한 50개 진행 그룹을 사용합니다. 게임 세계의 시작 연도는 2026년이며, 실제 2026/27 선수 명단이라는 뜻은 아닙니다.
- 구단에 매칭된 원본 실명 선수를 보존하고, 부족한 선수단을 이름에 `(가상)`을 표시한 선수로 보완했습니다. 미매칭 선수를 임의로 실제 구단에 배정하지 않습니다.
- 정규리그는 게임용 홈·원정 2회전으로 통일합니다. 국가별 리그 달력, 폐쇄형 리그, 일부 승강 예외를 구분하지만 실제 2026 규정·플레이오프·라이선스·리저브팀 자격을 전부 재현하거나 검증한 모델은 아닙니다. K2↔K3와 네덜란드 2↔3부는 자동 연결하지 않으며 미국 대회 사이에도 자동 승강하지 않습니다. 일본 2026 특별대회와 추춘제 전환은 정상 7월 시작 시즌으로 단순화합니다. 각 규정 화면에 모델 설명과 공식 기관 참고 링크가 있습니다.
- 국대는 연 5회 소집 기간에 예선·친선·본선을 진행합니다. 월드컵 48팀, 유로·아시안컵·아프리카컵·U20 월드컵 24팀 등 지원 본선을 실제 조별리그와 녹아웃으로 치릅니다. 국가별 실제 예선 구조·개최일은 게임 모형이며 부족한 선수단은 명시된 가상 선수로 보완합니다.
- 국내 컵 17개와 UEFA 3개 대회를 지원합니다. 지원 범위 밖 지역 예선, 전체 UEFA 회원국의 실제 계수·예선·추첨 제한, 연장전 30분, 임대·등록 제한 전체는 재현하지 않습니다. 적용 모형을 대회 상세에 표시하며 존재하지 않는 결과로 우승·수상을 만들지 않습니다.
- 16개 포지션, 7개 재능 등급과 포지션별 10개 플레이스타일을 제공합니다.
- 기존 CAREER24는 `legacy.html`에 보존합니다. 기존 localStorage와 새 K볼 슬롯은 서로 덮어쓰지 않으며, 기존 시즌 합계를 새 경기 원장으로 위조해 가져오지 않습니다.

이전 K볼 저장은 원래 해시를 먼저 확인한 뒤 불러옵니다. 첫 진행 명령에서 새 시스템을 초기화하며 기존 기록을 보존합니다. 과거에 수집하지 않은 세부 행동이나 NPC 기록은 만들지 않습니다. 이전·신규 경기 기록이 섞인 범위의 역할 지표에는 상세 기록이 있는 경기만 따로 집계하고 기록 범위를 표시합니다. JSON 저장 파일 한도는 256MB입니다.

## 검증

```sh
npm test                 # 엔진·능력치 민감도·세계/국대·수상·계약·저장 검증 및 30시즌 검사
npm run typecheck
npm run test:legacy      # 기존 턴 전환 테스트
npm run build
npx playwright install chromium
npm run preview          # 별도 터미널에서 유지
npm run test:e2e
npm run test:home        # 위 브라우저 검사에서 만든 저장으로 홈 동선·펼침·기록 보존 확인
npm run test:colors      # 위 브라우저 검사에서 만든 저장으로 화면별 대비·가림 확인
npx tsx tests/generate-captain-fixture.ts # 실제 2시즌 계산으로 주장 제의 저장 생성
node tests/kball-captain-browser.test.mjs # 수락·거절·임기·재접속·모바일 확인
node tests/v55-browser.test.mjs
```

브라우저 검증은 기본적으로 4173번 포트의 빌드를 사용합니다. `KBALL_TEST_URL`과 `CAREER24_TEST_URL`로 주소를 지정할 수 있습니다. 이미 설치한 Chromium을 사용하려면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium`을 지정합니다.

30시즌 검사는 세계의 모든 리그 경기를 실제 계산하므로 수 분 걸릴 수 있습니다. 단일 파일도 `KBALL_TEST_URL=http://127.0.0.1:<포트>/Kball.html`로 같은 브라우저 검증을 수행할 수 있습니다. 장기 검사에서 생성한 `test-results/long-career-30-seasons.json`은 `node tests/kball-large-save.test.mjs`로 실제 브라우저의 대용량 가져오기·저장·재접속까지 확인할 수 있습니다. 빠른 반복 검사에는 `KBALL_SKIP_LONG_TEST=1 npm test`를 사용하고, 배포 전에는 30시즌 검사도 실행합니다.

2.2 개선안의 화면·계산·장기 저장 검증 결과와 남은 범위는 [검증 기록](docs/VALIDATION.md)에 정리했습니다.
